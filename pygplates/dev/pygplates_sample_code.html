Sample code

This document contains sample code that shows pyGPlates solving common plate tectonic problems.

Note

The Getting started section has a Getting Started tutorial as well as an installation guide to help get started.

Each sample is a complete script that runs in a directory containing the data files it names (such as rotations.rot or topologies.gpml). The GPlates sample data provides files of every kind the samples use. Where a sample has an Output section, it shows what the script printed for one particular model and version of pyGPlates, so running it on other data (the sample data included) gives other numbers.
