pygplates.VerifyInformationModel

class pygplates.VerifyInformationModel

Whether to check feature types, property names and property values against the GPlates Geological Information Model (GPGIM).

Accepted by the Feature methods that create or set properties (for example Feature.__init__(), Feature.add(), Feature.set() and Feature.set_geometry()) and by the Feature.create_* functions.

Value

Description

VerifyInformationModel.yes

Verify (the default). InformationModelError is raised if a feature type is not recognised, a property name is not supported by the feature type, or a property value is not of the type the property expects.

VerifyInformationModel.no

Do not verify. Any property can then be added to any feature, but GPlates may not recognise the result.

See also

The GPGIM documentation for the feature types and their properties.
