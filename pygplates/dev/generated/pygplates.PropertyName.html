pygplates.PropertyName

class pygplates.PropertyName

Bases: instance

The namespace-qualified name of a property.

All comparison operators (==, !=, <, <=, >, >=) are supported. PropertyName is hashable (can be used as a key in a dict).

Common property names are available as class attributes, listed under Attributes below, including the names of some enumeration and geometry properties.

A PropertyName can also be pickled.

Changed in version 0.42: Added pickle support.

Changed in version 0.49: Added attributes gpml_rift_edgeLength_threshold_degrees, gpml_rift_exponential_stretching_constant, gpml_rift_left_plate, gpml_rift_right_plate and gpml_rift_strain_rate_resolution_log10.

Changed in version 1.1: Added attribute gpml_rift_edge_length_threshold_degrees. The old name gpml_rift_edgeLength_threshold_degrees still works, but is deprecated.

static create_from_qualified_string(name)

Creates a PropertyName instance from a fully qualified name string.

Parameters:

name (str) – qualified name

Return type:

PropertyName, or None

The name string should have a : character separating the namespace alias from the unqualified name, for example gpml:reconstructionPlateId. If the namespace alias is not recognised (as gpml, gml or xsi) then gpml is assumed.

An over-qualified name string (eg, containing two or more : characters), or an empty name (eg, '' or 'gpml:'), will result in None being returned.
