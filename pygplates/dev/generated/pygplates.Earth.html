pygplates.Earth

class pygplates.Earth

Bases: instance

Various Earth-related parameters (such as radius).

The radius parameters are available as class attributes: equatorial_radius_in_kms (6378.137 kms), polar_radius_in_kms (6356.7523142 kms) and mean_radius_in_kms (6371.009 kms).

For example, to access the mean radius:

earth_mean_radius_in_kms = pygplates.Earth.mean_radius_in_kms

Note

The radius parameters are based on the WGS-84 coordinate system.
