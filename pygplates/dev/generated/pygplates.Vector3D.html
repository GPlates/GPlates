pygplates.Vector3D

class pygplates.Vector3D

Bases: instance

Represents a vector in 3D cartesian coordinates. Vectors are equality (==, !=) comparable (but not hashable - cannot be used as a key in a dict).

The following operations can be used:

Operation

Result

-vector

Creates a new Vector3D that points in the opposite direction to vector

scalar * vector

Creates a new Vector3D from vector with each component of (x,y,z) multiplied by scalar

vector * scalar

Creates a new Vector3D from vector with each component of (x,y,z) multiplied by scalar

vector1 + vector2

Creates a new Vector3D that is the sum of vector1 and vector2

vector1 - vector2

Creates a new Vector3D that is vector2 subtracted from vector1

For example, to interpolate between two vectors:

vector1 = pygplates.Vector3D(...)
vector2 = pygplates.Vector3D(...)
vector_interp = t * vector1 + (1-t) * vector2

The zero vector and the unit vectors along the x, y and z axes are available as class attributes, zero, x_axis, y_axis and z_axis.

For example, to create a vector from a triplet of axis basis weights (triplet of scalars):

vector = (
    x_weight * pygplates.Vector3D.x_axis +
    y_weight * pygplates.Vector3D.y_axis +
    z_weight * pygplates.Vector3D.z_axis)

A Vector3D can also be pickled.

Changed in version 0.42: Added pickle support.

angle_between(other_vector)

Returns the angle between this vector and another vector (in radians).

Parameters:

other_vector (Vector3D, or sequence (such as list or tuple) of float) – the other vector

Return type:

float

Raises:

UnableToNormaliseZeroVectorError – if either this vector or other_vector is (0,0,0) (ie, has zero magnitude)

Note that the angle between a vector (vec) and its opposite (-vec) is math.pi (and not zero) even though both vectors are parallel. This is because they point in opposite directions.

The following example shows a few different ways to use this method:

vec1 = pygplates.Vector3D(1.1, 2.2, 3.3)
vec2 = pygplates.Vector3D(-1.1, -2.2, -3.3)
angle = vec1.angle_between(vec2)

angle = vec1.angle_between((-1.1, -2.2, -3.3))

This method can also be called on the Vector3D class, passing this vector as the first argument:

angle = pygplates.Vector3D.angle_between(vec1, vec2)

This method is the equivalent of:

if not vector.is_zero_magnitude() and not other_vector.is_zero_magnitude():
    angle_between = math.acos(
        vector.to_normalised().dot(other_vector.to_normalised()))
else:
    raise pygplates.UnableToNormaliseZeroVectorError

Changed in version 1.1: Can be called on a vector (vector.angle_between(other_vector)), as well as on the Vector3D class (it was a static method). Renamed the argument vector2 to other_vector (the old names, vector1 and vector2, still work, but cannot be mixed with the new name in the same call).

cross(other_vector)

Returns the cross product of this vector and another vector.

Parameters:

other_vector (Vector3D, or sequence (such as list or tuple) of float) – the other vector

Return type:

Vector3D

The cross product is a new vector (this vector is not modified, since a Vector3D is immutable). The order matters: vec1.cross(vec2) is the opposite of vec2.cross(vec1).

The following example shows a few different ways to use this method:

vec1 = pygplates.Vector3D(1.1, 2.2, 3.3)
vec2 = pygplates.Vector3D(-1.1, -2.2, -3.3)
cross_product = vec1.cross(vec2)

cross_product = vec1.cross((-1.1, -2.2, -3.3))

This method can also be called on the Vector3D class, passing this vector as the first argument:

cross_product = pygplates.Vector3D.cross(vec1, vec2)

The cross product is the equivalent of:

cross_product = pygplates.Vector3D(
    vector.get_y() * other_vector.get_z() - vector.get_z() * other_vector.get_y(),
    vector.get_z() * other_vector.get_x() - vector.get_x() * other_vector.get_z(),
    vector.get_x() * other_vector.get_y() - vector.get_y() * other_vector.get_x())

Changed in version 1.1: Can be called on a vector (vector.cross(other_vector)), as well as on the Vector3D class (it was a static method). Renamed the argument vector2 to other_vector (the old names, vector1 and vector2, still work, but cannot be mixed with the new name in the same call).

to_normalised()

Returns a new vector that is a normalised (unit length) version of this vector.

Return type:

Vector3D

Raises:

UnableToNormaliseZeroVectorError – if this vector is (0,0,0) (ie, has zero magnitude)

If a vector is not zero magnitude then it can return a normalised version of itself:

if not vector.is_zero_magnitude():
    normalised_vector = vector.to_normalised()

NOTE: This does not normalise this vector. Instead it returns a new vector object that is the equivalent of this vector but has a magnitude of 1.0.

This function is the equivalent of:

if not vector.is_zero_magnitude():
    scale = 1.0 / vector.get_magnitude()
    normalised_vector = pygplates.Vector3D(
        scale * vector.get_x(),
        scale * vector.get_y(),
        scale * vector.get_z())
else:
    raise pygplates.UnableToNormaliseZeroVectorError
