pygplates.ReconstructType

class pygplates.ReconstructType

The type of reconstructed geometry that a feature produces when it is reconstructed.

Used to select which features are reconstructed, returned or exported (for example by ReconstructSnapshot.get_reconstructed_geometries(), ReconstructSnapshot.export_reconstructed_geometries() and reconstruct()). Where a method accepts more than one type at once, combine values with the bitwise-or operator (eg, pygplates.ReconstructType.feature_geometry | pygplates.ReconstructType.motion_path).

Value

Description

ReconstructType.feature_geometry

Regular (non-topological) features, which reconstruct to ReconstructedFeatureGeometry objects.

ReconstructType.motion_path

Motion path features, which reconstruct to ReconstructedMotionPath objects.

ReconstructType.flowline

Flowline features, which reconstruct to ReconstructedFlowline objects.
