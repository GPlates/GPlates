pygplates.InformationModelError

exception pygplates.InformationModelError

Bases: PreconditionViolationError

A feature type, property name or property value does not conform to the GPlates Geological Information Model (GPGIM).

Raised when verify_information_model is VerifyInformationModel.yes (the default) and, for example, a feature type is not recognised, a property name is not supported by the feature type, or a property value is not of the type the property expects.
