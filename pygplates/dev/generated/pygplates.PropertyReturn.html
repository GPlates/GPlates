pygplates.PropertyReturn

class pygplates.PropertyReturn

How many matching properties (or property values, or geometries) a query returns.

Accepted by Feature.get(), Feature.get_value(), Feature.get_geometry() and the other Feature methods that query properties.

Value

Description

PropertyReturn.exactly_one

Return the single match only if exactly one property matches the query, otherwise return None.

PropertyReturn.first

Return the first match, or None if nothing matches. Note that a feature is an unordered collection of properties, so this is only meaningful when the order does not matter.

PropertyReturn.all

Return a list of all matches (empty if nothing matches).
