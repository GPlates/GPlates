Partition features into plates

This example partitions features, and a single geometry, into plates at a past geological time using a pygplates.PlatePartitioner.

A plate partitioner holds a set of plates at one time: static polygons reconstructed to that time, or topological plates (and deforming networks) resolved at that time. It cuts whatever it is given along their boundaries.

The first example partitions features whose geometries were digitised at a past time. It assigns each piece the plate ID of its plate, so that the features can be reconstructed to any other time.

The second example partitions a single polygon into resolved topological plates, to find how much of it each plate covers.

Both partition polygons, which a plate partitioner cuts into polygons.

Partition features at a past time

This example:

  • creates a plate partitioner from static polygons reconstructed to 50Ma, with Africa as the anchor plate,

  • splits features whose geometries are positions at 50Ma (relative to Africa) into the plates, assigning plate IDs to the pieces,

  • prints the polygons and scalar values of the pieces, and saves them, and

  • assigns plate IDs a second way, without splitting the features.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the static polygons.

static_polygons.gpml

Static polygon features, each with a reconstruction plate ID. They are reconstructed to 50Ma to become the partitioning plates.

features_at_50Ma.gpml

The features to partition. Their geometries are not at present day positions: they are where the features were at 50Ma, relative to Africa (plate 701). Data digitised over a reconstruction, such as a palaeogeographic map, is like this. The features need no plate IDs: each piece inside a plate is given the plate ID of that plate.

Rotation files and static polygons are in the GPlates sample data.

Sample code

import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# The features to partition were digitised over a reconstruction to 50Ma that held Africa (plate 701) fixed.
# So their geometries are positions at 50Ma relative to Africa, not present day positions.
reconstruction_time = 50
anchor_plate_id = 701

# Create a plate partitioner from the static polygons, reconstructed to the same time with the same anchor plate.
plate_partitioner = pygplates.PlatePartitioner(
        'static_polygons.gpml',
        rotation_model,
        reconstruction_time=reconstruction_time,
        anchor_plate_id=anchor_plate_id)

# Split each feature into the plates it overlaps.
# Each partitioned feature is given the plate ID of its plate, and its geometry is reverse reconstructed to present day.
# The parts of a feature that are outside all the plates are returned in an unpartitioned feature.
partitioned_features, unpartitioned_features = plate_partitioner.partition_features(
        'features_at_50Ma.gpml',
        partition_return=pygplates.PartitionReturn.separate_partitioned_and_unpartitioned)

for partitioned_feature in partitioned_features:
    print(f'Part of "{partitioned_feature.get_name()}" on plate {partitioned_feature.get_reconstruction_plate_id()}:')

    # A polygon is partitioned into polygons, which have interior rings where they need them.
    for geometry in partitioned_feature.get_geometries():
        if isinstance(geometry, pygplates.PolygonOnSphere):
            area_in_square_kms = geometry.get_area() * pygplates.Earth.mean_radius_in_kms**2
            print(f'  polygon with {geometry.get_number_of_interior_rings()} interior rings '
                  f'and an area of {area_in_square_kms:.0f} square kms')

    # A geometry that had a scalar value at each of its points is partitioned into geometries that have them too.
    for geometry, scalars in partitioned_feature.get_geometries(
            coverage_return=pygplates.CoverageReturn.geometry_and_scalars):
        for scalar_type, scalar_values in scalars.items():
            print(f'  {len(geometry.get_points())} points with {scalar_type} values {scalar_values}')

for unpartitioned_feature in unpartitioned_features:
    print(f'Part of "{unpartitioned_feature.get_name()}" outside all plates: '
          f'{len(unpartitioned_feature.get_geometries())} geometries')

# The partitioned features can now be reconstructed to any time, so save them.
pygplates.FeatureCollection(partitioned_features).write('partitioned_features.gpml')

# A plate partitioner drops the slivers that a cut can leave: pieces of a polygon less than about 90 metres wide.
# To keep every piece, create a plate partitioner with a sliver width threshold of zero.
plate_partitioner_keeping_slivers = pygplates.PlatePartitioner(
        'static_polygons.gpml',
        rotation_model,
        reconstruction_time=reconstruction_time,
        anchor_plate_id=anchor_plate_id,
        sliver_width_threshold_radians=0)
partitioned_features_with_slivers = plate_partitioner_keeping_slivers.partition_features('features_at_50Ma.gpml')
print(f'Keeping slivers gives {len(partitioned_features_with_slivers)} features '
      f'instead of {len(partitioned_features) + len(unpartitioned_features)}')

# Alternatively, don't split the features. Give each the plate ID of the plate that most overlaps it.
# For a polygon that is the plate containing the largest area of it.
whole_features = plate_partitioner.partition_features(
        'features_at_50Ma.gpml',
        partition_method=pygplates.PartitionMethod.most_overlapping_plate)
for whole_feature in whole_features:
    print(f'Most of "{whole_feature.get_name()}" is on plate {whole_feature.get_reconstruction_plate_id()}')

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

The features to partition are at their 50Ma positions, in a reference frame that holds Africa (plate 701) fixed.

The plates must be at the same time and in the same reference frame, or the features will not be where the plates are.

# The features to partition were digitised over a reconstruction to 50Ma that held Africa (plate 701) fixed.
# So their geometries are positions at 50Ma relative to Africa, not present day positions.
reconstruction_time = 50
anchor_plate_id = 701

A pygplates.PlatePartitioner is created from the static polygons. It reconstructs them to reconstruction_time, relative to anchor_plate_id, and these reconstructed polygons are its partitioning plates.

Without reconstruction_time the plates are at present day. Without anchor_plate_id the anchor plate is the default anchor plate of the rotation model, which is zero unless the rotation model was created with another.

The plate partitioner can now partition any number of features and geometries. To partition at another time, create another plate partitioner.

# Create a plate partitioner from the static polygons, reconstructed to the same time with the same anchor plate.
plate_partitioner = pygplates.PlatePartitioner(
        'static_polygons.gpml',
        rotation_model,
        reconstruction_time=reconstruction_time,
        anchor_plate_id=anchor_plate_id)

pygplates.PlatePartitioner.partition_features() splits each feature into the plates that it overlaps. This is the default partition_method, PartitionMethod.split_into_plates.

A feature that overlaps two plates becomes two features, each a copy of the original with the part of its geometry that is inside one plate. Each is assigned the reconstruction plate ID of its plate (other properties of the plate, such as its valid time, can be copied too: see the properties_to_copy argument).

Each of these partitioned features is then reverse reconstructed, with its new plate ID, from 50Ma to present day, using the rotation model and the anchor plate of the plate partitioner. Its geometry is now a present day position, like that of any other feature.

Any part of a feature that is outside all the plates becomes an unpartitioned feature. It is not assigned a plate ID (it keeps one that the original feature had) and it is not reverse reconstructed, so its geometry is still a position at 50Ma.

With partition_return set to PartitionReturn.separate_partitioned_and_unpartitioned the partitioned and unpartitioned features are returned in two lists. By default they are returned in one.

The features that were passed in are not changed. New features are always returned.

# Split each feature into the plates it overlaps.
# Each partitioned feature is given the plate ID of its plate, and its geometry is reverse reconstructed to present day.
# The parts of a feature that are outside all the plates are returned in an unpartitioned feature.
partitioned_features, unpartitioned_features = plate_partitioner.partition_features(
        'features_at_50Ma.gpml',
        partition_return=pygplates.PartitionReturn.separate_partitioned_and_unpartitioned)

Each partitioned feature has the name of the feature it was cut from, and the plate ID of its plate.

for partitioned_feature in partitioned_features:
    print(f'Part of "{partitioned_feature.get_name()}" on plate {partitioned_feature.get_reconstruction_plate_id()}:')

A polygon that crosses a plate boundary is cut into polygons (before pyGPlates 1.1 it was cut into polylines).

The polygons have interior rings where they need them. For example, where the original polygon covers a small plate and the plate around it, the piece on the plate around it has a hole where the small plate is.

The area of a polygon is pygplates.PolygonOnSphere.get_area(), which takes its interior rings into account, and pygplates.PolygonOnSphere.get_number_of_interior_rings() counts them.

# A polygon is partitioned into polygons, which have interior rings where they need them.
for geometry in partitioned_feature.get_geometries():
    if isinstance(geometry, pygplates.PolygonOnSphere):
        area_in_square_kms = geometry.get_area() * pygplates.Earth.mean_radius_in_kms**2
        print(f'  polygon with {geometry.get_number_of_interior_rings()} interior rings '
              f'and an area of {area_in_square_kms:.0f} square kms')

A geometry can have scalar values, one at each of its points (a coverage). When such a geometry is split, each piece keeps the values at the original’s points, and gets interpolated values at the points that the cut adds.

pygplates.Feature.get_geometries() returns each geometry with its scalar values when coverage_return is CoverageReturn.geometry_and_scalars. The values are in a dict mapping each pygplates.ScalarType to a list with one value per point.

Each piece that has scalar values is returned in a feature of its own.

# A geometry that had a scalar value at each of its points is partitioned into geometries that have them too.
for geometry, scalars in partitioned_feature.get_geometries(
        coverage_return=pygplates.CoverageReturn.geometry_and_scalars):
    for scalar_type, scalar_values in scalars.items():
        print(f'  {len(geometry.get_points())} points with {scalar_type} values {scalar_values}')

The reconstructed static polygons do not cover the globe. They have moved apart since present day, leaving gaps.

An unpartitioned feature has the parts of one original feature that are in the gaps.

for unpartitioned_feature in unpartitioned_features:
    print(f'Part of "{unpartitioned_feature.get_name()}" outside all plates: '
          f'{len(unpartitioned_feature.get_geometries())} geometries')

The partitioned features are saved to a file. With their plate IDs and present day geometries they can be reconstructed to any time, like the features in Reconstruct regular features.

# The partitioned features can now be reconstructed to any time, so save them.
pygplates.FeatureCollection(partitioned_features).write('partitioned_features.gpml')

A cut can leave slivers: where the outline of a polygon was digitised along a plate boundary it strays a few metres over the boundary, and each excursion is a thin piece on the neighbouring plate.

A plate partitioner drops the pieces of a polygon that are narrower than its sliver_width_threshold_radians argument, which is about 90 metres by default. So a polygon digitised along a plate boundary stays whole, on one plate.

With a threshold of zero every piece is kept, and the pieces cover the original polygon exactly.

# A plate partitioner drops the slivers that a cut can leave: pieces of a polygon less than about 90 metres wide.
# To keep every piece, create a plate partitioner with a sliver width threshold of zero.
plate_partitioner_keeping_slivers = pygplates.PlatePartitioner(
        'static_polygons.gpml',
        rotation_model,
        reconstruction_time=reconstruction_time,
        anchor_plate_id=anchor_plate_id,
        sliver_width_threshold_radians=0)
partitioned_features_with_slivers = plate_partitioner_keeping_slivers.partition_features('features_at_50Ma.gpml')
print(f'Keeping slivers gives {len(partitioned_features_with_slivers)} features '
      f'instead of {len(partitioned_features) + len(unpartitioned_features)}')

With partition_method set to PartitionMethod.most_overlapping_plate the features are not split. Each feature is assigned the plate ID of the one plate that most overlaps it, and its whole geometry is reverse reconstructed with that plate ID.

The plate that most overlaps a polygon is the one containing the largest area of it (before pyGPlates 1.1 this was measured by the length of the polygon’s outline). For a polyline it is the plate containing the greatest length, and for points the greatest number.

A feature that overlaps no plate is returned as it was.

# Alternatively, don't split the features. Give each the plate ID of the plate that most overlaps it.
# For a polygon that is the plate containing the largest area of it.
whole_features = plate_partitioner.partition_features(
        'features_at_50Ma.gpml',
        partition_method=pygplates.PartitionMethod.most_overlapping_plate)
for whole_feature in whole_features:
    print(f'Most of "{whole_feature.get_name()}" is on plate {whole_feature.get_reconstruction_plate_id()}')

Partition a polygon into resolved plates

This example:

  • creates a plate partitioner from the topological plates (and deforming networks) resolved at 10Ma,

  • partitions a polygon into them, and

  • prints the area of the polygon that each plate covers.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the features that the topologies are built from.

topologies.gpml

Topological plate polygon features, with or without deforming network features. They are resolved at 10Ma to become the partitioning plates.

Files of these kinds are in the GPlates sample data.

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Get a snapshot of our resolved topologies at 10Ma.
reconstruction_time = 10
topological_snapshot = topological_model.topological_snapshot(reconstruction_time)

# Create a plate partitioner from the resolved topological plates (and deforming networks).
# The snapshot's rotation model has the anchor plate that the topologies were resolved with.
plate_partitioner = pygplates.PlatePartitioner(
        topological_snapshot.get_resolved_topologies(),
        topological_snapshot.get_rotation_model())

# The region to partition: a polygon that is where it is at 10Ma (it is not reconstructed).
region = pygplates.PolygonOnSphere([(-15, 125), (-15, 172), (25, 172), (25, 125)])

# Partition the region into the plates.
# Each entry of the first list is a plate and a list of the pieces of the region inside it.
# The second list has the pieces of the region that are outside all the plates.
pieces_inside_plates = []
pieces_outside_plates = []
plate_partitioner.partition_geometry(region, pieces_inside_plates, pieces_outside_plates)

for plate, pieces_inside_plate in pieces_inside_plates:

    # The plate is a resolved topological plate or network, or a rigid block inside a network.
    # Either way it has a feature, with a plate ID and a name.
    plate_feature = plate.get_feature()

    # A polygon is partitioned into polygons, which have interior rings where they need them.
    area_inside_plate = 0
    num_interior_rings = 0
    for piece in pieces_inside_plate:
        area_inside_plate += piece.get_area()
        num_interior_rings += piece.get_number_of_interior_rings()

    area_inside_plate_in_square_kms = area_inside_plate * pygplates.Earth.mean_radius_in_kms**2
    print(f'Plate {plate_feature.get_reconstruction_plate_id()} ({plate_feature.get_name()}) contains '
          f'{area_inside_plate_in_square_kms:.0f} square kms of the region, '
          f'in {len(pieces_inside_plate)} polygons with {num_interior_rings} interior rings')

area_outside_plates = sum(piece.get_area() for piece in pieces_outside_plates)
area_outside_plates_in_square_kms = area_outside_plates * pygplates.Earth.mean_radius_in_kms**2
print(f'{area_outside_plates_in_square_kms:.0f} square kms of the region are outside all plates')

Details

A topological model is created from the topological features and the rotation file.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The topological features are resolved at 10Ma using pygplates.TopologicalModel.topological_snapshot().

# Get a snapshot of our resolved topologies at 10Ma.
reconstruction_time = 10
topological_snapshot = topological_model.topological_snapshot(reconstruction_time)

A pygplates.PlatePartitioner can also be created from plates that have already been reconstructed or resolved. Here they are the resolved topological plates and networks of the snapshot, from pygplates.TopologicalSnapshot.get_resolved_topologies().

The plate partitioner also needs the rotation model and the anchor plate that the plates were resolved with. pygplates.TopologicalSnapshot.get_rotation_model() provides both, since the default anchor plate of the rotation model it returns is the anchor plate of the snapshot.

Where a deforming network overlays a plate, the network is searched first, so what is inside both is partitioned into the network (see pygplates.SortPartitioningPlates).

# Create a plate partitioner from the resolved topological plates (and deforming networks).
# The snapshot's rotation model has the anchor plate that the topologies were resolved with.
plate_partitioner = pygplates.PlatePartitioner(
        topological_snapshot.get_resolved_topologies(),
        topological_snapshot.get_rotation_model())

The polygon to partition is created from four points.

A geometry given to a plate partitioner is not reconstructed. It is taken to be at the time of the partitioning plates (10Ma here) and in the reference frame of their anchor plate.

# The region to partition: a polygon that is where it is at 10Ma (it is not reconstructed).
region = pygplates.PolygonOnSphere([(-15, 125), (-15, 172), (25, 172), (25, 125)])

pygplates.PlatePartitioner.partition_geometry() partitions the polygon, appending to the two lists it is given.

To the first it appends a 2-tuple for each plate that contains part of the polygon: the plate, and a list of the pieces inside that plate.

To the second it appends the pieces that are outside all the plates.

As with features, a polygon is partitioned into polygons.

# Partition the region into the plates.
# Each entry of the first list is a plate and a list of the pieces of the region inside it.
# The second list has the pieces of the region that are outside all the plates.
pieces_inside_plates = []
pieces_outside_plates = []
plate_partitioner.partition_geometry(region, pieces_inside_plates, pieces_outside_plates)

Each plate is a pygplates.ResolvedTopologicalBoundary or a pygplates.ResolvedTopologicalNetwork.

A rigid block inside a deforming network is a plate of its own here: a pygplates.ReconstructedFeatureGeometry, whose feature is the block’s. The network then contains only what is in its deforming region, so a piece of the polygon that surrounds a rigid block has an interior ring where the block is.

All three have a get_feature() method, which provides the plate ID and name.

The area that a plate covers is the sum of the areas of its pieces.

for plate, pieces_inside_plate in pieces_inside_plates:

    # The plate is a resolved topological plate or network, or a rigid block inside a network.
    # Either way it has a feature, with a plate ID and a name.
    plate_feature = plate.get_feature()

    # A polygon is partitioned into polygons, which have interior rings where they need them.
    area_inside_plate = 0
    num_interior_rings = 0
    for piece in pieces_inside_plate:
        area_inside_plate += piece.get_area()
        num_interior_rings += piece.get_number_of_interior_rings()

    area_inside_plate_in_square_kms = area_inside_plate * pygplates.Earth.mean_radius_in_kms**2
    print(f'Plate {plate_feature.get_reconstruction_plate_id()} ({plate_feature.get_name()}) contains '
          f'{area_inside_plate_in_square_kms:.0f} square kms of the region, '
          f'in {len(pieces_inside_plate)} polygons with {num_interior_rings} interior rings')

The pieces outside all the plates are where the polygon extends beyond the topological model.

area_outside_plates = sum(piece.get_area() for piece in pieces_outside_plates)
area_outside_plates_in_square_kms = area_outside_plates * pygplates.Earth.mean_radius_in_kms**2
print(f'{area_outside_plates_in_square_kms:.0f} square kms of the region are outside all plates')

Note

To partition with a single polygon, pygplates.PolygonOnSphere.partition() does the same without a plate partitioner. Find the overlap, union and difference of polygons shows the polygon operations that return the same pieces.
