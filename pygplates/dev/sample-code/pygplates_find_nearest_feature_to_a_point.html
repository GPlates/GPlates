Find nearest reconstructed feature to a point

This example reconstructs a collection of features, and finds the reconstructed feature that is nearest to a point.

  • Details

  • Advanced

  • See also

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the features in features.gpml.

features.gpml

Reconstructable features, each with a reconstruction plate ID and one or more geometries.

Files of these kinds are in the GPlates sample data.

Sample code

import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Load some features.
features = pygplates.FeatureCollection('features.gpml')

# Reconstruct features to 10Ma.
reconstruction_time = 10

# All features have their distance calculated relative to this point.
point_latitude = 0
point_longitude = 0
point = pygplates.PointOnSphere(point_latitude, point_longitude)

# Whether polygons are filled, so that a point inside a polygon is at distance zero from it (True),
# or are only their outlines, so that the distance is to the outline even from inside (False).
polygons_are_solid = False

# Reconstruct the features to 10Ma.
reconstruct_snapshot = pygplates.ReconstructSnapshot(features, rotation_model, reconstruction_time)
reconstructed_features = reconstruct_snapshot.get_reconstructed_features()

# The minimum distance to all features and the nearest feature.
min_distance_to_all_features = None
nearest_feature = None

# Iterate over all reconstructed features.
for feature, feature_reconstructed_geometries in reconstructed_features:

    # Iterate over all reconstructed geometries of the current feature.
    for feature_reconstructed_geometry in feature_reconstructed_geometries:

        # Get the minimum distance from point to the current reconstructed geometry.
        min_distance_to_feature = point.distance(
                feature_reconstructed_geometry.get_reconstructed_geometry(),
                min_distance_to_all_features,
                other_geometry_is_solid=polygons_are_solid)

        # If the current geometry is nearer than all previous geometries then
        # its associated feature is the nearest feature so far.
        if min_distance_to_feature is not None:
            min_distance_to_all_features = min_distance_to_feature
            nearest_feature = feature

if nearest_feature is not None:
    print(f'The nearest feature, to point {point.to_lat_lon()}, has feature ID {nearest_feature.get_feature_id()} '
          f'and a minimum distance of {min_distance_to_all_features * pygplates.Earth.mean_radius_in_kms:f}kms')

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

The reconstructable features are loaded into a pygplates.FeatureCollection.

# Load some features.
features = pygplates.FeatureCollection('features.gpml')

The features will be reconstructed to their 10Ma positions.

# Reconstruct features to 10Ma.
reconstruction_time = 10

The test point is at zero latitude and zero longitude. The script finds the reconstructed feature that is closest to it.

# All features have their distance calculated relative to this point.
point_latitude = 0
point_longitude = 0
point = pygplates.PointOnSphere(point_latitude, point_longitude)

polygons_are_solid says how the distance to a polygon is measured. With False, as here, a polygon is only its outline: the distance to it is the distance to its outline, even where the point is inside the polygon. With True a polygon is filled, so a point inside it is at a distance of zero from it. The distance to any other type of geometry is the same either way.

# Whether polygons are filled, so that a point inside a polygon is at distance zero from it (True),
# or are only their outlines, so that the distance is to the outline even from inside (False).
polygons_are_solid = False

The features are reconstructed to 10Ma by creating a pygplates.ReconstructSnapshot. A feature that does not exist at 10Ma, according to its valid time period, is not reconstructed.

pygplates.ReconstructSnapshot.get_reconstructed_features() returns the reconstructed feature geometries grouped by their feature. This example does not strictly need the grouping: pygplates.ReconstructSnapshot.get_reconstructed_geometries() would also do.

# Reconstruct the features to 10Ma.
reconstruct_snapshot = pygplates.ReconstructSnapshot(features, rotation_model, reconstruction_time)
reconstructed_features = reconstruct_snapshot.get_reconstructed_features()

min_distance_to_all_features is the distance from the point to the nearest geometry found so far. It starts as None, since nothing has been found yet.

It is also passed to the distance() method below as the distance threshold, where None means there is no threshold.

# The minimum distance to all features and the nearest feature.
min_distance_to_all_features = None
nearest_feature = None

Each item in the reconstructed_features list is a tuple of a feature and a list of its reconstructed geometries.

# Iterate over all reconstructed features.
for feature, feature_reconstructed_geometries in reconstructed_features:

A feature can have more than one geometry, and so more than one reconstructed geometry.

# Iterate over all reconstructed geometries of the current feature.
for feature_reconstructed_geometry in feature_reconstructed_geometries:

The distance() method of the point returns the minimum distance, in radians, from the point to a reconstructed geometry. polygons_are_solid is passed as its other_geometry_is_solid argument.

min_distance_to_all_features is the distance threshold. With a threshold, the method returns None for a geometry that is further away than the threshold. Only a geometry that is nearer than the nearest one found so far is of interest.

# Get the minimum distance from point to the current reconstructed geometry.
min_distance_to_feature = point.distance(
        feature_reconstructed_geometry.get_reconstructed_geometry(),
        min_distance_to_all_features,
        other_geometry_is_solid=polygons_are_solid)

If None was returned, the current geometry is further away than min_distance_to_all_features, and is ignored.

Otherwise the current geometry is the nearest one found so far. Its feature becomes the nearest feature, and its distance becomes the new minimum distance.

# If the current geometry is nearer than all previous geometries then
# its associated feature is the nearest feature so far.
if min_distance_to_feature is not None:
    min_distance_to_all_features = min_distance_to_feature
    nearest_feature = feature

Once all the features have been tested, the script prints the nearest feature and its distance from the point, converted to kilometres. Nothing is printed if no feature was reconstructed.

if nearest_feature is not None:
    print(f'The nearest feature, to point {point.to_lat_lon()}, has feature ID {nearest_feature.get_feature_id()} '
          f'and a minimum distance of {min_distance_to_all_features * pygplates.Earth.mean_radius_in_kms:f}kms')

Advanced

To also find the nearest position on the nearest feature, set return_closest_positions to True when calculating the distance to a geometry:

nearest_point_on_nearest_feature = None

...

min_distance_to_feature_and_closest_positions = point.distance(
        feature_reconstructed_geometry.get_reconstructed_geometry(),
        min_distance_to_all_features,
        other_geometry_is_solid=polygons_are_solid,
        return_closest_positions=True)

When return_closest_positions is True, the distance() method returns a 3-tuple: the distance, the closest point on the geometry it is called on, and the closest point on the other geometry. It still returns None if the distance is greater than the threshold. The closest point on a polygon is always on its outline, even when the polygon is filled (polygons_are_solid = True) and the point is inside it, at a distance of zero.

Otherwise the tuple can be unpacked into its three elements.

if min_distance_to_feature_and_closest_positions is not None:
    min_distance_to_all_features, _, nearest_point_on_nearest_feature = min_distance_to_feature_and_closest_positions
    nearest_feature = feature

Here _ is just a placeholder for the second element of the tuple, which is ignored. It is the closest point on the test point, which is the test point itself. Only the closest point on the geometry of the feature is of interest.
