Query the triangulation and rigid blocks of deforming networks

This example looks inside resolved deforming networks: at the triangulation that deforms each network, and at the rigid blocks inside it.

A deforming network, resolved at a geological time, has a boundary polygon, any number of interior rigid blocks, and a triangulation. The vertices of the triangulation are the points of the boundary, of the rigid blocks and of any other interior geometries, and each moves with the feature it comes from.

The network deforms as its vertices move together or apart, and the strain rate of each triangle is calculated from the velocities of its three vertices.

The first example lists the rigid blocks, vertices and triangles of each network. The second finds the triangle that contains a point, and compares the strain rate of that triangle with the strain rate at the point.

Data files

Both scripts read the same files:

topologies.gpml

Deforming network features, and the features that their boundaries and interiors are built from. Topological plate polygon features can be in the file too. There must be networks at 10Ma, since the second script chooses its points from them. Leave out inactive networks, such as those in Zahirovic_etal_2022_Deforming_Networks_Inactive.gpml in the GPlates sample data, so that the points are chosen from networks that are deforming.

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the features that the deforming networks are built from, since those are what move the vertices of each triangulation.

Files of these kinds are in the GPlates sample data.

List the rigid blocks, vertices and triangles of each network

Sample code

import pygplates


# Create a topological model from our topological features (plate polygons and deforming networks) and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Get a snapshot of our resolved topologies at 10Ma.
time = 10
topological_snapshot = topological_model.topological_snapshot(time)

# Get the resolved deforming networks (and not the resolved rigid plates).
resolved_networks = topological_snapshot.get_resolved_topologies(pygplates.ResolveTopologyType.network)

for resolved_network in resolved_networks:

    network_feature = resolved_network.get_feature()
    print(f'Network {network_feature.get_reconstruction_plate_id()} ({network_feature.get_name()}) at {time}Ma:')

    # The interior rigid blocks of the network. This is an empty list if the network has none.
    for rigid_block in resolved_network.get_rigid_blocks():
        rigid_block_feature = rigid_block.get_feature()
        # The outline of the rigid block at 10Ma, which is a polygon.
        rigid_block_polygon = rigid_block.get_reconstructed_geometry()
        rigid_block_area_in_sq_kms = rigid_block_polygon.get_area() * pygplates.Earth.mean_radius_in_kms ** 2
        print(f'  Rigid block "{rigid_block_feature.get_name()}" moves with plate '
              f'{rigid_block_feature.get_reconstruction_plate_id()} and has area {rigid_block_area_in_sq_kms:.0f} km^2')

    # The triangulation of the network, and its vertices and triangles.
    network_triangulation = resolved_network.get_network_triangulation()
    vertices = network_triangulation.get_vertices()
    triangles = network_triangulation.get_triangles()

    # The position and speed of each vertex.
    # Each vertex is also mapped to its index, so that a triangle can refer to its vertices by index (below).
    vertex_indices = {}
    vertex_lat_lons = []
    vertex_speeds = []
    for vertex_index, vertex in enumerate(vertices):
        vertex_indices[vertex] = vertex_index
        vertex_lat_lons.append(vertex.position.to_lat_lon())
        # The velocity of the vertex is a vector (in cms/yr here), and the speed is its magnitude.
        vertex_velocity = vertex.get_velocity(velocity_units=pygplates.VelocityUnits.cms_per_yr)
        vertex_speeds.append(vertex_velocity.get_magnitude())

    # The vertices (as indices into the vertex lists) and the strain rate of each triangle in the deforming region.
    triangle_vertex_indices = []
    triangle_strain_rates = []
    for triangle in triangles:

        # Skip triangles that are outside the network's boundary, or inside one of its rigid blocks.
        if not triangle.is_in_deforming_region:
            continue

        triangle_vertex_indices.append(
                tuple(vertex_indices[triangle.get_vertex(index)] for index in range(3)))
        # The strain rate is constant across the triangle.
        triangle_strain_rates.append(triangle.strain_rate)

    print(f'  {len(vertices)} vertices:')
    for vertex_index, (latitude, longitude) in enumerate(vertex_lat_lons):
        print(f'    Vertex {vertex_index} at ({latitude:.2f}, {longitude:.2f}) has speed {vertex_speeds[vertex_index]:.2f} cms/yr')

    print(f'  {len(triangles)} triangles, of which {len(triangle_vertex_indices)} are in the deforming region:')
    for vertex_index_triple, triangle_strain_rate in zip(triangle_vertex_indices, triangle_strain_rates):
        print(f'    Triangle with vertices {vertex_index_triple} has dilatation rate '
              f'{triangle_strain_rate.get_dilatation_rate():.3e} 1/s and total strain rate '
              f'{triangle_strain_rate.get_total_strain_rate():.3e} 1/s')

Details

A topological model is created from the topological features and the rotation file.

# Create a topological model from our topological features (plate polygons and deforming networks) and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The topological features are resolved at 10Ma using pygplates.TopologicalModel.topological_snapshot().

# Get a snapshot of our resolved topologies at 10Ma.
time = 10
topological_snapshot = topological_model.topological_snapshot(time)

pygplates.TopologicalSnapshot.get_resolved_topologies() returns the resolved topologies of the types it is asked for.

With pygplates.ResolveTopologyType.network those are the deforming networks only, each a pygplates.ResolvedTopologicalNetwork.

# Get the resolved deforming networks (and not the resolved rigid plates).
resolved_networks = topological_snapshot.get_resolved_topologies(pygplates.ResolveTopologyType.network)

The plate ID and name of each network are read from its feature (pygplates.ResolvedTopologicalNetwork.get_feature()).

network_feature = resolved_network.get_feature()
print(f'Network {network_feature.get_reconstruction_plate_id()} ({network_feature.get_name()}) at {time}Ma:')

pygplates.ResolvedTopologicalNetwork.get_rigid_blocks() returns the interior rigid blocks of the network, as a list of pygplates.ReconstructedFeatureGeometry. The list is empty if the network has none.

A rigid block is a polygon feature inside the network that does not deform. It moves as one piece, with the reconstruction plate ID of its feature.

Its reconstructed geometry is its outline at 10Ma, which is a pygplates.PolygonOnSphere.

pygplates.PolygonOnSphere.get_area() returns an area on a sphere of unit radius, so it is multiplied by the square of the Earth’s radius to get square kilometres.

# The interior rigid blocks of the network. This is an empty list if the network has none.
for rigid_block in resolved_network.get_rigid_blocks():
    rigid_block_feature = rigid_block.get_feature()
    # The outline of the rigid block at 10Ma, which is a polygon.
    rigid_block_polygon = rigid_block.get_reconstructed_geometry()
    rigid_block_area_in_sq_kms = rigid_block_polygon.get_area() * pygplates.Earth.mean_radius_in_kms ** 2
    print(f'  Rigid block "{rigid_block_feature.get_name()}" moves with plate '
          f'{rigid_block_feature.get_reconstruction_plate_id()} and has area {rigid_block_area_in_sq_kms:.0f} km^2')

pygplates.ResolvedTopologicalNetwork.get_network_triangulation() returns the triangulation of the network, a pygplates.NetworkTriangulation.

Its vertices and triangles are each a read-only sequence: it has a length, and it can be iterated over and indexed.

# The triangulation of the network, and its vertices and triangles.
network_triangulation = resolved_network.get_network_triangulation()
vertices = network_triangulation.get_vertices()
triangles = network_triangulation.get_triangles()

Each vertex is a pygplates.NetworkTriangulation.Vertex. Its position is a pygplates.PointOnSphere. Its velocity is a pygplates.Vector3D, in kilometres per million years unless the velocity_units argument says otherwise. It is the velocity of the feature that the vertex comes from. (A vertex where two sections of the boundary meet comes from two features, and has the average of their velocities.)

A vertex can be used as a key in a dictionary. Here a dictionary maps each vertex to its index in the sequence of vertices, which the triangles need below.

# The position and speed of each vertex.
# Each vertex is also mapped to its index, so that a triangle can refer to its vertices by index (below).
vertex_indices = {}
vertex_lat_lons = []
vertex_speeds = []
for vertex_index, vertex in enumerate(vertices):
    vertex_indices[vertex] = vertex_index
    vertex_lat_lons.append(vertex.position.to_lat_lon())
    # The velocity of the vertex is a vector (in cms/yr here), and the speed is its magnitude.
    vertex_velocity = vertex.get_velocity(velocity_units=pygplates.VelocityUnits.cms_per_yr)
    vertex_speeds.append(vertex_velocity.get_magnitude())

Each triangle is a pygplates.NetworkTriangulation.Triangle. Two more lists are filled from the triangles.

# The vertices (as indices into the vertex lists) and the strain rate of each triangle in the deforming region.
triangle_vertex_indices = []
triangle_strain_rates = []
for triangle in triangles:

Not every triangle is part of the deforming region of the network.

The triangulation covers the convex hull of its vertices, so where the boundary of the network is concave there are triangles outside the boundary. There are also triangles inside each rigid block.

pygplates.NetworkTriangulation.Triangle.is_in_deforming_region is False for those, and their strain rate is zero. They are skipped.

# Skip triangles that are outside the network's boundary, or inside one of its rigid blocks.
if not triangle.is_in_deforming_region:
    continue

pygplates.NetworkTriangulation.Triangle.get_vertex() returns one of the three vertices of a triangle, given an index of 0, 1 or 2. The dictionary turns each vertex into its index.

The strain rate of a triangle is a pygplates.StrainRate. It is the same everywhere in the triangle.

triangle_vertex_indices.append(
        tuple(vertex_indices[triangle.get_vertex(index)] for index in range(3)))
# The strain rate is constant across the triangle.
triangle_strain_rates.append(triangle.strain_rate)

The script now has the triangulation as three lists: the positions of the vertices, the three vertex indices of each triangle, and a value (the strain rate) for each triangle.

That is the form in which plotting libraries usually take a triangular mesh. Here the lists are only printed.

print(f'  {len(vertices)} vertices:')
for vertex_index, (latitude, longitude) in enumerate(vertex_lat_lons):
    print(f'    Vertex {vertex_index} at ({latitude:.2f}, {longitude:.2f}) has speed {vertex_speeds[vertex_index]:.2f} cms/yr')

print(f'  {len(triangles)} triangles, of which {len(triangle_vertex_indices)} are in the deforming region:')
for vertex_index_triple, triangle_strain_rate in zip(triangle_vertex_indices, triangle_strain_rates):
    print(f'    Triangle with vertices {vertex_index_triple} has dilatation rate '
          f'{triangle_strain_rate.get_dilatation_rate():.3e} 1/s and total strain rate '
          f'{triangle_strain_rate.get_total_strain_rate():.3e} 1/s')

Note

A vertex also has a strain rate, which is an average of the strain rates of the deforming triangles around it, and it can list the vertices and triangles that it is joined to.

Find the triangle that contains a point

This example finds where points are in the networks at 10Ma. For a point in the deforming region of a network it finds the triangle that contains the point, and for a point in a rigid block it finds the block. It chooses four points in the deforming regions, and one in a rigid block if there is one, to run with.

Sample code

import sys
import pygplates


# Create a topological model from our topological features (plate polygons and deforming networks) and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Get a snapshot of our resolved topologies at 10Ma.
time = 10
topological_snapshot = topological_model.topological_snapshot(time)

# The points to locate are chosen from a coarse grid of points, 10 degrees apart,
# from latitude 60 to -60 (north to south).
# Each is the (latitude, longitude) of a point at 10Ma.
grid_points = [(latitude, longitude) for latitude in range(60, -70, -10) for longitude in range(-180, 180, 10)]

# Find the resolved plate (or deforming network) that contains each point.
grid_point_locations = topological_snapshot.get_point_locations(grid_points)

# Keep the points in the deforming region of a network, each with its location,
# and take the first four of them, so that the output stays short.
points_and_locations = [(point, point_location) for point, point_location in zip(grid_points, grid_point_locations)
                        if point_location.located_in_resolved_network_deforming_region()][:4]

# Stop if there are none: there are no deforming networks at 10Ma, or they are too small for the grid.
if not points_and_locations:
    sys.exit(f'No grid point is in the deforming region of a network at {time}Ma')

# Also take the first point in a rigid block of a network, if there is one.
points_and_locations += [(point, point_location) for point, point_location in zip(grid_points, grid_point_locations)
                         if point_location.located_in_resolved_network_rigid_block()][:1]

for point, point_location in points_and_locations:

    # See if the point is in an interior rigid block of a deforming network.
    network_and_rigid_block = point_location.located_in_resolved_network_rigid_block()
    if network_and_rigid_block:
        resolved_network, rigid_block = network_and_rigid_block
        print(f'{point} is in a rigid block of network "{resolved_network.get_feature().get_name()}" '
              f'that moves with plate {rigid_block.get_feature().get_reconstruction_plate_id()}')
        continue

    # Otherwise the point is in the deforming region of a network, since the points were chosen that way.
    # Get the network, and the triangle (of the network's triangulation) that contains the point.
    resolved_network, triangle = point_location.located_in_resolved_network_deforming_region(
            return_network_triangle=True)

    # The positions of the three vertices of the triangle.
    triangle_lat_lons = [triangle.get_vertex(index).position.to_lat_lon() for index in range(3)]

    # The strain rate of the triangle, which is constant across the triangle.
    triangle_strain_rate = triangle.strain_rate
    # The strain rate at the point itself. By default this is smoothed, so it can differ from that of the triangle.
    point_strain_rate = resolved_network.get_point_strain_rate(point)

    # The strain rates of the triangles that share an edge with the triangle and are in the deforming region.
    adjacent_triangle_strain_rates = []
    for index in range(3):
        # The adjacent triangle opposite the vertex at 'index' (None if the triangulation ends at that edge).
        adjacent_triangle = triangle.get_adjacent_triangle(index)
        if adjacent_triangle and adjacent_triangle.is_in_deforming_region:
            adjacent_triangle_strain_rates.append(adjacent_triangle.strain_rate)

    print(f'{point} is in the deforming region of network "{resolved_network.get_feature().get_name()}":')
    print('  it is in the triangle with vertices at ' +
          ', '.join(f'({latitude:.2f}, {longitude:.2f})' for latitude, longitude in triangle_lat_lons))
    print(f'  total strain rate at the point: {point_strain_rate.get_total_strain_rate():.3e} 1/s')
    print(f'  total strain rate of the triangle: {triangle_strain_rate.get_total_strain_rate():.3e} 1/s')
    print('  total strain rates of the adjacent triangles: ' +
          ', '.join(f'{strain_rate.get_total_strain_rate():.3e}' for strain_rate in adjacent_triangle_strain_rates) + ' 1/s')

Details

The topological model and the snapshot at 10Ma are the same as in the first example.

The points are chosen from the networks, rather than written into the script, so that the example works with any topological features that have deforming networks at 10Ma. They are chosen from a coarse grid of points, 10 degrees apart, from latitude 60 to -60. It stops at 60 degrees because, in the GPlates sample data, the grid points nearer the poles happen to fall where the networks barely deform at 10Ma, so they would make poor examples. The grid is scanned from north to south, and the first points found are used.

The points are given as (latitude, longitude) tuples. They are positions at 10Ma, since they are located in the topologies resolved at that time.

# Create a topological model from our topological features (plate polygons and deforming networks) and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Get a snapshot of our resolved topologies at 10Ma.
time = 10
topological_snapshot = topological_model.topological_snapshot(time)

# The points to locate are chosen from a coarse grid of points, 10 degrees apart,
# from latitude 60 to -60 (north to south).
# Each is the (latitude, longitude) of a point at 10Ma.
grid_points = [(latitude, longitude) for latitude in range(60, -70, -10) for longitude in range(-180, 180, 10)]

pygplates.TopologicalSnapshot.get_point_locations() returns the location of each point in the resolved topologies, in the order of the points.

# Find the resolved plate (or deforming network) that contains each point.
grid_point_locations = topological_snapshot.get_point_locations(grid_points)

The grid points in the deforming region of a network, which pygplates.TopologyPointLocation.located_in_resolved_network_deforming_region() finds (see below), are kept with their locations, and the first four of them are taken. If there are none, the script stops with an error message that says so.

The first grid point in a rigid block of a network, which pygplates.TopologyPointLocation.located_in_resolved_network_rigid_block() finds (see below), is taken too, if there is one.

# Keep the points in the deforming region of a network, each with its location,
# and take the first four of them, so that the output stays short.
points_and_locations = [(point, point_location) for point, point_location in zip(grid_points, grid_point_locations)
                        if point_location.located_in_resolved_network_deforming_region()][:4]

# Stop if there are none: there are no deforming networks at 10Ma, or they are too small for the grid.
if not points_and_locations:
    sys.exit(f'No grid point is in the deforming region of a network at {time}Ma')

# Also take the first point in a rigid block of a network, if there is one.
points_and_locations += [(point, point_location) for point, point_location in zip(grid_points, grid_point_locations)
                         if point_location.located_in_resolved_network_rigid_block()][:1]

So each point is in a network, and a point in a network is either in one of its rigid blocks or in its deforming region.

For a point in a rigid block, pygplates.TopologyPointLocation.located_in_resolved_network_rigid_block() returns a 2-tuple: the resolved network, and the rigid block (one of those that pygplates.ResolvedTopologicalNetwork.get_rigid_blocks() returns). For any other point it returns None.

# See if the point is in an interior rigid block of a deforming network.
network_and_rigid_block = point_location.located_in_resolved_network_rigid_block()
if network_and_rigid_block:
    resolved_network, rigid_block = network_and_rigid_block
    print(f'{point} is in a rigid block of network "{resolved_network.get_feature().get_name()}" '
          f'that moves with plate {rigid_block.get_feature().get_reconstruction_plate_id()}')
    continue

For a point in the deforming region of a network, pygplates.TopologyPointLocation.located_in_resolved_network_deforming_region() returns the resolved network.

With return_network_triangle set to True it returns a 2-tuple instead: the resolved network, and the triangle of its triangulation that contains the point.

Either way it returns None for a point that is not in the deforming region of a network. The script does not test for that: a point here that is not in a rigid block is in a deforming region, since that is how the points were chosen.

# Otherwise the point is in the deforming region of a network, since the points were chosen that way.
# Get the network, and the triangle (of the network's triangulation) that contains the point.
resolved_network, triangle = point_location.located_in_resolved_network_deforming_region(
        return_network_triangle=True)

The positions of the three vertices of the triangle are converted to (latitude, longitude) tuples.

# The positions of the three vertices of the triangle.
triangle_lat_lons = [triangle.get_vertex(index).position.to_lat_lon() for index in range(3)]

The strain rate of the triangle is compared with the strain rate at the point, which pygplates.ResolvedTopologicalNetwork.get_point_strain_rate() returns.

The two usually differ. By default the strain rate at a point is smoothed: it is interpolated from the strain rates of the vertices near the point, each of which is an average over the triangles around that vertex. So it varies from place to place within a triangle.

Without smoothing, the strain rate at a point is the strain rate of the triangle that contains it (see Clamp and smooth strain rates, and set rift parameters).

# The strain rate of the triangle, which is constant across the triangle.
triangle_strain_rate = triangle.strain_rate
# The strain rate at the point itself. By default this is smoothed, so it can differ from that of the triangle.
point_strain_rate = resolved_network.get_point_strain_rate(point)

pygplates.NetworkTriangulation.Triangle.get_adjacent_triangle() returns the triangle on the other side of one edge: the edge opposite the vertex at the given index.

It returns None if there is no triangle there, which happens at the outer edge of the triangulation.

The neighbours that are not in the deforming region are left out.

# The strain rates of the triangles that share an edge with the triangle and are in the deforming region.
adjacent_triangle_strain_rates = []
for index in range(3):
    # The adjacent triangle opposite the vertex at 'index' (None if the triangulation ends at that edge).
    adjacent_triangle = triangle.get_adjacent_triangle(index)
    if adjacent_triangle and adjacent_triangle.is_in_deforming_region:
        adjacent_triangle_strain_rates.append(adjacent_triangle.strain_rate)

Finally the vertices of the triangle are printed, with the three kinds of strain rate.

print(f'{point} is in the deforming region of network "{resolved_network.get_feature().get_name()}":')
print('  it is in the triangle with vertices at ' +
      ', '.join(f'({latitude:.2f}, {longitude:.2f})' for latitude, longitude in triangle_lat_lons))
print(f'  total strain rate at the point: {point_strain_rate.get_total_strain_rate():.3e} 1/s')
print(f'  total strain rate of the triangle: {triangle_strain_rate.get_total_strain_rate():.3e} 1/s')
print('  total strain rates of the adjacent triangles: ' +
      ', '.join(f'{strain_rate.get_total_strain_rate():.3e}' for strain_rate in adjacent_triangle_strain_rates) + ' 1/s')

Note

The triangle that contains a point is found in a flat map projection of the network, where the edges of the triangles are not quite where they are on the globe. So a point near an edge can be given the triangle on the other side of that edge. For the same reason, a point in the deforming region is occasionally given a triangle whose pygplates.NetworkTriangulation.Triangle.is_in_deforming_region is False. The strain rate of such a triangle is zero, while the smoothed strain rate at the point need not be. See pygplates.TopologyPointLocation.located_in_resolved_network_deforming_region().
