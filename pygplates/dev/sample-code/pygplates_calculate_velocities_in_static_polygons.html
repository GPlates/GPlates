Calculate velocities in static polygons

This example calculates velocities of plates at static point locations using static polygons, for a plate model that has no topologies.

Static polygons are regular features with polygon geometries, each with the reconstruction plate ID of the plate it is part of. At each time they are reconstructed, and pygplates.ReconstructSnapshot.get_point_velocities() calculates the velocity at each point from the reconstructed polygon that contains it: the velocity of that polygon’s plate ID at the point.

Unlike the resolved topological plates in Calculate velocities in dynamic plates, static polygons keep their present day shapes. Reconstructed to a past time they move apart, leaving gaps, and over each other. So a point can be outside all of them, or inside more than one.

The first example calculates the velocities, and groups them by plate. The second finds only which polygon contains each point, and counts the points in gaps and in overlaps.

Data files

Both scripts read the same files:

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the static polygons, since the velocity of a polygon comes from the motion of its plate ID.

static_polygons.gpml

Static polygon features, each with a reconstruction plate ID and a valid time period. A polygon without a plate ID is given plate ID zero. Features with other geometry types can be in the file, but only polygons can contain points.

lat_lon_velocity_domain_9_18.gpml

The velocity domain: features whose geometries contain the static points at which velocities are calculated. Any geometry type will do, since only its points are used. Such a file can be generated in GPlates using the menu Features > Generate Velocity Domain Points.

Rotation files and static polygons are in the GPlates sample data.

Calculate velocities of static polygons at static points

Sample code

import pygplates


# Create a reconstruct model from the static polygon features and rotation file(s).
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', 'rotations.rot')

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    print(f'Time: {time}')

    # Get a snapshot of our static polygons reconstructed to the current 'time'.
    reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

    # Calculate a velocity at each domain point, from 'time + delta_time' to 'time',
    # and find the reconstructed static polygon that contains each domain point.
    # Both lists are in the same order as the domain points.
    domain_velocity_vectors, domain_point_locations = reconstruct_snapshot.get_point_velocities(
            domain_points,
            velocity_delta_time=delta_time,
            return_point_locations=True)

    # The domain points on each plate, and their velocity vectors.
    # Each is a dictionary mapping a plate ID to a list.
    points_on_plates = {}
    velocity_vectors_on_plates = {}

    for point_index, domain_point in enumerate(domain_points):
        domain_velocity_vector = domain_velocity_vectors[point_index]
        reconstructed_static_polygon = domain_point_locations[point_index]

        if reconstructed_static_polygon is None:
            # The point is outside all the reconstructed static polygons, so it has no velocity.
            continue

        # The plate that the point is on is the reconstruction plate ID of the static polygon containing it.
        plate_id = reconstructed_static_polygon.get_feature().get_reconstruction_plate_id()

        # Add the point, and its velocity, to those of its plate.
        if plate_id not in points_on_plates:
            points_on_plates[plate_id] = []
            velocity_vectors_on_plates[plate_id] = []
        points_on_plates[plate_id].append(domain_point)
        velocity_vectors_on_plates[plate_id].append(domain_velocity_vector)

    # All (magnitude, azimuth, inclination) velocities for the current time, grouped by plate ID.
    velocities_on_plates = {}

    for plate_id, points_on_plate in points_on_plates.items():

        # Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
        velocities_on_plates[plate_id] = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
                points_on_plate,
                velocity_vectors_on_plates[plate_id])

        # The mean speed (velocity magnitude) of the points on the plate.
        mean_speed = sum(magnitude for magnitude, azimuth, inclination in velocities_on_plates[plate_id]) / len(points_on_plate)
        print(f'  Plate {plate_id}: {len(points_on_plate)} points, mean speed {mean_speed:.1f} km/My')

Details

A reconstruct model is created from the static polygon features and the rotation file.

The static polygons are not reconstructed here. That happens at each time, in the loop below.

# Create a reconstruct model from the static polygon features and rotation file(s).
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', 'rotations.rot')

The velocity domain features contain the static points at which velocities are calculated.

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

The points of all the velocity domain features are gathered into one list.

A velocity domain feature usually has a single geometry, but pygplates.Feature.get_geometries() handles any number, and pygplates.GeometryOnSphere.get_points() reduces each geometry to its points.

The points are not reconstructed. They stay where they are while the polygons move over them, so the same list is used at every time.

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

The velocities at each time are calculated over a 1My interval, from time + delta_time to time.

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

The static polygons are reconstructed to the current time using pygplates.ReconstructModel.reconstruct_snapshot().

A polygon that does not exist at that time (according to its valid time period) is not reconstructed, so it contains no points.

# Get a snapshot of our static polygons reconstructed to the current 'time'.
reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

pygplates.ReconstructSnapshot.get_point_velocities() returns one velocity for each point, in the order of the points. Each is a pygplates.Vector3D (a global cartesian velocity vector), in kilometres per million years unless the velocity_units argument says otherwise.

With return_point_locations set to True it returns a 2-tuple: the list of velocities, and a list with the reconstructed static polygon that contains each point. This is more efficient than getting the polygons in a separate call to pygplates.ReconstructSnapshot.get_point_locations().

Where reconstructed polygons overlap, a point inside more than one gets the first that is found. By default they are searched from the highest plate ID to the lowest, so that the result does not depend on the order of the features in the file (the second example searches another way).

# Calculate a velocity at each domain point, from 'time + delta_time' to 'time',
# and find the reconstructed static polygon that contains each domain point.
# Both lists are in the same order as the domain points.
domain_velocity_vectors, domain_point_locations = reconstruct_snapshot.get_point_velocities(
        domain_points,
        velocity_delta_time=delta_time,
        return_point_locations=True)

Each point is visited with its velocity and the polygon that contains it.

for point_index, domain_point in enumerate(domain_points):
    domain_velocity_vector = domain_velocity_vectors[point_index]
    reconstructed_static_polygon = domain_point_locations[point_index]

A point that is outside all the reconstructed static polygons has no polygon and no velocity: both of its entries are None. It is skipped.

if reconstructed_static_polygon is None:
    # The point is outside all the reconstructed static polygons, so it has no velocity.
    continue

The plate that the point is on is read from the feature of the polygon (pygplates.ReconstructedFeatureGeometry.get_feature()). It is this reconstruction plate ID whose motion gave the point its velocity.

# The plate that the point is on is the reconstruction plate ID of the static polygon containing it.
plate_id = reconstructed_static_polygon.get_feature().get_reconstruction_plate_id()

The point and its velocity are appended to the lists of its plate.

The lists are kept in two dictionaries whose keys are plate IDs. A plate is usually made of many static polygons, all with its plate ID and all moving together, so the points are grouped by plate rather than by polygon.

# Add the point, and its velocity, to those of its plate.
if plate_id not in points_on_plates:
    points_on_plates[plate_id] = []
    velocity_vectors_on_plates[plate_id] = []
points_on_plates[plate_id].append(domain_point)
velocity_vectors_on_plates[plate_id].append(domain_velocity_vector)

Iterating over a dictionary visits each plate that has a point on it once.

for plate_id, points_on_plate in points_on_plates.items():

The vectors are converted to local (magnitude, azimuth, inclination) tuples, one per point, using pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination().

Each point determines its own local coordinate system. For example, the velocity azimuth is relative to North as viewed from that point.

No point here is without a velocity, since the points outside all the polygons were skipped. The conversion raises TypeError if it is given None in place of a vector.

# Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
velocities_on_plates[plate_id] = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
        points_on_plate,
        velocity_vectors_on_plates[plate_id])

Finally the number of points on the plate is printed with their mean speed, which is the mean of the velocity magnitudes.

# The mean speed (velocity magnitude) of the points on the plate.
mean_speed = sum(magnitude for magnitude, azimuth, inclination in velocities_on_plates[plate_id]) / len(points_on_plate)
print(f'  Plate {plate_id}: {len(points_on_plate)} points, mean speed {mean_speed:.1f} km/My')

Find the static polygon containing each static point

This example finds the reconstructed static polygon that contains each point, without calculating velocities. At each time it counts the points that are in a gap between the polygons, and the points that are inside more than one polygon, where the polygon found depends on the order of the search.

Sample code

import pygplates


# Create a reconstruct model from the static polygon features and rotation file(s).
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', 'rotations.rot')

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    # Get a snapshot of our static polygons reconstructed to the current 'time'.
    reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

    # Find the reconstructed static polygon that contains each domain point (None if no polygon does).
    # Where reconstructed polygons overlap, this finds the one with the highest plate ID.
    domain_point_locations = reconstruct_snapshot.get_point_locations(domain_points)

    # Do the same but, where reconstructed polygons overlap, find the one with the largest area.
    domain_point_locations_by_area = reconstruct_snapshot.get_point_locations(
            domain_points,
            sort_reconstructed_static_polygons=pygplates.SortReconstructedStaticPolygons.by_plate_area)

    # The reconstructed static polygons themselves (of the static polygon features that exist at 'time').
    reconstructed_static_polygons = reconstruct_snapshot.get_reconstructed_geometries()

    # Count the points that no polygon contains, the points that more than one polygon contains, and of
    # those, the points for which the two searches find different polygons.
    num_points_outside_polygons = 0
    num_points_in_overlapping_polygons = 0
    num_points_depending_on_search_order = 0
    for domain_point, reconstructed_static_polygon, reconstructed_static_polygon_by_area in zip(
            domain_points, domain_point_locations, domain_point_locations_by_area):

        if reconstructed_static_polygon is None:
            num_points_outside_polygons += 1
            continue

        # The number of reconstructed polygons that contain the point.
        num_containing_polygons = 0
        for reconstructed_polygon in reconstructed_static_polygons:
            polygon = reconstructed_polygon.get_reconstructed_geometry()
            if isinstance(polygon, pygplates.PolygonOnSphere) and polygon.is_point_in_polygon(domain_point):
                num_containing_polygons += 1

        if num_containing_polygons > 1:
            num_points_in_overlapping_polygons += 1
            if reconstructed_static_polygon != reconstructed_static_polygon_by_area:
                num_points_depending_on_search_order += 1

    print(f'Time {time}: of {len(domain_points)} points, {num_points_outside_polygons} are outside all polygons '
          f'and {num_points_in_overlapping_polygons} are inside more than one '
          f'({num_points_depending_on_search_order} of them in a different polygon when searched by area)')

Details

The reconstruct model and the static points are the same as in the first example.

# Create a reconstruct model from the static polygon features and rotation file(s).
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', 'rotations.rot')

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

pygplates.ReconstructSnapshot.get_point_locations() returns the reconstructed static polygon that contains each point, in the order of the points. The entry of a point that is outside all the polygons is None.

Where reconstructed polygons overlap, it returns the first that is found, searching from the highest plate ID to the lowest.

# Find the reconstructed static polygon that contains each domain point (None if no polygon does).
# Where reconstructed polygons overlap, this finds the one with the highest plate ID.
domain_point_locations = reconstruct_snapshot.get_point_locations(domain_points)

The sort_reconstructed_static_polygons argument changes the order of the search (see pygplates.SortReconstructedStaticPolygons). Here the polygons are searched from the largest area to the smallest.

pygplates.ReconstructSnapshot.get_point_velocities() accepts the same argument.

# Do the same but, where reconstructed polygons overlap, find the one with the largest area.
domain_point_locations_by_area = reconstruct_snapshot.get_point_locations(
        domain_points,
        sort_reconstructed_static_polygons=pygplates.SortReconstructedStaticPolygons.by_plate_area)

A point with no polygon is in a gap between the reconstructed polygons.

pygplates.ReconstructSnapshot.get_point_locations() finds only one polygon for each point, so it can’t tell whether a point is inside more than one. To count those points, the script tests each point against every reconstructed polygon itself, with pygplates.PolygonOnSphere.is_point_in_polygon().

# The reconstructed static polygons themselves (of the static polygon features that exist at 'time').
reconstructed_static_polygons = reconstruct_snapshot.get_reconstructed_geometries()

For a point inside more than one polygon, the polygon found (and so its plate ID and its velocity) depends on the order of the search. Of those points, the script also counts the ones for which the two searches find different polygons. For the others, both searches happen to find the same one.

A point on the boundary between two polygons is inside both, so points also count as inside more than one where polygons only share a boundary, as static polygons do at present day.

# Count the points that no polygon contains, the points that more than one polygon contains, and of
# those, the points for which the two searches find different polygons.
num_points_outside_polygons = 0
num_points_in_overlapping_polygons = 0
num_points_depending_on_search_order = 0
for domain_point, reconstructed_static_polygon, reconstructed_static_polygon_by_area in zip(
        domain_points, domain_point_locations, domain_point_locations_by_area):

    if reconstructed_static_polygon is None:
        num_points_outside_polygons += 1
        continue

    # The number of reconstructed polygons that contain the point.
    num_containing_polygons = 0
    for reconstructed_polygon in reconstructed_static_polygons:
        polygon = reconstructed_polygon.get_reconstructed_geometry()
        if isinstance(polygon, pygplates.PolygonOnSphere) and polygon.is_point_in_polygon(domain_point):
            num_containing_polygons += 1

    if num_containing_polygons > 1:
        num_points_in_overlapping_polygons += 1
        if reconstructed_static_polygon != reconstructed_static_polygon_by_area:
            num_points_depending_on_search_order += 1
