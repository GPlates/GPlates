Process times in parallel with multiprocessing

This example shares a calculation that is done at each of a sequence of geological times among several processes, using a multiprocessing.Pool from the Python standard library.

Many pyGPlates workflows do the same thing at one time after another, and the times do not depend on each other. They can be done at the same time by worker processes, each on its own CPU.

What the main process gives a worker process, and what the worker gives back, is pickled to send it from one process to the other. Most pyGPlates objects can be pickled, including pygplates.RotationModel, pygplates.TopologicalModel, pygplates.ReconstructModel, their snapshots, features, feature collections and geometries. In the reference, the page of a class that can be pickled says so.

Here the calculation is the total length of subduction zones, as in Find the total length of ridges and subduction zones, and the main process sends each worker process a topological model.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the features that the topologies are built from.

topologies.gpml

Topological plate polygon features, with or without deforming network features. Some of their boundary sections should be subduction zones, or every length is zero.

Files of these kinds are in the GPlates sample data.

Sample code

import multiprocessing
import pygplates


# The topological model of a worker process.
# Each worker process has its own, which 'initialise_worker()' sets when the process starts.
worker_topological_model = None


def initialise_worker(topological_model):
    """Called once in each worker process, with the topological model that the main process gave the pool."""
    global worker_topological_model
    worker_topological_model = topological_model


def find_total_subduction_zone_length(time):
    """Called in a worker process, once for each time. Returns the time and the length in kms."""

    # Resolve the topologies at 'time', in this worker process.
    topological_snapshot = worker_topological_model.topological_snapshot(time)

    # Accumulate the lengths of the subduction zones along the resolved plate boundaries.
    total_subduction_zone_length = 0
    for shared_boundary_section in topological_snapshot.get_resolved_topological_sections():
        if shared_boundary_section.get_feature().get_feature_type() == pygplates.FeatureType.gpml_subduction_zone:
            for shared_sub_segment in shared_boundary_section.get_shared_sub_segments():
                total_subduction_zone_length += shared_sub_segment.get_resolved_geometry().get_arc_length()

    # The result is sent back to the main process, so it must be something that can be pickled.
    # Numbers can, and so can geometries and features, but resolved topologies cannot.
    return time, total_subduction_zone_length * pygplates.Earth.mean_radius_in_kms


# Only the main process runs the code below. A worker process imports this script to find the two
# functions above, and without this test each worker would run the code below too.
if __name__ == '__main__':

    # Create a topological model from the topological plate polygon features (can also include deforming networks)
    # and rotation file(s). This is done once, in the main process.
    topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

    # Our geological times will be from 0Ma to 20Ma in 1 My intervals.
    times = range(0, 21)

    # Start two worker processes (leave out 'processes' to start one for each CPU).
    # The topological model is pickled and sent to each worker process, which passes it to 'initialise_worker()'.
    with multiprocessing.Pool(
            processes=2,
            initializer=initialise_worker,
            initargs=(topological_model,)) as pool:

        # Share the times among the worker processes, and gather their results in the order of the times.
        results = pool.map(find_total_subduction_zone_length, times)

    for time, total_subduction_zone_length_in_kms in results:
        print(f'At time {time}Ma, total subduction zone length is {total_subduction_zone_length_in_kms:f} kms.')

Details

The code that runs in the worker processes is in functions defined at the top level of the script. A worker process finds a function by importing the script and looking up the function’s name, so a function defined inside another function, or a lambda, will not do.

Each worker process keeps its own topological model in a global variable. initialise_worker() is called once in each worker process, when it starts, and sets it.

# The topological model of a worker process.
# Each worker process has its own, which 'initialise_worker()' sets when the process starts.
worker_topological_model = None


def initialise_worker(topological_model):
    """Called once in each worker process, with the topological model that the main process gave the pool."""
    global worker_topological_model
    worker_topological_model = topological_model

find_total_subduction_zone_length() is called in a worker process, once for each time.

def find_total_subduction_zone_length(time):
    """Called in a worker process, once for each time. Returns the time and the length in kms."""

    # Resolve the topologies at 'time', in this worker process.
    topological_snapshot = worker_topological_model.topological_snapshot(time)

    # Accumulate the lengths of the subduction zones along the resolved plate boundaries.
    total_subduction_zone_length = 0
    for shared_boundary_section in topological_snapshot.get_resolved_topological_sections():
        if shared_boundary_section.get_feature().get_feature_type() == pygplates.FeatureType.gpml_subduction_zone:
            for shared_sub_segment in shared_boundary_section.get_shared_sub_segments():
                total_subduction_zone_length += shared_sub_segment.get_resolved_geometry().get_arc_length()

    # The result is sent back to the main process, so it must be something that can be pickled.
    # Numbers can, and so can geometries and features, but resolved topologies cannot.
    return time, total_subduction_zone_length * pygplates.Earth.mean_radius_in_kms

The worker process resolves the topologies itself, using its own topological model.

That is the point of giving each worker process a model: the model is sent once to each worker, and each time is then only a number. A pygplates.TopologicalSnapshot can be pickled too, but what is pickled is what it was made from (its topological features, rotations and time), not its resolved topologies, which are resolved again when it is unpickled. So sending a snapshot for each time would send every feature and rotation for each time, and resolve each time twice: once in the main process to make the snapshot, and again in the worker process.

# Resolve the topologies at 'time', in this worker process.
topological_snapshot = worker_topological_model.topological_snapshot(time)

The value that the function returns is pickled and sent back to the main process.

Numbers and strings can be pickled. So can geometries (such as a resolved boundary polygon) and features (such as a resolved feature).

The objects that hold reconstructed or resolved geometries cannot, such as pygplates.ResolvedTopologicalBoundary, pygplates.ReconstructedFeatureGeometry and the shared sub-segments used here. Returning one of them fails with an error from multiprocessing. So a worker returns what it calculated from them, not the objects themselves.

# The result is sent back to the main process, so it must be something that can be pickled.
# Numbers can, and so can geometries and features, but resolved topologies cannot.
return time, total_subduction_zone_length * pygplates.Earth.mean_radius_in_kms

The rest of the script is inside if __name__ == '__main__':, which is true only in the main process.

This matters wherever a worker process is a new Python interpreter that imports the script, as it is on Windows and macOS. Without the test each worker would itself create a model and a pool of workers.

# Only the main process runs the code below. A worker process imports this script to find the two
# functions above, and without this test each worker would run the code below too.
if __name__ == '__main__':

The topological model is created once, in the main process, from the topological features and the rotation file.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s). This is done once, in the main process.
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

A multiprocessing.Pool starts the worker processes.

Its initializer and initargs arguments are the function to call in each worker process as it starts, and the arguments to call it with. This is where the topological model is pickled and sent, once for each worker process.

Without processes the pool starts as many worker processes as the computer has CPUs. Each has a copy of the model, and resolves its own snapshots, so memory can limit how many are worth starting.

# Start two worker processes (leave out 'processes' to start one for each CPU).
# The topological model is pickled and sent to each worker process, which passes it to 'initialise_worker()'.
with multiprocessing.Pool(
        processes=2,
        initializer=initialise_worker,
        initargs=(topological_model,)) as pool:

pool.map() calls the function once for each time, in whichever worker process is free, and returns the results as a list in the order of the times.

The with statement shuts the worker processes down when it ends, so the results are gathered inside it.

# Share the times among the worker processes, and gather their results in the order of the times.
results = pool.map(find_total_subduction_zone_length, times)

Finally the main process prints the results.

for time, total_subduction_zone_length_in_kms in results:
    print(f'At time {time}Ma, total subduction zone length is {total_subduction_zone_length_in_kms:f} kms.')

Note

A worker process could instead load the files itself, in initialise_worker(). Sending the model keeps the loading in one place, and also works for a model that was not loaded from files as it is: one created from features that the main process created or modified.
