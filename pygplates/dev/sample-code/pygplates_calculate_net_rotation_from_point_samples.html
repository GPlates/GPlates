Calculate net rotation from point samples

This example calculates net rotation by adding up the contributions of sample points, where Calculate net rotation leaves that to a pygplates.NetRotationModel.

A pygplates.NetRotationModel needs a topological model, and decides for itself how each sample point moves. Adding the samples yourself is for everything else: a plate model without topologies, motions that come from somewhere other than a plate model, or a net rotation over some of the points only.

A pygplates.NetRotation is an accumulator. A new one is zero, each sample point contributes one that is created from the point, the area it stands for and its motion, and they are added together.

The first example calculates the net rotation of static polygons, giving each sample point the rotation of its plate. The second calculates net rotation from a velocity at each sample point.

Calculate net rotation of static polygons

This example calculates the net rotation of the plates of a model that has static polygons but no topologies, and the net rotation of each plate, at each time over a time period.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the static polygons.

static_polygons.gpml

Static polygon features, each with a reconstruction plate ID.

Files of these kinds are in the GPlates sample data.

Sample code

import math
import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create a reconstruct model from the static polygon features and the rotation model.
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', rotation_model)

# The points at which net rotation is sampled: a uniform latitude-longitude grid, 3 degrees apart.
# Each point has a sample area, which is the area of the globe that it stands for (in steradians).
num_samples_along_meridian = 60
sample_spacing_in_degrees = 180.0 / num_samples_along_meridian
sample_spacing_in_radians = math.radians(sample_spacing_in_degrees)
sample_points = []
sample_areas = []
for latitude_index in range(num_samples_along_meridian):
    latitude = -90.0 + (latitude_index + 0.5) * sample_spacing_in_degrees
    # The cosine is because points near the North/South poles are closer together.
    sample_area = math.cos(math.radians(latitude)) * sample_spacing_in_radians * sample_spacing_in_radians
    for longitude_index in range(2 * num_samples_along_meridian):
        longitude = -180.0 + (longitude_index + 0.5) * sample_spacing_in_degrees
        sample_points.append(pygplates.PointOnSphere(latitude, longitude))
        sample_areas.append(sample_area)

# Net rotations will be calculated over a time interval of 1My, from 'time + delta_time' to 'time'.
delta_time = 1.0

# We'll calculate net rotation from 140Ma to present day in 10 My intervals.
max_time = 140
time_increment = 10

for time in range(0, max_time + 1, time_increment):

    print(f'Time {time}:')

    # Get a snapshot of our static polygons reconstructed to the current 'time'.
    reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

    # Find the reconstructed static polygon that contains each sample point (None if no polygon does).
    reconstructed_static_polygons = reconstruct_snapshot.get_point_locations(sample_points)

    # The net rotation of all the plates, and of each plate (a dictionary mapping a plate ID to a net rotation).
    # A new net rotation is zero, and the samples are added to it.
    total_net_rotation = pygplates.NetRotation()
    plate_net_rotations = {}

    # The stage rotation of each plate (a dictionary mapping a plate ID to a rotation).
    plate_stage_rotations = {}

    for sample_index, reconstructed_static_polygon in enumerate(reconstructed_static_polygons):

        # A sample point outside all the reconstructed static polygons contributes nothing.
        if reconstructed_static_polygon is None:
            continue

        # The plate that the sample point is on, and the rotation of that plate from 'time + delta_time' to 'time'.
        plate_id = reconstructed_static_polygon.get_feature().get_reconstruction_plate_id()
        if plate_id not in plate_stage_rotations:
            plate_stage_rotations[plate_id] = rotation_model.get_rotation(time, plate_id, time + delta_time)

        # The contribution of the sample point to net rotation.
        net_rotation_sample = pygplates.NetRotation.create_sample_from_finite_rotation(
                sample_points[sample_index],
                sample_areas[sample_index],
                plate_stage_rotations[plate_id],
                delta_time)

        # Add the sample to the net rotation of all the plates, and to the net rotation of its own plate.
        total_net_rotation += net_rotation_sample
        if plate_id not in plate_net_rotations:
            plate_net_rotations[plate_id] = pygplates.NetRotation()
        plate_net_rotations[plate_id] += net_rotation_sample

    # The pole (latitude and longitude) and the rotation rate of the total net rotation.
    # The angle of the net rotation over a million years is its rate in degrees per million years.
    pole_latitude, pole_longitude, rotation_rate_in_degrees_per_myr = (
            total_net_rotation.get_finite_rotation().get_lat_lon_euler_pole_and_angle_degrees())
    print(f'  Total net rotation: {rotation_rate_in_degrees_per_myr} degrees/myr '
          f'about ({pole_latitude}, {pole_longitude})')

    for plate_id, plate_net_rotation in plate_net_rotations.items():
        # The magnitude of the rotation rate vector is the rotation rate in radians per million years.
        plate_rotation_rate_in_degrees_per_myr = math.degrees(plate_net_rotation.get_rotation_rate_vector().get_magnitude())
        # The area of the plate covered by its sample points.
        sampled_area_in_square_kms = plate_net_rotation.get_area() * pygplates.Earth.mean_radius_in_kms**2
        print(f'  Plate {plate_id} has net rotation {plate_rotation_rate_in_degrees_per_myr} degrees/myr '
              f'sampled over an area of {sampled_area_in_square_kms} square kms')

Details

The rotations are loaded into a pygplates.RotationModel, which is kept because the rotation of each plate is needed below.

A reconstruct model is created from the static polygons and the rotation model.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create a reconstruct model from the static polygon features and the rotation model.
reconstruct_model = pygplates.ReconstructModel('static_polygons.gpml', rotation_model)

Net rotation is an integral over the surface of the globe, which is approximated by a sum over sample points. Each sample point has a sample area: the area of the globe that it stands for, in steradians (square radians).

Here the points are a uniform latitude-longitude grid, which is what pygplates.NetRotationModel uses by default (at a finer spacing). On such a grid the sample area shrinks with the cosine of the latitude, because the points are closer together near the poles.

Any distribution of points will do, as long as each has its sample area. For points spread evenly over the sphere that is the same for every point: the area of the sphere divided by the number of points.

# The points at which net rotation is sampled: a uniform latitude-longitude grid, 3 degrees apart.
# Each point has a sample area, which is the area of the globe that it stands for (in steradians).
num_samples_along_meridian = 60
sample_spacing_in_degrees = 180.0 / num_samples_along_meridian
sample_spacing_in_radians = math.radians(sample_spacing_in_degrees)
sample_points = []
sample_areas = []
for latitude_index in range(num_samples_along_meridian):
    latitude = -90.0 + (latitude_index + 0.5) * sample_spacing_in_degrees
    # The cosine is because points near the North/South poles are closer together.
    sample_area = math.cos(math.radians(latitude)) * sample_spacing_in_radians * sample_spacing_in_radians
    for longitude_index in range(2 * num_samples_along_meridian):
        longitude = -180.0 + (longitude_index + 0.5) * sample_spacing_in_degrees
        sample_points.append(pygplates.PointOnSphere(latitude, longitude))
        sample_areas.append(sample_area)

The motion of each plate is taken over a 1My interval, from time + delta_time to time.

# Net rotations will be calculated over a time interval of 1My, from 'time + delta_time' to 'time'.
delta_time = 1.0

At each time the static polygons are reconstructed, and pygplates.ReconstructSnapshot.get_point_locations() finds the reconstructed static polygon that contains each sample point (see Calculate velocities in static polygons).

# Find the reconstructed static polygon that contains each sample point (None if no polygon does).
reconstructed_static_polygons = reconstruct_snapshot.get_point_locations(sample_points)

pygplates.NetRotation() creates a zero net rotation.

One accumulates the net rotation of all the plates. The others, one for each plate, are kept in a dictionary whose keys are plate IDs.

# The net rotation of all the plates, and of each plate (a dictionary mapping a plate ID to a net rotation).
# A new net rotation is zero, and the samples are added to it.
total_net_rotation = pygplates.NetRotation()
plate_net_rotations = {}

A sample point that is outside all the reconstructed static polygons is skipped. It contributes neither a rotation nor its sample area.

So the total is the net rotation of the area that the polygons cover, not of the whole globe (see the note below).

for sample_index, reconstructed_static_polygon in enumerate(reconstructed_static_polygons):

    # A sample point outside all the reconstructed static polygons contributes nothing.
    if reconstructed_static_polygon is None:
        continue

The motion of a sample point is the motion of its plate: the stage rotation of the polygon’s reconstruction plate ID from time + delta_time to time.

Many sample points are on the same plate, so the stage rotation of each plate is looked up once and kept in a dictionary.

# The plate that the sample point is on, and the rotation of that plate from 'time + delta_time' to 'time'.
plate_id = reconstructed_static_polygon.get_feature().get_reconstruction_plate_id()
if plate_id not in plate_stage_rotations:
    plate_stage_rotations[plate_id] = rotation_model.get_rotation(time, plate_id, time + delta_time)

pygplates.NetRotation.create_sample_from_finite_rotation() creates the contribution of one sample point from the point, its sample area, and the finite rotation that moves it.

The last argument is the time interval of that finite rotation (which defaults to 1My), so that the rotation can be converted to a rate.

# The contribution of the sample point to net rotation.
net_rotation_sample = pygplates.NetRotation.create_sample_from_finite_rotation(
        sample_points[sample_index],
        sample_areas[sample_index],
        plate_stage_rotations[plate_id],
        delta_time)

Net rotations are added with += (or with +, which returns a new net rotation).

The same sample is added to the net rotation of all the plates and to the net rotation of its own plate.

# Add the sample to the net rotation of all the plates, and to the net rotation of its own plate.
total_net_rotation += net_rotation_sample
if plate_id not in plate_net_rotations:
    plate_net_rotations[plate_id] = pygplates.NetRotation()
plate_net_rotations[plate_id] += net_rotation_sample

A net rotation can be extracted as a finite rotation over one million years, or as a rotation rate vector.

Here the pole and the angle of the finite rotation are printed. The angle is the rotation rate in degrees per million years.

# The pole (latitude and longitude) and the rotation rate of the total net rotation.
# The angle of the net rotation over a million years is its rate in degrees per million years.
pole_latitude, pole_longitude, rotation_rate_in_degrees_per_myr = (
        total_net_rotation.get_finite_rotation().get_lat_lon_euler_pole_and_angle_degrees())
print(f'  Total net rotation: {rotation_rate_in_degrees_per_myr} degrees/myr '
      f'about ({pole_latitude}, {pole_longitude})')

The net rotation of each plate is printed as the magnitude of its rotation rate vector, which is in radians per million years.

pygplates.NetRotation.get_area() is the sum of the sample areas that were added, so here it is the area of the plate as its sample points measure it.

for plate_id, plate_net_rotation in plate_net_rotations.items():
    # The magnitude of the rotation rate vector is the rotation rate in radians per million years.
    plate_rotation_rate_in_degrees_per_myr = math.degrees(plate_net_rotation.get_rotation_rate_vector().get_magnitude())
    # The area of the plate covered by its sample points.
    sampled_area_in_square_kms = plate_net_rotation.get_area() * pygplates.Earth.mean_radius_in_kms**2
    print(f'  Plate {plate_id} has net rotation {plate_rotation_rate_in_degrees_per_myr} degrees/myr '
          f'sampled over an area of {sampled_area_in_square_kms} square kms')

Note

A net rotation is an average over the area of its own samples. The net rotation of a plate is averaged over the area of that plate, and the total here over the area that the reconstructed polygons cover, which shrinks as gaps open between them at past times. To average over the whole globe instead, also add a sample for each point that is outside all the polygons, with a rotation of pygplates.FiniteRotation.create_identity_rotation(). It adds its sample area but no rotation, and so reduces the net rotation in proportion.

Calculate net rotation from velocities

This example calculates net rotation from a velocity at each sample point. Here the velocities come from resolved topologies, but they could come from anywhere, such as a file of velocities.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological features.

topologies.gpml

Topological plate polygon features, with or without deforming network features.

Files of these kinds are in the GPlates sample data.

Sample code

import math
import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# The points at which net rotation is sampled: a uniform latitude-longitude grid, 3 degrees apart.
# Each point has a sample area, which is the area of the globe that it stands for (in steradians).
num_samples_along_meridian = 60
sample_spacing_in_degrees = 180.0 / num_samples_along_meridian
sample_spacing_in_radians = math.radians(sample_spacing_in_degrees)
sample_points = []
sample_areas = []
for latitude_index in range(num_samples_along_meridian):
    latitude = -90.0 + (latitude_index + 0.5) * sample_spacing_in_degrees
    # The cosine is because points near the North/South poles are closer together.
    sample_area = math.cos(math.radians(latitude)) * sample_spacing_in_radians * sample_spacing_in_radians
    for longitude_index in range(2 * num_samples_along_meridian):
        longitude = -180.0 + (longitude_index + 0.5) * sample_spacing_in_degrees
        sample_points.append(pygplates.PointOnSphere(latitude, longitude))
        sample_areas.append(sample_area)

# Velocities will be calculated over a time interval of 1My, from 'time + delta_time' to 'time'.
delta_time = 1.0

# We'll calculate net rotation from 140Ma to present day in 10 My intervals.
max_time = 140
time_increment = 10

for time in range(0, max_time + 1, time_increment):

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Calculate a velocity at each sample point, in kilometres per million years.
    # A velocity is None if its point is outside all the resolved plates (and deforming networks).
    sample_velocity_vectors = topological_snapshot.get_point_velocities(
            sample_points,
            velocity_delta_time=delta_time,
            velocity_units=pygplates.VelocityUnits.kms_per_my,
            earth_radius_in_kms=pygplates.Earth.mean_radius_in_kms)

    # The net rotation of all the plates. A new net rotation is zero, and the samples are added to it.
    net_rotation = pygplates.NetRotation()

    for sample_point, sample_area, sample_velocity_vector in zip(sample_points, sample_areas, sample_velocity_vectors):

        # A sample point outside all the plates contributes nothing.
        if sample_velocity_vector is None:
            continue

        # The rotation rate vector of the sample point, with a magnitude in radians per million years.
        # This is the cross product of its position (a unit vector) and its velocity,
        # with the velocity converted from kilometres to radians (of arc) per million years.
        sample_position_vector = pygplates.Vector3D(sample_point.to_xyz())
        sample_rotation_rate_vector = (
                sample_position_vector.cross(sample_velocity_vector) * (1.0 / pygplates.Earth.mean_radius_in_kms))

        # Add the contribution of the sample point to net rotation.
        net_rotation += pygplates.NetRotation.create_sample_from_rotation_rate(
                sample_point,
                sample_area,
                sample_rotation_rate_vector)

    # The magnitude of the rotation rate vector is the rotation rate in radians per million years.
    rotation_rate_in_degrees_per_myr = math.degrees(net_rotation.get_rotation_rate_vector().get_magnitude())
    print(f'Time {time}: net rotation {rotation_rate_in_degrees_per_myr} degrees/myr')

Details

A topological model is created from the topological features and the rotation file. The sample points, their sample areas and the time interval are the same as in the first example.

# and rotation file(s).

sample_spacing_in_radians = math.radians(sample_spacing_in_degrees)
sample_points = []
sample_areas = []
for latitude_index in range(num_samples_along_meridian):
    latitude = -90.0 + (latitude_index + 0.5) * sample_spacing_in_degrees
    # The cosine is because points near the North/South poles are closer together.
    sample_area = math.cos(math.radians(latitude)) * sample_spacing_in_radians * sample_spacing_in_radians
    for longitude_index in range(2 * num_samples_along_meridian):
        longitude = -180.0 + (longitude_index + 0.5) * sample_spacing_in_degrees
        sample_points.append(pygplates.PointOnSphere(latitude, longitude))
        sample_areas.append(sample_area)

# Velocities will be calculated over a time interval of 1My, from 'time + delta_time' to 'time'.
delta_time = 1.0

At each time, pygplates.TopologicalSnapshot.get_point_velocities() calculates the velocity at each sample point from the plate or deforming network that contains it (see Calculate velocities in dynamic plates).

The units and the Earth radius are the defaults. They are spelled out because the conversion below depends on them.

# Calculate a velocity at each sample point, in kilometres per million years.
# A velocity is None if its point is outside all the resolved plates (and deforming networks).
sample_velocity_vectors = topological_snapshot.get_point_velocities(
        sample_points,
        velocity_delta_time=delta_time,
        velocity_units=pygplates.VelocityUnits.kms_per_my,
        earth_radius_in_kms=pygplates.Earth.mean_radius_in_kms)

A sample point that is outside all the plates has no velocity, and is skipped.

for sample_point, sample_area, sample_velocity_vector in zip(sample_points, sample_areas, sample_velocity_vectors):

    # A sample point outside all the plates contributes nothing.
    if sample_velocity_vector is None:
        continue

The motion of a sample point is given as a rotation rate vector: its direction is the axis that the point is rotating about, and its magnitude is the rate in radians per million years.

For a point at position \(\boldsymbol r\) (a unit vector) with velocity \(\boldsymbol v\), the vector \(\boldsymbol r \times \boldsymbol v\) is such a rotation rate, once the velocity is divided by the radius of the Earth to convert kilometres to radians.

It is not the only rotation rate that gives the point that velocity. A rotation about an axis through the point itself doesn’t move the point, so any amount of it can be added without changing the velocity. Net rotation measures how the lithosphere moves, so it uses only the part of a sample’s rotation rate that moves the point, and it doesn’t matter which of these rotation rates is given. \(\boldsymbol r \times \boldsymbol v\) is the simplest of them.

# The rotation rate vector of the sample point, with a magnitude in radians per million years.
# This is the cross product of its position (a unit vector) and its velocity,
# with the velocity converted from kilometres to radians (of arc) per million years.
sample_position_vector = pygplates.Vector3D(sample_point.to_xyz())
sample_rotation_rate_vector = (
        sample_position_vector.cross(sample_velocity_vector) * (1.0 / pygplates.Earth.mean_radius_in_kms))

pygplates.NetRotation.create_sample_from_rotation_rate() creates the contribution of one sample point from the point, its sample area and its rotation rate vector. It is added to the net rotation with +=.

# Add the contribution of the sample point to net rotation.
net_rotation += pygplates.NetRotation.create_sample_from_rotation_rate(
        sample_point,
        sample_area,
        sample_rotation_rate_vector)

The net rotation is printed as the magnitude of its rotation rate vector, converted to degrees per million years.

# The magnitude of the rotation rate vector is the rotation rate in radians per million years.
rotation_rate_in_degrees_per_myr = math.degrees(net_rotation.get_rotation_rate_vector().get_magnitude())
print(f'Time {time}: net rotation {rotation_rate_in_degrees_per_myr} degrees/myr')

Note

With the same sample points and areas (its point_distribution argument), a pygplates.NetRotationSnapshot calculates the same net rotation for points inside rigid plates. Inside the deforming region of a network the two differ slightly: the snapshot interpolates the stage rotations of the corners of the network triangle that contains the point, where pygplates.TopologicalSnapshot.get_point_velocities() interpolates the velocities of the vertices near the point, using natural neighbour interpolation.
