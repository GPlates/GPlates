Find plates and strain rates at static points

This example finds which topological plate or deforming network contains each of a set of static points, and the strain rate at each point, over a series of geological times.

At each time the topological plates (and deforming networks) are resolved. Then pygplates.TopologicalSnapshot.get_point_locations() finds the plate or network that contains each point, and pygplates.TopologicalSnapshot.get_point_strain_rates() calculates the strain rate there.

The points do not move. So this finds the plates that pass over fixed locations, and how fast the crust at those locations is deforming at each time. To follow points as they move with the plates, accumulating strain, see Reconstruct strain and strain rate.

Calculate velocities in dynamic plates calculates velocities at static points in the same way.

The first example finds where each point is: in a rigid plate, in the deforming region of a network, in a rigid block inside a network, or outside them all. The second calculates the strain rate at each point.

Data files

Both scripts read the same files:

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological features, and of the features that the boundaries of the deforming networks are built from.

topologies.gpml

Topological plate polygon and deforming network features. They are resolved at each time. A strain rate is only non-zero inside the deforming region of a network.

lat_lon_velocity_domain_9_18.gpml

Features whose geometries contain the static points. Any geometry type will do, since only its points are used. Such a file can be generated in GPlates using the menu Features > Generate Velocity Domain Points.

Rotation files and topological features are in the GPlates sample data.

Find the plate or network containing each static point

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
point_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
points = []
for point_feature in point_features:

    # A feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for geometry in point_feature.get_geometries():

        points.extend(geometry.get_points())

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 30

# 'time' = 0, 1, 2, ... , 30
for time in range(num_time_steps + 1):

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Find the resolved plate (or deforming network) that contains each point.
    # The locations are in the same order as the points.
    point_locations = topological_snapshot.get_point_locations(points)

    # Do the same, but search the rigid plates only.
    # For a point in a deforming network, this finds the rigid plate (if any) that the network overlays there.
    point_locations_in_plates = topological_snapshot.get_point_locations(
            points,
            resolve_topology_types=pygplates.ResolveTopologyType.boundary)

    num_points_outside = 0
    num_points_in_plates = 0
    lines_for_points_in_networks = []

    for point_index, point in enumerate(points):
        point_location = point_locations[point_index]

        if point_location.not_located_in_resolved_topology():
            # The point is outside all the resolved plates (and deforming networks).
            num_points_outside += 1
            continue

        if point_location.located_in_resolved_boundary():
            # The point is in a rigid plate (and not in a deforming network).
            num_points_in_plates += 1
            continue

        # Otherwise the point is in a deforming network:
        # either in one of its interior rigid blocks or in its deforming region.
        rigid_block_location = point_location.located_in_resolved_network_rigid_block()
        if rigid_block_location:
            resolved_network, rigid_block = rigid_block_location
            rigid_block_plate_id = rigid_block.get_feature().get_reconstruction_plate_id()
            where_in_network = f'a rigid block (plate {rigid_block_plate_id}) of'
        else:
            resolved_network = point_location.located_in_resolved_network_deforming_region()
            where_in_network = 'the deforming region of'

        # The rigid plate that the network overlays at the point (None if there is no plate there).
        resolved_plate_beneath = point_locations_in_plates[point_index].located_in_resolved_boundary()
        if resolved_plate_beneath:
            plate_beneath_feature = resolved_plate_beneath.get_feature()
            plate_beneath = (f'over plate {plate_beneath_feature.get_reconstruction_plate_id()} '
                             f'({plate_beneath_feature.get_name()})')
        else:
            plate_beneath = 'over no plate'

        latitude, longitude = point.to_lat_lon()
        network_feature = resolved_network.get_feature()
        lines_for_points_in_networks.append(
                f'  ({latitude:.1f}, {longitude:.1f}) is in {where_in_network} network '
                f'{network_feature.get_reconstruction_plate_id()} ({network_feature.get_name()}), {plate_beneath}')

    print(f'Time {time}Ma: {num_points_in_plates} points are in rigid plates, '
          f'{len(lines_for_points_in_networks)} in deforming networks and {num_points_outside} outside both')
    for line in lines_for_points_in_networks:
        print(line)

Details

A topological model is created from the topological features and the rotation file.

The topological features are not resolved here. That happens at each time, in the loop below.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The points of all the features are gathered into one list.

A feature usually has a single geometry, but pygplates.Feature.get_geometries() handles any number, and pygplates.GeometryOnSphere.get_points() reduces each geometry to its points.

The points are not reconstructed. They stay where they are while the plates move over them, so the same list is used at every time.

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
point_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
points = []
for point_feature in point_features:

    # A feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for geometry in point_feature.get_geometries():

        points.extend(geometry.get_points())

The topological features are resolved to the current time using pygplates.TopologicalModel.topological_snapshot().

# Get a snapshot of our resolved topologies at the current 'time'.
topological_snapshot = topological_model.topological_snapshot(time)

pygplates.TopologicalSnapshot.get_point_locations() returns the location of each point in the resolved topologies, in the order of the points.

Where a deforming network overlays a rigid plate, a point inside both is located in the network.

# Find the resolved plate (or deforming network) that contains each point.
# The locations are in the same order as the points.
point_locations = topological_snapshot.get_point_locations(points)

The resolve_topology_types argument chooses what is searched: the rigid plates (pygplates.ResolveTopologyType.boundary), the deforming networks (pygplates.ResolveTopologyType.network), or both, which is the default.

Here a second search looks at the rigid plates only. For a point in a network, it finds the plate that the network overlays there.

pygplates.TopologicalSnapshot.get_point_strain_rates() and pygplates.TopologicalSnapshot.get_point_velocities() accept the same argument.

# Do the same, but search the rigid plates only.
# For a point in a deforming network, this finds the rigid plate (if any) that the network overlays there.
point_locations_in_plates = topological_snapshot.get_point_locations(
        points,
        resolve_topology_types=pygplates.ResolveTopologyType.boundary)

Each point is visited with its location.

for point_index, point in enumerate(points):
    point_location = point_locations[point_index]

pygplates.TopologyPointLocation.not_located_in_resolved_topology() returns True for a point that is outside all the resolved plates and networks. Such points are only counted.

if point_location.not_located_in_resolved_topology():
    # The point is outside all the resolved plates (and deforming networks).
    num_points_outside += 1
    continue

pygplates.TopologyPointLocation.located_in_resolved_boundary() returns the resolved topological boundary (the rigid plate) that contains the point, or None.

It is None for a point in a network, even where the network overlays a plate. Points in rigid plates are only counted too.

if point_location.located_in_resolved_boundary():
    # The point is in a rigid plate (and not in a deforming network).
    num_points_in_plates += 1
    continue

A point that remains is in a deforming network, and a point in a network is in one of two places.

It can be in one of the network’s interior rigid blocks, which are polygons inside the network that do not deform. Then pygplates.TopologyPointLocation.located_in_resolved_network_rigid_block() returns a 2-tuple: the resolved topological network, and the rigid block as a pygplates.ReconstructedFeatureGeometry. The block moves with the reconstruction plate ID of its feature.

Otherwise it is in the deforming region of the network. Then that method returns None, and pygplates.TopologyPointLocation.located_in_resolved_network_deforming_region() returns the resolved network.

(pygplates.TopologyPointLocation.located_in_resolved_network() returns the resolved network in both cases.)

# Otherwise the point is in a deforming network:
# either in one of its interior rigid blocks or in its deforming region.
rigid_block_location = point_location.located_in_resolved_network_rigid_block()
if rigid_block_location:
    resolved_network, rigid_block = rigid_block_location
    rigid_block_plate_id = rigid_block.get_feature().get_reconstruction_plate_id()
    where_in_network = f'a rigid block (plate {rigid_block_plate_id}) of'
else:
    resolved_network = point_location.located_in_resolved_network_deforming_region()
    where_in_network = 'the deforming region of'

The rigid plate beneath the network at the point comes from the second list of locations, which searched the plates only.

There might be none: nothing requires a network to lie over a plate.

# The rigid plate that the network overlays at the point (None if there is no plate there).
resolved_plate_beneath = point_locations_in_plates[point_index].located_in_resolved_boundary()
if resolved_plate_beneath:
    plate_beneath_feature = resolved_plate_beneath.get_feature()
    plate_beneath = (f'over plate {plate_beneath_feature.get_reconstruction_plate_id()} '
                     f'({plate_beneath_feature.get_name()})')
else:
    plate_beneath = 'over no plate'

A line is made for the point, with the plate ID and name of the network. They are read from its feature (pygplates.ResolvedTopologicalNetwork.get_feature()).

latitude, longitude = point.to_lat_lon()
network_feature = resolved_network.get_feature()
lines_for_points_in_networks.append(
        f'  ({latitude:.1f}, {longitude:.1f}) is in {where_in_network} network '
        f'{network_feature.get_reconstruction_plate_id()} ({network_feature.get_name()}), {plate_beneath}')

Finally the numbers of points are printed for the current time, followed by the line of each point that is in a network.

print(f'Time {time}Ma: {num_points_in_plates} points are in rigid plates, '
      f'{len(lines_for_points_in_networks)} in deforming networks and {num_points_outside} outside both')
for line in lines_for_points_in_networks:
    print(line)

Calculate strain rates at static points

This example calculates the strain rate at each static point, and prints it for the points that are in the deforming region of a network.

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
point_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
points = []
for point_feature in point_features:

    # A feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for geometry in point_feature.get_geometries():

        points.extend(geometry.get_points())

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 30

# 'time' = 0, 1, 2, ... , 30
for time in range(num_time_steps + 1):

    print(f'Time {time}Ma:')

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Calculate the strain rate at each point,
    # and find the resolved plate (or deforming network) that contains each point.
    # Both lists are in the same order as the points.
    point_strain_rates, point_locations = topological_snapshot.get_point_strain_rates(
            points,
            return_point_locations=True)

    for point_index, point in enumerate(points):
        point_strain_rate = point_strain_rates[point_index]
        point_location = point_locations[point_index]

        if point_strain_rate is None:
            # The point is outside all the resolved plates (and deforming networks), so it has no strain rate.
            continue

        resolved_network = point_location.located_in_resolved_network_deforming_region()
        if not resolved_network:
            # The point is in a rigid plate, or in a rigid block of a deforming network.
            # Its strain rate is zero.
            continue

        # The rate of change of crustal area per unit area (in units of 1/second).
        # It is positive where the crust is extending and negative where it is contracting.
        dilatation_rate = point_strain_rate.get_dilatation_rate()
        # The magnitude of the strain rate (in units of 1/second), including both its normal and shear components.
        total_strain_rate = point_strain_rate.get_total_strain_rate()

        latitude, longitude = point.to_lat_lon()
        print(f'  ({latitude:.1f}, {longitude:.1f}) in "{resolved_network.get_feature().get_name()}": '
              f'dilatation rate {dilatation_rate:.3e} 1/s, total strain rate {total_strain_rate:.3e} 1/s')

Details

The topological model and the static points are the same as in the first example.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the static points.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
point_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points.
points = []
for point_feature in point_features:

    # A feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for geometry in point_feature.get_geometries():

        points.extend(geometry.get_points())

pygplates.TopologicalSnapshot.get_point_strain_rates() returns one strain rate for each point, in the order of the points.

With return_point_locations set to True it returns a 2-tuple: the list of strain rates, and a list with the location of each point in the resolved topologies. This is more efficient than getting the locations in a separate call to pygplates.TopologicalSnapshot.get_point_locations().

The strain rate is that of the snapshot’s time. It is calculated from the velocities of the network around the point, which are always calculated over a 1My time interval (the method has no velocity arguments).

# Calculate the strain rate at each point,
# and find the resolved plate (or deforming network) that contains each point.
# Both lists are in the same order as the points.
point_strain_rates, point_locations = topological_snapshot.get_point_strain_rates(
        points,
        return_point_locations=True)

Each point is visited with its strain rate and its location.

for point_index, point in enumerate(points):
    point_strain_rate = point_strain_rates[point_index]
    point_location = point_locations[point_index]

A point that is outside all the resolved plates and networks has no strain rate: its entry in the list is None. It is skipped.

if point_strain_rate is None:
    # The point is outside all the resolved plates (and deforming networks), so it has no strain rate.
    continue

A point in a rigid plate has a strain rate of zero (pygplates.StrainRate.zero), since a rigid plate does not deform. So has a point in a rigid block of a network.

Only a point in the deforming region of a network can have a strain rate that is not zero, so the other points are skipped.

resolved_network = point_location.located_in_resolved_network_deforming_region()
if not resolved_network:
    # The point is in a rigid plate, or in a rigid block of a deforming network.
    # Its strain rate is zero.
    continue

Two quantities are taken from the strain rate. Both are in units of 1/second.

The dilatation rate is the rate of change of crustal area per unit area. It is positive where the crust is extending and negative where it is contracting.

The total strain rate is the magnitude of the strain rate. It includes both the normal (extension or compression) and shear components.

See pygplates.StrainRate for the other quantities, and for how they are defined.

# The rate of change of crustal area per unit area (in units of 1/second).
# It is positive where the crust is extending and negative where it is contracting.
dilatation_rate = point_strain_rate.get_dilatation_rate()
# The magnitude of the strain rate (in units of 1/second), including both its normal and shear components.
total_strain_rate = point_strain_rate.get_total_strain_rate()

Finally the point is printed with the name of its network and the two quantities.

latitude, longitude = point.to_lat_lon()
print(f'  ({latitude:.1f}, {longitude:.1f}) in "{resolved_network.get_feature().get_name()}": '
      f'dilatation rate {dilatation_rate:.3e} 1/s, total strain rate {total_strain_rate:.3e} 1/s')

Note

The deforming region of a network is divided into triangles, each with one strain rate. By default the strain rate at a point is smoothed, using the strain rates of the triangles around the point. See Query the triangulation and rigid blocks of deforming networks for the triangle that contains a point, and Clamp and smooth strain rates, and set rift parameters for how to change the smoothing.
