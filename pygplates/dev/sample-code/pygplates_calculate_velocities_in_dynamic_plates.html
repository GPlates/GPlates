Calculate velocities in dynamic plates

This example shows two similar ways to calculate velocities of topological plates at static point locations.

Both read the same files and calculate the same velocities: at each time the topological plates (and deforming networks) are resolved, and pygplates.TopologicalSnapshot.get_point_velocities() calculates the velocity at each point from the plate or network that contains it.

Inside a rigid plate that is the velocity of the plate, which comes from the motion of its reconstruction plate ID. Inside a deforming network it is the velocity of the network at the point, which varies across the network.

The first example calculates a velocity at each point, keeping the points in their order. The second also finds which plate contains each point, and groups the points and their velocities by plate.

Data files

Both scripts read the same files:

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological plates in topologies.gpml, since the velocity of a plate comes from the motion of its plate ID.

topologies.gpml

Topological plate polygon features, with or without deforming network features. They are resolved at each time. Each plate polygon should have a reconstruction plate ID, since that is the plate ID whose motion gives its velocity (a plate polygon without one is given plate ID zero).

lat_lon_velocity_domain_9_18.gpml

The velocity domain: features whose geometries contain the static points at which velocities are calculated. Any geometry type will do, since only its points are used. Such a file can be generated in GPlates using the menu Features > Generate Velocity Domain Points.

Rotation files and topological plate polygons are in the GPlates sample data.

Calculate velocities of dynamic plates at static points

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Calculate a velocity at each domain point, from 'time + delta_time' to 'time'.
    # The velocities are in the same order as the domain points.
    # A velocity is None if its point is outside all the resolved plates (and deforming networks).
    domain_velocity_vectors = topological_snapshot.get_point_velocities(
            domain_points,
            velocity_delta_time=delta_time)

    # Keep the domain points that are inside a plate (or deforming network), and their velocities.
    points_in_plates = []
    velocity_vectors_in_plates = []
    for domain_point, domain_velocity_vector in zip(domain_points, domain_velocity_vectors):
        if domain_velocity_vector is not None:
            points_in_plates.append(domain_point)
            velocity_vectors_in_plates.append(domain_velocity_vector)

    # Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
    velocities_in_plates = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
            points_in_plates,
            velocity_vectors_in_plates)

    print(f'Time {time}: calculated velocities at {len(points_in_plates)} of {len(domain_points)} points')

Details

A topological model is created from the topological features and the rotation file.

The topological features are not resolved here. That happens at each time, in the loop below.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The velocity domain features contain the static points at which velocities are calculated.

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

The points of all the velocity domain features are gathered into one list.

A velocity domain feature usually has a single geometry, but pygplates.Feature.get_geometries() handles any number, and pygplates.GeometryOnSphere.get_points() reduces each geometry to its points.

The points are not reconstructed. They stay where they are while the plates move over them, so the same list is used at every time.

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

The velocities at each time are calculated over a 1My interval, from time + delta_time to time.

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

The topological features are resolved to the current time using pygplates.TopologicalModel.topological_snapshot().

# Get a snapshot of our resolved topologies at the current 'time'.
topological_snapshot = topological_model.topological_snapshot(time)

Note

A new snapshot is needed at each time because the plates are dynamic: which plate contains a point changes as the plate boundaries move.

pygplates.TopologicalSnapshot.get_point_velocities() returns one velocity for each point, in the order of the points. Each is a pygplates.Vector3D (a global cartesian velocity vector), in kilometres per million years unless the velocity_units argument says otherwise.

A point that is outside all the resolved plates and networks has no velocity: its entry in the list is None.

Where a deforming network overlays a rigid plate, a point inside both gets the velocity of the network.

# Calculate a velocity at each domain point, from 'time + delta_time' to 'time'.
# The velocities are in the same order as the domain points.
# A velocity is None if its point is outside all the resolved plates (and deforming networks).
domain_velocity_vectors = topological_snapshot.get_point_velocities(
        domain_points,
        velocity_delta_time=delta_time)

The points that have no velocity are left out before the velocities are converted, since the conversion below raises TypeError if it is given None in place of a vector.

The points that remain are still in the order of the velocity domain points. A script that needs an entry for every velocity domain point can use domain_velocity_vectors instead, which lines up with domain_points.

# Keep the domain points that are inside a plate (or deforming network), and their velocities.
points_in_plates = []
velocity_vectors_in_plates = []
for domain_point, domain_velocity_vector in zip(domain_points, domain_velocity_vectors):
    if domain_velocity_vector is not None:
        points_in_plates.append(domain_point)
        velocity_vectors_in_plates.append(domain_velocity_vector)

The vectors are converted to local (magnitude, azimuth, inclination) tuples, one per point, using pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination().

Each point determines its own local coordinate system. For example, the velocity azimuth is relative to North as viewed from that point.

# Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
velocities_in_plates = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
        points_in_plates,
        velocity_vectors_in_plates)

Calculate velocities by grouping static points into dynamic plates

This example is like the one above, except that it groups the points, and their velocities, by the plate that contains them.

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    print(f'Time: {time}')

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Calculate a velocity at each domain point, from 'time + delta_time' to 'time',
    # and find the resolved plate (or deforming network) that contains each domain point.
    domain_velocity_vectors, domain_point_locations = topological_snapshot.get_point_velocities(
            domain_points,
            velocity_delta_time=delta_time,
            return_point_locations=True)

    # The domain points in each resolved plate (or deforming network), and their velocity vectors.
    # Each is a dictionary mapping a resolved plate to a list.
    points_in_plates = {}
    velocity_vectors_in_plates = {}

    for point_index, domain_point in enumerate(domain_points):
        domain_velocity_vector = domain_velocity_vectors[point_index]
        domain_point_location = domain_point_locations[point_index]

        # The resolved plate that contains the point or, if the point is in a deforming network, the resolved network.
        containing_plate = (domain_point_location.located_in_resolved_boundary() or
                            domain_point_location.located_in_resolved_network())
        if not containing_plate:
            # The point is outside all the resolved plates (and deforming networks), so it has no velocity.
            continue

        # Add the point, and its velocity, to those of the plate that contains it.
        if containing_plate not in points_in_plates:
            points_in_plates[containing_plate] = []
            velocity_vectors_in_plates[containing_plate] = []
        points_in_plates[containing_plate].append(domain_point)
        velocity_vectors_in_plates[containing_plate].append(domain_velocity_vector)

    # All (magnitude, azimuth, inclination) velocities for the current time, grouped by resolved plate.
    velocities_in_plates = {}

    for containing_plate, points_in_plate in points_in_plates.items():

        # Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
        velocities_in_plates[containing_plate] = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
                points_in_plate,
                velocity_vectors_in_plates[containing_plate])

        # The plate ID (and name) of the plate come from its feature.
        containing_plate_feature = containing_plate.get_feature()
        print(f'  Plate {containing_plate_feature.get_reconstruction_plate_id()} '
              f'({containing_plate_feature.get_name()}), number of points: {len(points_in_plate)}')

Details

The topological model, velocity domain points and time interval are the same as in the first example.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Load the features that contain the geometries we will calculate velocities at.
# These can be generated in GPlates via the menu 'Features > Generate Velocity Domain Points'.
velocity_domain_features = pygplates.FeatureCollection('lat_lon_velocity_domain_9_18.gpml')

# The static points at which velocities are calculated.
domain_points = []
for velocity_domain_feature in velocity_domain_features:

    # A velocity domain feature usually has a single geometry but we'll assume it can be any number.
    # Iterate over them all.
    for velocity_domain_geometry in velocity_domain_feature.get_geometries():

        domain_points.extend(velocity_domain_geometry.get_points())

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

pygplates.TopologicalSnapshot.get_point_velocities() is called as before, but with return_point_locations set to True.

It then returns a 2-tuple: the list of velocities, and a list with the location of each point in the resolved topologies. Both lists are in the order of the points.

This is more efficient than getting the locations in a separate call to pygplates.TopologicalSnapshot.get_point_locations().

# Calculate a velocity at each domain point, from 'time + delta_time' to 'time',
# and find the resolved plate (or deforming network) that contains each domain point.
domain_velocity_vectors, domain_point_locations = topological_snapshot.get_point_velocities(
        domain_points,
        velocity_delta_time=delta_time,
        return_point_locations=True)

Each point is visited with its velocity and its location.

for point_index, domain_point in enumerate(domain_points):
    domain_velocity_vector = domain_velocity_vectors[point_index]
    domain_point_location = domain_point_locations[point_index]

pygplates.TopologyPointLocation.located_in_resolved_boundary() returns the resolved topological boundary (the rigid plate) that contains the point, or None.

pygplates.TopologyPointLocation.located_in_resolved_network() returns the resolved topological network that contains the point, or None. That includes a point inside one of the network’s interior rigid blocks.

A point is located in one or the other, not both: where a network overlays a plate, the point is located in the network.

A point located in neither is outside all the plates and networks. Its velocity is None, and it is skipped.

# The resolved plate that contains the point or, if the point is in a deforming network, the resolved network.
containing_plate = (domain_point_location.located_in_resolved_boundary() or
                    domain_point_location.located_in_resolved_network())
if not containing_plate:
    # The point is outside all the resolved plates (and deforming networks), so it has no velocity.
    continue

The point and its velocity are appended to the lists of the plate that contains the point.

The lists are kept in two dictionaries whose keys are the resolved plates themselves. A plate’s plate ID would not do as the key, since nothing stops two topologies from having the same plate ID.

# Add the point, and its velocity, to those of the plate that contains it.
if containing_plate not in points_in_plates:
    points_in_plates[containing_plate] = []
    velocity_vectors_in_plates[containing_plate] = []
points_in_plates[containing_plate].append(domain_point)
velocity_vectors_in_plates[containing_plate].append(domain_velocity_vector)

Iterating over a dictionary visits each plate that contains a point once.

for containing_plate, points_in_plate in points_in_plates.items():

The velocities are converted as in the first example, but one plate at a time.

No point here is without a velocity, since every point in the dictionaries is inside a plate.

# Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
velocities_in_plates[containing_plate] = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
        points_in_plate,
        velocity_vectors_in_plates[containing_plate])

Finally the plate ID and name of each plate are read from its feature (pygplates.ResolvedTopologicalBoundary.get_feature(), or pygplates.ResolvedTopologicalNetwork.get_feature() for a network), and printed with the number of points in the plate.

# The plate ID (and name) of the plate come from its feature.
containing_plate_feature = containing_plate.get_feature()
print(f'  Plate {containing_plate_feature.get_reconstruction_plate_id()} '
      f'({containing_plate_feature.get_name()}), number of points: {len(points_in_plate)}')
