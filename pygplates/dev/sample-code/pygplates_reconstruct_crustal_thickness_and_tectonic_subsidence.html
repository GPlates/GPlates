Reconstruct crustal thickness and tectonic subsidence

This example reconstructs (and deforms) points through topological plate polygons and deforming networks, from a past geological time to present day. At each time along the way it finds:

  • the reconstructed positions of the initial points,

  • their crustal thicknesses,

  • their crustal stretching factors, and

  • their tectonic subsidences.

Data files

topologies.gpml

Topological plate polygon and deforming network features. There must be networks at 30Ma, since the initial points are chosen from them. Leave out inactive networks, such as those in Zahirovic_etal_2022_Deforming_Networks_Inactive.gpml in the GPlates sample data, so that the points are chosen from networks that are deforming. The crustal thickness, crustal stretching factor and tectonic subsidence of a point only change while it is inside the deforming region of a network.

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological features.

Files of these kinds are in the GPlates sample data.

Sample code

import sys
import pygplates


# Create a topological model from our topological features (plate polygons and deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Our reconstruction will span from 30Ma to present day in 1 Myr intervals.
initial_time = 30
# The time increment must divide 'initial_time' exactly ('reconstruct_geometry()' raises ValueError otherwise).
time_increment = 1

# The initial points that we will reconstruct (and deform) through the topological model.
# They are chosen from a coarse grid of (latitude, longitude) points, 10 degrees apart, from latitude -60 to 60
# (south to north): the first four that are in the deforming region of a network at the initial time.
grid_points = [(latitude, longitude) for latitude in range(-60, 70, 10) for longitude in range(-180, 180, 10)]
grid_point_locations = topological_model.topological_snapshot(initial_time).get_point_locations(grid_points)
initial_points = [point for point, point_location in zip(grid_points, grid_point_locations)
                  if point_location.located_in_resolved_network_deforming_region()][:4]

# Stop if there are none: there are no deforming networks at the initial time, or they are too small for the grid.
if not initial_points:
    sys.exit(f'No grid point is in the deforming region of a network at {initial_time}Ma')

# Reconstruct the initial points through the topological model from initial time to present day.
reconstructed_time_span = topological_model.reconstruct_geometry(
        initial_points,
        initial_time,
        time_increment=time_increment)

# Get the history of reconstructed positions, crustal thickness, crustal stretching and tectonic subsidence
# of the initial points from initial time to present day.
for time in range(initial_time, -1, -time_increment):  # initial_time, initial_time - time_increment, ..., 0
    # Reconstructed positions at the current 'time'.
    reconstructed_points = reconstructed_time_span.get_geometry_points(time)

    # If every point has been deactivated by the current 'time' then there are no positions (or anything else) to get.
    if reconstructed_points is None:
        print(f'Time {time}Ma: all points have been deactivated')
        continue

    # In which resolved topologies are the reconstructed positions located at the current 'time'.
    reconstructed_topology_point_locations = reconstructed_time_span.get_topology_point_locations(time)

    # The crustal thickness (in kms), crustal stretching factor and tectonic subsidence (in kms)
    # for each point at the current 'time'.
    reconstructed_crustal_thicknesses = reconstructed_time_span.get_crustal_thicknesses(time)
    reconstructed_crustal_stretching_factors = reconstructed_time_span.get_crustal_stretching_factors(time)
    reconstructed_tectonic_subsidences = reconstructed_time_span.get_tectonic_subsidences(time)

    # Print the position, crustal thickness, crustal stretching factor and tectonic subsidence of each point.
    print(f'Time {time}Ma:')
    for point_index, reconstructed_point in enumerate(reconstructed_points):
        latitude, longitude = reconstructed_point.to_lat_lon()
        print(f'  lat: {latitude:f}, lon: {longitude:f}, '
              f'crustal thickness: {reconstructed_crustal_thicknesses[point_index]:f} kms, '
              f'crustal stretching factor: {reconstructed_crustal_stretching_factors[point_index]:f}, '
              f'tectonic subsidence: {reconstructed_tectonic_subsidences[point_index]:f} kms')

Details

A topological model is created from the topological features (plate polygons and deforming networks) and the rotation file.

Here there is one file of topological features and one rotation file. More than one of each can be given, and a pygplates.RotationModel can be given in place of the rotation files.

# Create a topological model from our topological features (plate polygons and deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The initial points are chosen from the networks, rather than written into the script, so that the example works with any topological features that have deforming networks at the initial time, 30Ma.

They are chosen from a coarse grid of (latitude, longitude) points, 10 degrees apart, from latitude -60 to 60. It stops at 60 degrees because, in the GPlates sample data, the grid points nearer the poles happen to fall where the networks barely deform at 30Ma, so they would make poor examples. The grid is scanned from south to north, and the first points found are used. In the GPlates sample data, three of the first four points found from north to south barely deform.

pygplates.TopologicalModel.topological_snapshot() resolves the topologies at the initial time, and pygplates.TopologicalSnapshot.get_point_locations() returns the location of each grid point in them. The first four points that pygplates.TopologyPointLocation.located_in_resolved_network_deforming_region() places in the deforming region of a network are kept. If there are none, the script stops with an error message that says so.

# The initial points that we will reconstruct (and deform) through the topological model.
# They are chosen from a coarse grid of (latitude, longitude) points, 10 degrees apart, from latitude -60 to 60
# (south to north): the first four that are in the deforming region of a network at the initial time.
grid_points = [(latitude, longitude) for latitude in range(-60, 70, 10) for longitude in range(-180, 180, 10)]
grid_point_locations = topological_model.topological_snapshot(initial_time).get_point_locations(grid_points)
initial_points = [point for point, point_location in zip(grid_points, grid_point_locations)
                  if point_location.located_in_resolved_network_deforming_region()][:4]

# Stop if there are none: there are no deforming networks at the initial time, or they are too small for the grid.
if not initial_points:
    sys.exit(f'No grid point is in the deforming region of a network at {initial_time}Ma')

pygplates.TopologicalModel.reconstruct_geometry() reconstructs (and deforms) the initial_points from their positions at initial_time to present day, in 1 Myr intervals.

It returns a reconstructed geometry time span. This holds the history of the reconstructed point positions and of the scalar values at the points, such as crustal thickness and tectonic subsidence, which change while a point is passing through a deforming network.

The initial_scalars argument is not given. So the initial crustal thicknesses, crustal stretching factors and tectonic subsidences have their default values, of 40 kms, 1.0 and 0.0. The last two mean that there is no stretching, and that the subsidence is at sea level, at the initial time.

The deactivate_points argument is not given either. So points are deactivated in the default way, which is the way that GPlates does it (with Reconstruct using topologies in a green layer). This means an initial point on oceanic crust can be subducted and disappear (be deactivated).

# Reconstruct the initial points through the topological model from initial time to present day.
reconstructed_time_span = topological_model.reconstruct_geometry(
        initial_points,
        initial_time,
        time_increment=time_increment)

pygplates.ReconstructedGeometryTimeSpan.get_geometry_points() returns the reconstructed positions at the current time. Some of the initial points may have been deactivated by then, so reconstructed_points can have fewer points than initial_points.

# Reconstructed positions at the current 'time'.
reconstructed_points = reconstructed_time_span.get_geometry_points(time)

If all the points have been deactivated by the current time then pygplates.ReconstructedGeometryTimeSpan.get_geometry_points() returns None rather than an empty list, and so do the other queries below. So the script tests for that first.

# If every point has been deactivated by the current 'time' then there are no positions (or anything else) to get.
if reconstructed_points is None:
    print(f'Time {time}Ma: all points have been deactivated')
    continue

pygplates.ReconstructedGeometryTimeSpan.get_topology_point_locations() returns the resolved topology that each reconstructed position is in at the current time. It returns one location for each point in reconstructed_points, in the same order. The script gets the locations but does not print them.

# In which resolved topologies are the reconstructed positions located at the current 'time'.
reconstructed_topology_point_locations = reconstructed_time_span.get_topology_point_locations(time)

The crustal thickness (in kms), the crustal stretching factor and the tectonic subsidence (in kms) of each point in reconstructed_points are returned by pygplates.ReconstructedGeometryTimeSpan.get_crustal_thicknesses(), pygplates.ReconstructedGeometryTimeSpan.get_crustal_stretching_factors() and pygplates.ReconstructedGeometryTimeSpan.get_tectonic_subsidences().

Each returns a list with one value for each point in reconstructed_points, in the same order.

The crustal stretching factor is the initial crustal thickness divided by the crustal thickness at the current time. So crust that has been stretched to half its initial thickness has a crustal stretching factor of 2.

These three scalar types are builtin, so they are always available (even when no initial scalar values are provided). Each method is the equivalent of calling pygplates.ReconstructedGeometryTimeSpan.get_scalar_values() with the corresponding scalar type.

# The crustal thickness (in kms), crustal stretching factor and tectonic subsidence (in kms)
# for each point at the current 'time'.
reconstructed_crustal_thicknesses = reconstructed_time_span.get_crustal_thicknesses(time)
reconstructed_crustal_stretching_factors = reconstructed_time_span.get_crustal_stretching_factors(time)
reconstructed_tectonic_subsidences = reconstructed_time_span.get_tectonic_subsidences(time)

Finally the script prints the position, crustal thickness, crustal stretching factor and tectonic subsidence of each point.

# Print the position, crustal thickness, crustal stretching factor and tectonic subsidence of each point.
print(f'Time {time}Ma:')
for point_index, reconstructed_point in enumerate(reconstructed_points):
    latitude, longitude = reconstructed_point.to_lat_lon()
    print(f'  lat: {latitude:f}, lon: {longitude:f}, '
          f'crustal thickness: {reconstructed_crustal_thicknesses[point_index]:f} kms, '
          f'crustal stretching factor: {reconstructed_crustal_stretching_factors[point_index]:f}, '
          f'tectonic subsidence: {reconstructed_tectonic_subsidences[point_index]:f} kms')
