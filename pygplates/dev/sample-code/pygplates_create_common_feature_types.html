Create common feature types

This example creates features of various types.

It is similar to importing. The difference is that each feature here is given a specific type, where the import examples create features of the generic unclassified type (pygplates.FeatureType.gpml_unclassified_feature).

Each feature type is created in two ways. The sample code uses the create_... function of pygplates.Feature for that type. The alternate sample code creates an empty feature of the type and sets its properties one by one.

Create a coastline feature from present-day geometry

This example creates a coastline feature from present day geometry, and saves it to a file.

See also

Query a coastline feature

Sample code

import pygplates


# Start with an empty list of coastline features.
coastline_features = []

# Create a polyline geometry from lat/lon points for the present day location of part of the
# Eastern Panama coastline.
eastern_panama_present_day_coastline_geometry = pygplates.PolylineOnSphere(
    [
        (-0.635538, -80.402139),
        (-0.392500, -80.500444),
        ( 0.051750, -80.079222),
        ( 0.370111, -80.049944),
        ( 0.118972, -79.998333),
        ( 0.170306, -79.948361),
        ( 0.763083, -80.099222),
        ( 0.981833, -79.650750),
        ( 0.900000, -79.649472),
        ( 1.068417, -79.430556),
        ( 1.080250, -79.177028),
        ( 1.216111, -79.061472),
        ( 1.041000, -79.014306),
        ( 1.063750, -78.928500),
        ( 1.082389, -78.982583),
        ( 1.144583, -78.897694),
        ( 1.222414, -78.932823)
    ])

# Create a coastline feature from the coastline geometry, name, valid time period and plate ID.
eastern_panama_coastline_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_coastline,
    eastern_panama_present_day_coastline_geometry,
    name='Eastern Panama, Central America',
    valid_time=(600, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201)

coastline_features.append(eastern_panama_coastline_feature)

# Add more coastline features.
# ...

# Write the coastline features to a file.
coastline_feature_collection = pygplates.FeatureCollection(coastline_features)
coastline_feature_collection.write('coastlines.gpml')

Details

A pygplates.PolylineOnSphere geometry is created from a list of (latitude, longitude) tuples. When the polyline constructor receives a sequence of 2-tuples, it takes each one as the latitude and longitude, in degrees, of a point of the polyline.

This polyline is the location of part of the Eastern Panama coastline at present day (0Ma).

eastern_panama_present_day_coastline_geometry = pygplates.PolylineOnSphere(
    [
        (-0.635538, -80.402139),
        (-0.392500, -80.500444),
        ( 0.051750, -80.079222),
        ...
    ])

The coastline feature is created with pygplates.Feature.create_reconstructable_feature(). It is given the feature type (pygplates.FeatureType.gpml_coastline), the present day geometry, a name, a valid time period and a reconstruction plate ID.

The valid time period begins at 600Ma and ends in the distant future.

# Create a coastline feature from the coastline geometry, name, valid time period and plate ID.
eastern_panama_coastline_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_coastline,
    eastern_panama_present_day_coastline_geometry,
    name='Eastern Panama, Central America',
    valid_time=(600, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201)

Note

Advanced

pygplates.Feature.create_reconstructable_feature() creates a feature whose type is in the category of reconstructable features. A feature type in this category supports the gml:name, gml:description, gml:validTime and gpml:reconstructionPlateId properties that the function sets.

Many feature types are in this category. They are listed in the Inherited by features sub-section of gpml:ReconstructableFeature. One of them is gpml:TangibleFeature, which has its own Inherited by features list, and gpml:Coastline is in that list.

So a gpml:Coastline inherits, indirectly, from gpml:ReconstructableFeature. A feature type that inherits from another supports the properties of that other type. That makes gpml:Coastline one of the many feature types that can be used with pygplates.Feature.create_reconstructable_feature().

Given a feature type that is not in this category, the function raises pygplates.InformationModelError.

The coastline features are then saved to a file, as described in Load and save feature collections:

# Write the coastline features to a file.
coastline_feature_collection = pygplates.FeatureCollection(coastline_features)
coastline_feature_collection.write('coastlines.gpml')

The alternate sample code does not use pygplates.Feature.create_reconstructable_feature(). It first creates an empty pygplates.FeatureType.gpml_coastline feature, and then sets its properties one by one.

# Create a coastline feature from the coastline geometry, name, valid time period and plate ID.
eastern_panama_coastline_feature = pygplates.Feature(pygplates.FeatureType.gpml_coastline)
eastern_panama_coastline_feature.set_geometry(eastern_panama_present_day_coastline_geometry)
eastern_panama_coastline_feature.set_name('Eastern Panama, Central America')
eastern_panama_coastline_feature.set_valid_time(600, pygplates.GeoTimeInstant.create_distant_future())
eastern_panama_coastline_feature.set_reconstruction_plate_id(201)

Create an isochron feature from geometry at a past geological time

This example creates an isochron feature from geometry that is its location at a past geological time, not at present day.

See also

Query an isochron feature and Create conjugate isochrons from a ridge

Data files

Both scripts read the same file:

rotations.rot

A rotation file. It is used to reverse reconstruct the isochron geometry from 40.1Ma to present day, so it must contain rotations for the isochron’s plate (201) at that time.

Rotation files are in the GPlates sample data.

Sample code

import pygplates


# Load a rotation model from a rotation file.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create a polyline geometry from lat/lon points for the isochron location at 40.1 Ma.
isochron_time_of_appearance = 40.1
isochron_geometry_at_time_of_appearance = pygplates.PolylineOnSphere(
    [
        (-57.635356,  0.765764),
        (-57.162269, -1.953176),
        (-57.916700, -2.522021),
        (-57.658576, -3.936703),
        (-58.639846, -4.849338),
        (-58.404889, -6.060713),
        (-59.390700, -6.877544),
        (-59.048499, -8.573530)
    ])

# Create the isochron feature.
isochron_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_isochron,
    isochron_geometry_at_time_of_appearance,
    name='SOUTH AMERICAN ANTARCTIC RIDGE, SOUTH AMERICA-ANTARCTICA ANOMALY 18 IS',
    valid_time=(isochron_time_of_appearance, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201,
    conjugate_plate_id=802,
    # The specified geometry is not present day so it needs to be reverse-reconstructed to present day...
    reverse_reconstruct=(rotation_model, isochron_time_of_appearance))

Details

A pygplates.PolylineOnSphere geometry is created from a list of (latitude, longitude) tuples, as in Create a coastline feature from present-day geometry. This polyline is the location of the isochron at 40.1Ma, its time of appearance.

isochron_geometry_at_time_of_appearance = pygplates.PolylineOnSphere(
    [
        (-57.635356,  0.765764),
        (-57.162269, -1.953176),
        (-57.916700, -2.522021),
        (-57.658576, -3.936703),
        (-58.639846, -4.849338),
        (-58.404889, -6.060713),
        (-59.390700, -6.877544),
        (-59.048499, -8.573530)
    ])

A feature is not complete until its geometry is present day geometry. The isochron geometry is not, so the feature has to be reverse reconstructed to present day before it can be reconstructed to an arbitrary reconstruction time. That is done with either the reverse_reconstruct argument, as here, or the function pygplates.reverse_reconstruct().

The isochron feature (of type pygplates.FeatureType.gpml_isochron) is created with pygplates.Feature.create_reconstructable_feature(). It is given the geometry at the time of appearance, a name, a valid time period, a reconstruction plate ID and a conjugate plate ID. The valid time period begins at the time of appearance and ends in the distant future.

The reverse_reconstruct argument is a tuple of a rotation model and the time that the geometry is at, here the time of appearance of the isochron.

# Create the isochron feature.
isochron_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_isochron,
    isochron_geometry_at_time_of_appearance,
    name='SOUTH AMERICAN ANTARCTIC RIDGE, SOUTH AMERICA-ANTARCTICA ANOMALY 18 IS',
    valid_time=(isochron_time_of_appearance, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201,
    conjugate_plate_id=802,
    # The specified geometry is not present day so it needs to be reverse-reconstructed to present day...
    reverse_reconstruct=(rotation_model, isochron_time_of_appearance))

An alternative to the reverse_reconstruct argument is to call the pygplates.reverse_reconstruct() function on the feature after creating it:

isochron_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_isochron,
    isochron_geometry_at_time_of_appearance,
    name='SOUTH AMERICAN ANTARCTIC RIDGE, SOUTH AMERICA-ANTARCTICA ANOMALY 18 IS',
    valid_time=(isochron_time_of_appearance, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201,
    conjugate_plate_id=802)
pygplates.reverse_reconstruct(isochron_feature, rotation_model, isochron_time_of_appearance)

The alternate sample code does not use pygplates.Feature.create_reconstructable_feature(). It first creates an empty pygplates.FeatureType.gpml_isochron feature, and then sets its properties one by one.

# Create the isochron feature.
isochron_feature = pygplates.Feature(pygplates.FeatureType.gpml_isochron)
isochron_feature.set_geometry(isochron_geometry_at_time_of_appearance)
isochron_feature.set_name('SOUTH AMERICAN ANTARCTIC RIDGE, SOUTH AMERICA-ANTARCTICA ANOMALY 18 IS')
isochron_feature.set_valid_time(isochron_time_of_appearance, pygplates.GeoTimeInstant.create_distant_future())
isochron_feature.set_reconstruction_plate_id(201)
isochron_feature.set_conjugate_plate_id(802)

The geometry that was set is not present day geometry, so the feature is then reverse reconstructed to present day.

# The specified geometry is not present day so it needs to be reverse-reconstructed to present day.
pygplates.reverse_reconstruct(isochron_feature, rotation_model, isochron_time_of_appearance)

Warning

pygplates.reverse_reconstruct() is called after the properties have been set on the feature. This is necessary because reverse reconstruction looks at these properties (here the reconstruction plate ID) to determine how to reverse reconstruct.

An alternative is to reverse reconstruct when setting the geometry:

isochron_feature = pygplates.Feature(pygplates.FeatureType.gpml_isochron)
isochron_feature.set_name('SOUTH AMERICAN ANTARCTIC RIDGE, SOUTH AMERICA-ANTARCTICA ANOMALY 18 IS')
isochron_feature.set_valid_time(isochron_time_of_appearance, pygplates.GeoTimeInstant.create_distant_future())
isochron_feature.set_reconstruction_plate_id(201)
isochron_feature.set_conjugate_plate_id(802)

isochron_feature.set_geometry(
    isochron_geometry_at_time_of_appearance,
    reverse_reconstruct=(rotation_model, isochron_time_of_appearance))

Warning

pygplates.Feature.set_geometry() is called after the properties have been set on the feature, for the same reason.

Create a mid-ocean ridge feature from geometry at a past geological time

This example is similar to Create an isochron feature from geometry at a past geological time, except that it creates a type of tectonic section known as a mid-ocean ridge.

See also

Query a mid-ocean ridge feature and Create an isochron feature from geometry at a past geological time

Data files

Both scripts read the same file:

rotations.rot

A rotation file. It is used to reverse reconstruct the ridge geometry from 55.9Ma to present day. That uses the rotations of the ridge’s left plate (201) only, since 55.9Ma becomes the ridge’s geometry import time (see below). Reconstructing the ridge to any other time uses the rotations of its right plate (701) too.

Rotation files are in the GPlates sample data.

Sample code

import pygplates


# Load a rotation model from a rotation file.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create the mid-ocean ridge feature using geometry at a past geological time.
time_of_appearance = 55.9
time_of_disappearance = 48
geometry_at_time_of_appearance = pygplates.PolylineOnSphere(
    [
        (-27.5, -13.0),
        (-30.0, -13.5),
        (-32.5, -14.5),
        (-35.0, -15.5)
    ])
mid_ocean_ridge_feature = pygplates.Feature.create_tectonic_section(
    pygplates.FeatureType.gpml_mid_ocean_ridge,
    geometry_at_time_of_appearance,
    name='SOUTH ATLANTIC, SOUTH AMERICA-AFRICA',
    valid_time=(time_of_appearance, time_of_disappearance),
    left_plate=201,
    right_plate=701,
    reconstruction_method='HalfStageRotationVersion3',
    # The specified geometry is not present day so it needs to be reverse-reconstructed to present day...
    reverse_reconstruct=(rotation_model, time_of_appearance))

Details

This is similar to Create an isochron feature from geometry at a past geological time, except that the feature is created with pygplates.Feature.create_tectonic_section(), since a mid-ocean ridge feature is a type of tectonic section.

A tectonic section can have a left plate, a right plate and a reconstruction method. The reconstruction method here is 'HalfStageRotationVersion3'. A ridge with this method is not reconstructed by a single reconstruction plate ID, but by half-stage rotations between its left and right plates.

The ridge geometry is at 55.9Ma, the time of appearance of the ridge, so the feature is reverse reconstructed to present day with the reverse_reconstruct argument. This also sets the geometry import time of the ridge to 55.9Ma, which is the time that a 'HalfStageRotationVersion3' ridge starts spreading from.

Create a subduction zone feature from present-day geometry

This example is similar to Create a coastline feature from present-day geometry, except that it also sets an enumeration property on a subduction zone.

See also

Query a subduction zone feature and Create a coastline feature from present-day geometry

Sample code

import pygplates


# Create the subduction zone feature.
present_day_geometry = pygplates.PolylineOnSphere(
    [
        (-18.0, -71.5),
        (-23.0, -71.2),
        (-28.0, -71.8),
        (-33.0, -72.8),
        (-38.0, -74.5)
    ])
subduction_zone_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_subduction_zone,
    present_day_geometry,
    name='South America trench',
    valid_time=(200, pygplates.GeoTimeInstant.create_distant_future()),
    reconstruction_plate_id=201)

subduction_zone_feature.set_enumeration(
    pygplates.PropertyName.gpml_subduction_polarity,
    'Right')

Details

The subduction zone feature is created as in Create a coastline feature from present-day geometry. pygplates.Feature.set_enumeration() then sets its subduction polarity to 'Right'.

An enumeration property holds one of a fixed set of values. The subduction polarity is 'Left', 'Right' or 'Unknown': the side of the subduction zone that the overriding plate is on, when following the points of its geometry in order.

    [
        (-18.0, -71.5),
        (-23.0, -71.2),
        (-28.0, -71.8),
        (-33.0, -72.8),
        (-38.0, -74.5)
    ])
subduction_zone_feature = pygplates.Feature.create_reconstructable_feature(
    pygplates.FeatureType.gpml_subduction_zone,

The virtual geomagnetic pole feature is created with pygplates.Feature.create_reconstructable_feature().

The geometry it is given is the pole position, not the average sample site position. This is because gpml:polePosition is the default geometry property of a virtual geomagnetic pole (see its Default Geometry Property label).

A motion path has a point at each of a sequence of times. The more densely the times sample the path, the more accurate it is. Here the times are from 0 to 90Ma in 1My intervals.

A Python list comprehension converts the pole data into a list of time samples of finite rotations. A list comprehension creates one list from another. For example, string_list = [str(item) for item in integer_list] creates a list of strings from a list of integers.

The time samples could have been written out directly, in place of the pole data. Converting a list of pole data is more succinct and easier to read.

A pygplates.GpmlTimeSample expects a property value. So each finite rotation is wrapped in a pygplates.GpmlFiniteRotation, which is a type of property value.
