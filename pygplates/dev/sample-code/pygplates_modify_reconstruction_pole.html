Modify a reconstruction pole

This example:

  • reads a rotation file,

  • modifies a total reconstruction pole so that a point reconstructs to a desired location at a reconstruction time, and

  • writes the modified rotations back to the same rotation file.

This is similar to what the Modify Reconstruction Pole tool does in GPlates.

Data files

rotations.rot

A rotation file. It is read, modified and then written back to the same file, so keep a copy. It must contain a total reconstruction sequence whose moving plate is 801 (the plate of the point being adjusted) with enabled rotation samples spanning 60Ma, and rotations for that sequence’s fixed plate at 60Ma. Crossover tags (@xo_...) in the pole comments are used if present. Rotation files are in the GPlates sample data.

Sample code

import pygplates
import sys


# One or more rotation filenames.
rotation_filenames = ['rotations.rot']

# The reconstruction time (Ma) at which the rotation adjustment needs to be applied.
reconstruction_time = pygplates.GeoTimeInstant(60)

# The plate ID of the plate whose rotation we are adjusting.
reconstruction_plate_id = 801

# The present day point position specified using latitude and longitude (in degrees).
present_day_latitude = -20
present_day_longitude = 135
present_day_position = pygplates.PointOnSphere(
    present_day_latitude, present_day_longitude)

# The desired reconstructed point position specified using latitude and longitude (in degrees).
desired_reconstructed_latitude = -45
desired_reconstructed_longitude = 130
desired_reconstructed_position = pygplates.PointOnSphere(
    desired_reconstructed_latitude, desired_reconstructed_longitude)

# Create a point feature so we can reconstruct it using its plate ID.
point_feature = pygplates.Feature()
point_feature.set_reconstruction_plate_id(reconstruction_plate_id)
point_feature.set_geometry(present_day_position)

# Load the rotation features from rotation files.
# Using a 'pygplates.FeaturesFunctionArgument' to make it easier to write changes back out to the files.
rotation_features = pygplates.FeaturesFunctionArgument(rotation_filenames)

# A rotation model using the rotation features before they are modified.
rotation_model_before_adjustment = pygplates.RotationModel(rotation_features.get_features())

# Reconstruct our point feature to obtain the reconstructed point location.
reconstruct_snapshot = pygplates.ReconstructSnapshot(point_feature, rotation_model_before_adjustment, reconstruction_time)
reconstructed_position = reconstruct_snapshot.get_reconstructed_geometries()[0].get_reconstructed_geometry()

# Print the actual and desired reconstructed point positions to show they are different.
print('Reconstructed lat/lon position before adjustment ({:f}, {:f})'.format(*reconstructed_position.to_lat_lon()))
print('Desired reconstructed lat/lon position ({:f}, {:f})'.format(*desired_reconstructed_position.to_lat_lon()))

# If the actual and desired reconstructed positions are different then adjust rotation feature(s) to make them the same.
if reconstructed_position != desired_reconstructed_position:

    # The rotation that moves the actual reconstructed position to the desired position.
    rotation_adjustment = pygplates.FiniteRotation(reconstructed_position, desired_reconstructed_position)

    # Modify the rotation feature (or features) corresponding to the reconstruction plate ID.
    for rotation_feature in rotation_features.get_features():

        # Get the rotation feature information.
        total_reconstruction_pole = rotation_feature.get_total_reconstruction_pole()
        if not total_reconstruction_pole:
            # Not a rotation feature.
            continue

        fixed_plate_id, moving_plate_id, rotation_sequence = total_reconstruction_pole
        # We're only interested in rotation features whose moving plate ID matches our reconstruction plate ID.
        if moving_plate_id != reconstruction_plate_id:
            continue

        # Get the enabled rotation samples - ignore the disabled samples.
        enabled_rotation_samples = rotation_sequence.get_enabled_time_samples()
        if not enabled_rotation_samples:
            # All time samples are disabled.
            continue

        # Make sure the time span of the rotation feature's enabled samples includes the reconstruction time.
        if not (enabled_rotation_samples[0].get_time() <= reconstruction_time and
                enabled_rotation_samples[-1].get_time() >= reconstruction_time):
            continue

        # Get the finite rotation at the reconstruction time.
        # If the reconstruction time is between rotation samples then it will get interpolated.
        rotation_property_value = rotation_sequence.get_value(reconstruction_time)
        if not rotation_property_value:
            continue
        rotation = rotation_property_value.get_finite_rotation()

        # The rotation adjustment needs to be applied to the rotation feature (total reconstruction pole).
        # Since this is a rotation relative to the fixed plate of the rotation feature, and not the anchored plate,
        # we need to transform the adjustment appropriately before applying it.
        fixed_plate_frame = rotation_model_before_adjustment.get_rotation(reconstruction_time, fixed_plate_id)
        fixed_plate_frame_rotation_adjustment = fixed_plate_frame.get_inverse() * rotation_adjustment * fixed_plate_frame
        adjusted_rotation = fixed_plate_frame_rotation_adjustment * rotation

        # If one of the enabled rotation samples matches the reconstruction time then
        # get its description so we don't clobber it when we write the adjusted rotation.
        rotation_description = None
        for rotation_sample in enabled_rotation_samples:
            if rotation_sample.get_time() == reconstruction_time:
                rotation_description = rotation_sample.get_description()
                break

        # Set the adjusted rotation back into the rotation sequence.
        rotation_sequence.set_value(
            pygplates.GpmlFiniteRotation(adjusted_rotation),
            reconstruction_time,
            rotation_description)

    # Our rotation adjustment may require crossovers to be re-synchronised.
    if not pygplates.synchronise_crossovers(
            rotation_features.get_features(),
            crossover_threshold_degrees = 0.01,
            # Default to 'pygplates.CrossoverType.synch_old_crossover_and_stages' when/if crossover tags
            # are missing in the rotation file...
            crossover_type_function = pygplates.CrossoverTypeFunction.type_from_xo_tags_in_comment_default_xo_ys):
        print('Unable to synchronise all crossovers.', file=sys.stderr)

    # Get a new rotation model that uses the adjusted rotation features.
    rotation_model_after_adjustment = pygplates.RotationModel(rotation_features.get_features())
    reconstruct_snapshot = pygplates.ReconstructSnapshot(point_feature, rotation_model_after_adjustment, reconstruction_time)
    reconstructed_position = reconstruct_snapshot.get_reconstructed_geometries()[0].get_reconstructed_geometry()

    # Print the adjusted reconstructed point position - should now be same as desired position.
    print('Reconstructed lat/lon position after adjustment ({:f}, {:f})'.format(*reconstructed_position.to_lat_lon()))

    # Write the (modified) rotation feature collections back to the files they came from.
    rotation_files = rotation_features.get_files()
    if rotation_files:
        for feature_collection, filename in rotation_files:
            feature_collection.write(filename)

Details

The script starts with the filenames of one or more rotation files. The modified rotations are written back to these files at the end.

# One or more rotation filenames.
rotation_filenames = ['rotations.rot']

The rotation is adjusted at 60Ma.

The reconstruction time is a pygplates.GeoTimeInstant rather than a plain number. Its comparison operators (==, !=, <, <=, >, >=) compare times within a numerical tolerance, which is a good idea whenever floating-point numbers are compared. The script compares the reconstruction time with the times of rotation samples further down.

Here the script would probably still work with reconstruction_time = 60.

# The reconstruction time (Ma) at which the rotation adjustment needs to be applied.
reconstruction_time = pygplates.GeoTimeInstant(60)

There are two positions. The present day position is the point to reconstruct. The desired reconstructed position is where that point should be at 60Ma.

Each is a pygplates.PointOnSphere, created from a latitude and a longitude.

# The present day point position specified using latitude and longitude (in degrees).
present_day_latitude = -20
present_day_longitude = 135
present_day_position = pygplates.PointOnSphere(
    present_day_latitude, present_day_longitude)

# The desired reconstructed point position specified using latitude and longitude (in degrees).
desired_reconstructed_latitude = -45
desired_reconstructed_longitude = 130
desired_reconstructed_position = pygplates.PointOnSphere(
    desired_reconstructed_latitude, desired_reconstructed_longitude)

A point is reconstructed as part of a pygplates.Feature. The feature holds what the reconstruction needs: the plate ID (801) and the present day position.

# Create a point feature so we can reconstruct it using its plate ID.
point_feature = pygplates.Feature()
point_feature.set_reconstruction_plate_id(reconstruction_plate_id)
point_feature.set_geometry(present_day_position)

The rotation files are loaded with the utility class pygplates.FeaturesFunctionArgument. It keeps the features of each file together with the filename, which makes it a little easier to write the modified rotation features back to their files.

Alternatively, each rotation file could be loaded into its own pygplates.FeatureCollection and later saved back to its file.

# Load the rotation features from rotation files.
# Using a 'pygplates.FeaturesFunctionArgument' to make it easier to write changes back out to the files.
rotation_features = pygplates.FeaturesFunctionArgument(rotation_filenames)

A rotation model is created from the rotation features before they are modified. It is used to reconstruct the point, and later to work out the adjustment to the total reconstruction pole.

# A rotation model using the rotation features before they are modified.
rotation_model_before_adjustment = pygplates.RotationModel(rotation_features.get_features())

The point feature is reconstructed to 60Ma, to find where the point actually is at that time.

The point feature has no valid time, which means it exists at all times. So there is exactly one pygplates.ReconstructedFeatureGeometry, and its reconstructed geometry is the reconstructed point.

# Reconstruct our point feature to obtain the reconstructed point location.
reconstruct_snapshot = pygplates.ReconstructSnapshot(point_feature, rotation_model_before_adjustment, reconstruction_time)
reconstructed_position = reconstruct_snapshot.get_reconstructed_geometries()[0].get_reconstructed_geometry()

If the actual reconstructed position differs from the desired reconstructed position then the rotations of plate 801 need to be adjusted.

The rotation adjustment is the rotation from reconstructed_position to desired_reconstructed_position. This constructor of pygplates.FiniteRotation creates the rotation that moves one point to another along the great circle arc between them.

# If the actual and desired reconstructed positions are different then adjust rotation feature(s) to make them the same.
if reconstructed_position != desired_reconstructed_position:

    # The rotation that moves the actual reconstructed position to the desired position.
    rotation_adjustment = pygplates.FiniteRotation(reconstructed_position, desired_reconstructed_position)

The script then iterates over the rotation features, looking for those whose moving plate ID is the plate ID of the point feature. Changing the rotation of that plate moves the point, along with everything else on that plate and on its child plates (the plates that move relative to it at the reconstruction time).

pygplates.Feature.get_total_reconstruction_pole() returns the fixed plate ID, the moving plate ID and the time-varying total reconstruction pole of a rotation feature. It returns None for a feature that does not have all three, which means it is not a rotation feature.

# Modify the rotation feature (or features) corresponding to the reconstruction plate ID.
for rotation_feature in rotation_features.get_features():

    # Get the rotation feature information.
    total_reconstruction_pole = rotation_feature.get_total_reconstruction_pole()
    if not total_reconstruction_pole:
        # Not a rotation feature.
        continue

    fixed_plate_id, moving_plate_id, rotation_sequence = total_reconstruction_pole
    # We're only interested in rotation features whose moving plate ID matches our reconstruction plate ID.
    if moving_plate_id != reconstruction_plate_id:
        continue

The total reconstruction pole is a sequence of time samples. Each sample is the total rotation of the moving plate relative to the fixed plate at one time.

Some of the samples may be disabled. pygplates.GpmlIrregularSampling.get_enabled_time_samples() returns only the enabled ones.

The script continues with this rotation feature only if the reconstruction time is within the time range of its enabled samples, which are ordered from youngest to oldest.

Because reconstruction_time is a pygplates.GeoTimeInstant, these comparisons are made within a numerical tolerance (as mentioned above). So the test passes when the reconstruction time is the time of the first or the last sample.

# Get the enabled rotation samples - ignore the disabled samples.
enabled_rotation_samples = rotation_sequence.get_enabled_time_samples()
if not enabled_rotation_samples:
    # All time samples are disabled.
    continue

# Make sure the time span of the rotation feature's enabled samples includes the reconstruction time.
if not (enabled_rotation_samples[0].get_time() <= reconstruction_time and
        enabled_rotation_samples[-1].get_time() >= reconstruction_time):
    continue

pygplates.GpmlIrregularSampling.get_value() returns the original rotation at the reconstruction time. If the reconstruction time is between two rotation samples then it interpolates between them.

# Get the finite rotation at the reconstruction time.
# If the reconstruction time is between rotation samples then it will get interpolated.
rotation_property_value = rotation_sequence.get_value(reconstruction_time)
if not rotation_property_value:
    continue
rotation = rotation_property_value.get_finite_rotation()

The next step is to adjust the original rotation, so that the present day position reconstructs to the desired reconstructed position.

A point on moving plate \(P_{M}\) is reconstructed to time \(t\) by the equivalent total rotation of that plate. This is its rotation relative to the anchor plate \(P_{A}\), from present day to time \(t\):

\[\text{reconstructed\_position} = R(0 \rightarrow t,P_{A} \rightarrow P_{M}) \times \text{present\_day\_position}\]

Using the approach in Composing finite rotations, the desired reconstructed position can be written in terms of the actual reconstructed position:

\[\begin{split}\text{desired\_reconstructed\_position} &= R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times \text{reconstructed\_position} \\ &= R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times R(0 \rightarrow t,P_{A} \rightarrow P_{M}) \times \text{present\_day\_position}\end{split}\]

Here \(R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position})\) is the rotation adjustment: the rotation from \(\text{reconstructed\_position}\) to \(\text{desired\_reconstructed\_position}\). In pyGPlates it is pygplates.FiniteRotation(reconstructed_position, desired_reconstructed_position).

The composed rotation, from the present day position to the desired reconstructed position, is the adjusted equivalent rotation:

\[\begin{split}\text{desired\_reconstructed\_position} &= R(0 \rightarrow t,P_{A} \rightarrow P_{M})_{adjusted} \times \text{present\_day\_position} \\ R(0 \rightarrow t,P_{A} \rightarrow P_{M})_{adjusted} &= R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times R(0 \rightarrow t,P_{A} \rightarrow P_{M})\end{split}\]

But the pole of a rotation feature is not an equivalent rotation. It is a relative rotation, of the moving plate relative to the fixed plate \(P_{F}\) of the rotation feature.

So the adjusted equivalent rotation (relative to the anchor plate) is rewritten as an adjusted relative rotation (relative to the fixed plate), using the result \(R(P_{A} \rightarrow P_{M}) = R(P_{A} \rightarrow P_{F}) \times R(P_{F} \rightarrow P_{M})\) from Plate circuit paths:

\[\begin{split}R(0 \rightarrow t,P_{A} \rightarrow P_{M})_{adjusted} &= R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times R(0 \rightarrow t,P_{A} \rightarrow P_{M}) \\ R(0 \rightarrow t,P_{A} \rightarrow P_{F}) \times R(0 \rightarrow t,P_{F} \rightarrow P_{M})_{adjusted} &= R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times R(0 \rightarrow t,P_{A} \rightarrow P_{F}) \times R(0 \rightarrow t,P_{F} \rightarrow P_{M})\end{split}\]

Pre-multiplying both sides by \(R(0 \rightarrow t,P_{A} \rightarrow P_{F})^{-1}\) gives:

\[R(0 \rightarrow t,P_{F} \rightarrow P_{M})_{adjusted} = R(0 \rightarrow t,P_{A} \rightarrow P_{F})^{-1} \times R(\text{reconstructed\_position} \rightarrow \text{desired\_reconstructed\_position}) \times R(0 \rightarrow t,P_{A} \rightarrow P_{F}) \times R(0 \rightarrow t,P_{F} \rightarrow P_{M})\]

This gives the adjusted relative rotation \(R(0 \rightarrow t,P_{F} \rightarrow P_{M})_{adjusted}\) in terms of the original relative rotation \(R(0 \rightarrow t,P_{F} \rightarrow P_{M})\).

In pyGPlates this is written as follows, where fixed_plate_frame is \(R(0 \rightarrow t,P_{A} \rightarrow P_{F})\), the equivalent total rotation of the fixed plate:

# The rotation adjustment needs to be applied to the rotation feature (total reconstruction pole).
# Since this is a rotation relative to the fixed plate of the rotation feature, and not the anchored plate,
# we need to transform the adjustment appropriately before applying it.
fixed_plate_frame = rotation_model_before_adjustment.get_rotation(reconstruction_time, fixed_plate_id)
fixed_plate_frame_rotation_adjustment = fixed_plate_frame.get_inverse() * rotation_adjustment * fixed_plate_frame
adjusted_rotation = fixed_plate_frame_rotation_adjustment * rotation

A rotation sample usually has a description, which is the comment at the end of its line in the rotation file. If one of the enabled samples is at the reconstruction time then the script gets its description, so that it is not lost when the adjusted rotation replaces that sample.

# If one of the enabled rotation samples matches the reconstruction time then
# get its description so we don't clobber it when we write the adjusted rotation.
rotation_description = None
for rotation_sample in enabled_rotation_samples:
    if rotation_sample.get_time() == reconstruction_time:
        rotation_description = rotation_sample.get_description()
        break

pygplates.GpmlIrregularSampling.set_value() sets the adjusted relative rotation in the rotation feature, at the reconstruction time. If there is a sample at that time then it is modified, otherwise a new sample is inserted. Either way the sample gets the description found above (or none).

# Set the adjusted rotation back into the rotation sequence.
rotation_sequence.set_value(
    pygplates.GpmlFiniteRotation(adjusted_rotation),
    reconstruction_time,
    rotation_description)

The adjustment can put crossovers out of step. A crossover is a time at which a plate stops moving relative to one fixed plate and starts moving relative to another, so two of its rotation sequences meet there.

The adjustment changes the motion of plate 801 around 60Ma, and with it the motion of every plate below plate 801 in the hierarchy (the plates that move relative to it, the plates that move relative to those, and so on). Suppose a plate crosses over, at a time the adjustment affects, between one of those plates and a plate elsewhere in the hierarchy. Its two rotation sequences no longer agree at the crossover time, so the plate would jump in the reconstruction.

So the script calls pygplates.synchronise_crossovers(). It synchronises every crossover in the rotation features that is out of step by more than crossover_threshold_degrees, and modifies the rotation features in place.

The function needs to know how to synchronise each crossover: by changing the rotation sequence that is younger than the crossover time, or the one that is older. Here that is decided by pygplates.CrossoverTypeFunction.type_from_xo_tags_in_comment_default_xo_ys. It looks for an @xo_ tag in the description of the crossover’s younger pole (its comment in the rotation file), and treats a crossover without a tag as if it had the @xo_ys tag. See pygplates.synchronise_crossovers() for the tags and what they mean.

# Our rotation adjustment may require crossovers to be re-synchronised.
if not pygplates.synchronise_crossovers(
        rotation_features.get_features(),
        crossover_threshold_degrees = 0.01,
        # Default to 'pygplates.CrossoverType.synch_old_crossover_and_stages' when/if crossover tags
        # are missing in the rotation file...
        crossover_type_function = pygplates.CrossoverTypeFunction.type_from_xo_tags_in_comment_default_xo_ys):
    print('Unable to synchronise all crossovers.', file=sys.stderr)

The point feature is then reconstructed again, this time with a rotation model created from the modified rotation features. Its reconstructed position should now be the desired reconstructed position.

# Get a new rotation model that uses the adjusted rotation features.
rotation_model_after_adjustment = pygplates.RotationModel(rotation_features.get_features())
reconstruct_snapshot = pygplates.ReconstructSnapshot(point_feature, rotation_model_after_adjustment, reconstruction_time)
reconstructed_position = reconstruct_snapshot.get_reconstructed_geometries()[0].get_reconstructed_geometry()

# Print the adjusted reconstructed point position - should now be same as desired position.
print('Reconstructed lat/lon position after adjustment ({:f}, {:f})'.format(*reconstructed_position.to_lat_lon()))

The last step is to write the modified rotation features back to the files they came from. pygplates.FeaturesFunctionArgument.get_files() returns each feature collection that was loaded from a file, along with its filename.

# Write the (modified) rotation feature collections back to the files they came from.
rotation_files = rotation_features.get_files()
if rotation_files:
    for feature_collection, filename in rotation_files:
        feature_collection.write(filename)
