Calculate net rotation

This example calculates the total net rotation of a topological model at each geological time in a time period. At each time it also calculates the individual net rotation of each topological plate polygon (and deforming network).

  • Sample code

  • Details

Data files

topologies.gpml

Topological plate polygon and/or deforming network features. Each plate polygon should have a reconstruction plate ID: one without is treated as plate zero, and still contributes.

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological features.

Files of these kinds are in the GPlates sample data.

Sample code

import math
import pygplates


# Create a topological model from our topological features (can be plate polygons and/or deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Create a net rotation model from the topological model.
# Net rotations will be calculated with a velocity delta from 'time + 1.0' to 'time'.
net_rotation_model = pygplates.NetRotationModel(topological_model, 1.0, pygplates.VelocityDeltaTimeType.t_plus_delta_t_to_t)

# We'll query net rotation from 410Ma to present day in 1 Myr intervals.
max_time = 410
time_increment = 1

# Iterate over the time snapshots of net rotation.
for time in range(0, max_time+1, time_increment):

    # Print the current time.
    print(f'Time {time}:')

    # Net rotation snapshot at the current 'time'.
    net_rotation_snapshot = net_rotation_model.net_rotation_snapshot(time)

    # The total net rotation over the entire globe (over all topologies) at the current 'time'.
    total_net_rotation = net_rotation_snapshot.get_total_net_rotation()

    # The magnitude of the rotation rate vector is the rotation rate in radians per million years.
    total_rotation_rate_in_radians_per_myr = total_net_rotation.get_rotation_rate_vector().get_magnitude()

    # Print the total net rotation.
    print(f'  Total net rotation: {math.degrees(total_rotation_rate_in_radians_per_myr)} degrees/myr')

    # Iterate over each resolved topology at the current time.
    for resolved_topology in net_rotation_snapshot.get_topological_snapshot().get_resolved_topologies():

        # Net rotation for the current resolved topology.
        net_rotation = net_rotation_snapshot.get_net_rotation(resolved_topology)

        # Not all resolved topologies in our topological snapshot will necessarily contribute net rotation.
        if net_rotation:

            # An alternative way to extract the rotation rate (in degrees per million years) just to demonstrate extracting
            # from a finite rotation instead of a rotation rate vector (like we did above for the total net rotation).
            _, _, rotation_rate_in_degrees_per_myr = net_rotation.get_finite_rotation().get_lat_lon_euler_pole_and_angle_degrees()

            # The area of current topology covered by the net rotation point samples (used to calculate net rotation).
            sampled_area_in_square_kms = net_rotation.get_area() * pygplates.Earth.mean_radius_in_kms**2

            # Print the current topology's net rotation and sampled area.
            print(f'  Topology "{resolved_topology.get_feature().get_name()}" has net rotation '
                  f'{rotation_rate_in_degrees_per_myr} degrees/myr sampled over an area of '
                  f'{sampled_area_in_square_kms} square kms')

Details

A topological model is created from the topological features and the rotation file. The topological features can be plate polygons, deforming networks or both.

Here there is one file of topological features and one rotation file. More than one of each can be given, and a pygplates.RotationModel can be given in place of the rotation files.

# Create a topological model from our topological features (can be plate polygons and/or deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

A net rotation model is created from the topological model. The other two arguments give the time interval over which net rotation is calculated: here from time + 1.0 to time.

Net rotation is calculated at a distribution of points over the globe. The point_distribution argument of pygplates.NetRotationModel.__init__() can change it. It is left as the default here, which is the same as the GPlates net rotation export: 180 x 360 uniformly spaced latitude-longitude points.

# Create a net rotation model from the topological model.
# Net rotations will be calculated with a velocity delta from 'time + 1.0' to 'time'.
net_rotation_model = pygplates.NetRotationModel(topological_model, 1.0, pygplates.VelocityDeltaTimeType.t_plus_delta_t_to_t)

The script then iterates over a sequence of times. At each time it gets a net rotation snapshot from the net rotation model.

for time in range(0, max_time+1, time_increment):
    ...
    net_rotation_snapshot = net_rotation_model.net_rotation_snapshot(time)

pygplates.NetRotationSnapshot.get_total_net_rotation() returns the total net rotation, over the entire globe, at the current time.

It is a pygplates.NetRotation. This can give the net rotation either as a finite rotation or as a rotation rate vector.

# The total net rotation over the entire globe (over all topologies) at the current 'time'.
total_net_rotation = net_rotation_snapshot.get_total_net_rotation()

Here the script gets the total net rotation as a rotation rate vector (the choice is arbitrary). This is a 3D vector whose direction is the rotation pole, and whose magnitude is the rotation rate in radians per million years. The script uses only the rotation rate.

# The magnitude of the rotation rate vector is the rotation rate in radians per million years.
total_rotation_rate_in_radians_per_myr = total_net_rotation.get_rotation_rate_vector().get_magnitude()

Next is the individual net rotation of each resolved topology (topological plate polygon or deforming network) at the current time.

pygplates.NetRotationSnapshot.get_topological_snapshot() returns the topological snapshot that the net rotation snapshot was calculated from, and pygplates.TopologicalSnapshot.get_resolved_topologies() returns its resolved topological boundaries and networks. For each of these, pygplates.NetRotationSnapshot.get_net_rotation() returns its net rotation.

Not every resolved topology contributes to net rotation. One that contains none of the sample points does not (it might be so thin that it falls between the points). Its net rotation is then None.

for resolved_topology in net_rotation_snapshot.get_topological_snapshot().get_resolved_topologies():
    net_rotation = net_rotation_snapshot.get_net_rotation(resolved_topology)
    if net_rotation:
        ...

For each resolved topology that does contribute, the script gets its net rotation as a finite rotation. This is only to contrast with the total net rotation above. Either could have been a finite rotation or a rotation rate vector.

The finite rotation is the net rotation over one million years, so its angle is the rotation rate. Again the script uses only the rotation rate, and ignores the rotation pole.

# An alternative way to extract the rotation rate (in degrees per million years) just to demonstrate extracting
# from a finite rotation instead of a rotation rate vector (like we did above for the total net rotation).
_, _, rotation_rate_in_degrees_per_myr = net_rotation.get_finite_rotation().get_lat_lon_euler_pole_and_angle_degrees()

The script also gets the area of each of those resolved topologies. This is the area covered by the sample points that are inside the topology, in steradians (square radians). Multiplying it by the square of the Earth’s radius converts it to square kilometres.

# The area of current topology covered by the net rotation point samples (used to calculate net rotation).
sampled_area_in_square_kms = net_rotation.get_area() * pygplates.Earth.mean_radius_in_kms**2

The accuracy of this area depends on how many sample points were used to calculate net rotation. If an accurate area is needed, it is better to calculate the polygon area of the resolved topology.
