Calculate velocities of plate boundaries

This example calculates the velocities of the points along the boundaries of resolved topological plates (and deforming networks): how fast the boundaries themselves are moving.

A plate boundary does not move with the plate inside it. The boundary of a topological plate is assembled from sections (trenches, ridges and so on), each a feature that moves in its own way, and each point of the resolved boundary moves as the section it comes from does. A trench might move with the plate that overrides it, and a mid-ocean ridge spreads midway between the two plates beside it.

So the velocity of a boundary point need not be the velocity that either of the plates beside it has there. (For those see Calculate velocities in dynamic plates, and for how fast two plates converge across a boundary see Find divergence at subduction zones and convergence at ridges.)

This example finds the velocity of each boundary point, and the boundary section each belongs to, and prints the mean speed of each section of each plate’s boundary.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the boundary sections that the topologies are built from, since those are what move the boundary points.

topologies.gpml

Topological plate polygon features, with or without deforming network features, and the boundary section features that they reference.

Files of these kinds are in the GPlates sample data.

Sample code

import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Calculate velocities at 10Ma using a delta time interval of 1My.
reconstruction_time = 10
delta_time = 1

# Get a snapshot of our resolved topologies at the reconstruction time.
topological_snapshot = topological_model.topological_snapshot(reconstruction_time)

# Iterate over the resolved topological plates (and deforming networks).
for resolved_topology in topological_snapshot.get_resolved_topologies():

    # The points of the plate's boundary, resolved at the reconstruction time.
    boundary_points = resolved_topology.get_resolved_geometry_points()

    # The velocity of each boundary point, from 'reconstruction_time + delta_time' to 'reconstruction_time'.
    boundary_velocity_vectors = resolved_topology.get_resolved_geometry_point_velocities(
            velocity_delta_time=delta_time)

    # The feature that each boundary point comes from: the trench, ridge or other boundary section it is a point of.
    boundary_point_features = resolved_topology.get_resolved_geometry_point_features()

    # Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
    boundary_velocities = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
            boundary_points,
            boundary_velocity_vectors)

    # Group the speeds (velocity magnitudes) of the boundary points by the boundary section they belong to.
    # Each dictionary is keyed by the feature ID of a boundary section.
    section_features = {}
    section_speeds = {}
    for boundary_point_feature, (speed, azimuth, inclination) in zip(boundary_point_features, boundary_velocities):
        section_feature_id = boundary_point_feature.get_feature_id()
        if section_feature_id not in section_features:
            section_features[section_feature_id] = boundary_point_feature
            section_speeds[section_feature_id] = []
        section_speeds[section_feature_id].append(speed)

    plate_feature = resolved_topology.get_feature()
    print(f'Plate {plate_feature.get_reconstruction_plate_id()} ({plate_feature.get_name()}) '
          f'has {len(boundary_points)} boundary points:')
    for section_feature_id, section_feature in section_features.items():
        speeds = section_speeds[section_feature_id]
        mean_speed = sum(speeds) / len(speeds)
        print(f'  {len(speeds)} on {section_feature.get_feature_type()} "{section_feature.get_name()}", '
              f'mean speed {mean_speed:.1f} km/My')

Details

A topological model is created from the topological features and the rotation file.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

The velocities are calculated at boundaries resolved at 10Ma. And the velocities are calculated over a 1My interval from 11Ma to 10Ma.

# Calculate velocities at 10Ma using a delta time interval of 1My.
reconstruction_time = 10
delta_time = 1

The topological features are resolved at 10Ma using pygplates.TopologicalModel.topological_snapshot().

# Get a snapshot of our resolved topologies at the reconstruction time.
topological_snapshot = topological_model.topological_snapshot(reconstruction_time)

pygplates.TopologicalSnapshot.get_resolved_topologies() returns a pygplates.ResolvedTopologicalBoundary for each topological plate and a pygplates.ResolvedTopologicalNetwork for each deforming network. The three methods used below are methods of both.

# Iterate over the resolved topological plates (and deforming networks).
for resolved_topology in topological_snapshot.get_resolved_topologies():

get_resolved_geometry_points() returns the points of the resolved boundary, as a list of pygplates.PointOnSphere (see pygplates.ResolvedTopologicalBoundary.get_resolved_geometry_points()).

They are in order around the boundary, one section after another. Where two sections cross or touch, the point where they meet appears twice: once as the last point of one section and once as the first point of the next.

# The points of the plate's boundary, resolved at the reconstruction time.
boundary_points = resolved_topology.get_resolved_geometry_points()

get_resolved_geometry_point_velocities() returns the velocities of those points, in the same order (see pygplates.ResolvedTopologicalBoundary.get_resolved_geometry_point_velocities()).

This is a list of pygplates.Vector3D (one global cartesian velocity vector per point), in kilometres per million years unless the velocity_units argument says otherwise.

By default each velocity is calculated from reconstruction_time + velocity_delta_time to reconstruction_time.

# The velocity of each boundary point, from 'reconstruction_time + delta_time' to 'reconstruction_time'.
boundary_velocity_vectors = resolved_topology.get_resolved_geometry_point_velocities(
        velocity_delta_time=delta_time)

get_resolved_geometry_point_features() returns the feature that each point comes from, again in the same order (see pygplates.ResolvedTopologicalBoundary.get_resolved_geometry_point_features()).

That feature is the boundary section the point belongs to, and it is what determines the velocity of the point. A point of a section that has a reconstruction plate ID moves with that plate. A point of a mid-ocean ridge that is reconstructed by half-stage rotation moves midway between its left and right plates.

# The feature that each boundary point comes from: the trench, ridge or other boundary section it is a point of.
boundary_point_features = resolved_topology.get_resolved_geometry_point_features()

The vectors are converted to local (magnitude, azimuth, inclination) tuples, one per point, using pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination().

Each point determines its own local coordinate system. For example, the velocity azimuth is relative to North as viewed from that point.

# Convert global 3D velocity vectors to local (magnitude, azimuth, inclination) tuples (one tuple per point).
boundary_velocities = pygplates.LocalCartesian.convert_from_geocentric_to_magnitude_azimuth_inclination(
        boundary_points,
        boundary_velocity_vectors)

The speeds of the points are grouped by boundary section.

The sections are told apart by feature ID, which is the key of both dictionaries: one keeps the feature of each section, and the other a list of the speeds of its points.

# Group the speeds (velocity magnitudes) of the boundary points by the boundary section they belong to.
# Each dictionary is keyed by the feature ID of a boundary section.
section_features = {}
section_speeds = {}
for boundary_point_feature, (speed, azimuth, inclination) in zip(boundary_point_features, boundary_velocities):
    section_feature_id = boundary_point_feature.get_feature_id()
    if section_feature_id not in section_features:
        section_features[section_feature_id] = boundary_point_feature
        section_speeds[section_feature_id] = []
    section_speeds[section_feature_id].append(speed)

Finally the sections of the plate’s boundary are printed, each with its feature type (such as gpml:SubductionZone), its name, its number of points and their mean speed.

The plate ID and name of the plate itself come from its feature (pygplates.ResolvedTopologicalBoundary.get_feature(), or pygplates.ResolvedTopologicalNetwork.get_feature() for a network).

plate_feature = resolved_topology.get_feature()
print(f'Plate {plate_feature.get_reconstruction_plate_id()} ({plate_feature.get_name()}) '
      f'has {len(boundary_points)} boundary points:')
for section_feature_id, section_feature in section_features.items():
    speeds = section_speeds[section_feature_id]
    mean_speed = sum(speeds) / len(speeds)
    print(f'  {len(speeds)} on {section_feature.get_feature_type()} "{section_feature.get_name()}", '
          f'mean speed {mean_speed:.1f} km/My')

Note

A boundary that two plates share is visited twice here, once for each plate. To visit each boundary once, iterate over pygplates.TopologicalSnapshot.get_resolved_topological_sections() and the shared sub-segments of each (as Find the total length of ridges and subduction zones does). A pygplates.ResolvedTopologicalSharedSubSegment has the same three methods, as do a pygplates.ResolvedTopologicalSubSegment and a pygplates.ResolvedTopologicalLine.

Note

These are velocities at the points that the boundary happens to have, which can be far apart along a straight section. pygplates.TopologicalSnapshot.calculate_plate_boundary_statistics() calculates the velocity of the boundary at points uniformly spaced along it (pygplates.PlateBoundaryStatistic.boundary_velocity), with the velocities of the plates on either side.
