Find overriding plate of closest subducting line

This example finds the overriding plate of the subducting line that is nearest to each of a set of features, over a series of geological times. At each time it:

  • reconstructs the regular features,

  • resolves the topological plate boundaries,

  • finds the subducting line (in the topological plate boundaries) that is nearest to each regular feature, and

  • determines the overriding plate of that subducting line.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the features in features.gpml and topologies.gpml.

features.gpml

Regular (non-topological) features, each with a reconstruction plate ID and one or more geometries. The output below was captured with spreading ridges.

topologies.gpml

Topological plate polygon and/or deforming network features, and the boundary section features that they reference. Subduction zones are recognised by the feature type (pygplates.FeatureType.gpml_subduction_zone) of the boundary section features, and each needs a subduction polarity, since that is what determines its overriding plate.

Files of these kinds are in the GPlates sample data.

Sample code

import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create a reconstruct model from some regular (non-topological) features and the rotation model.
reconstruct_model = pygplates.ReconstructModel('features.gpml', rotation_model)

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and the rotation model.
topological_model = pygplates.TopologicalModel('topologies.gpml', rotation_model)

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    print(f'Time {time:f}')

    # Reconstruct the regular features to the current 'time'.
    reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)
    reconstructed_features = reconstruct_snapshot.get_reconstructed_features()

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)
    # Extract the boundary sections between our resolved topological plate polygons (and deforming networks) from the current snapshot.
    shared_boundary_sections = topological_snapshot.get_resolved_topological_sections()

    # Iterate over all reconstructed features.
    for feature, feature_reconstructed_geometries in reconstructed_features:

        # Print out the feature name.
        print(f'  Feature: {feature.get_name()}')

        #
        # Find the nearest subducting line (in the resolved topologies) to the current feature.
        #

        # The minimum distance of the current feature (its geometries) to all subducting lines in resolved topologies.
        min_distance_to_all_subducting_lines = None
        nearest_shared_sub_segment = None

        # Iterate over all reconstructed geometries of the current feature.
        for feature_reconstructed_geometry in feature_reconstructed_geometries:

            # Iterate over the shared boundary sections of all resolved topologies.
            for shared_boundary_section in shared_boundary_sections:

                # Skip sections that are not subduction zones.
                # We're only interested in closeness to subducting lines.
                if shared_boundary_section.get_feature().get_feature_type() != pygplates.FeatureType.gpml_subduction_zone:
                    continue

                # Iterate over the shared sub-segments of the current subducting line.
                # These are the parts of the subducting line that actually contribute to topological boundaries.
                for shared_sub_segment in shared_boundary_section.get_shared_sub_segments():

                    # Get the minimum distance from the current reconstructed geometry to
                    # the current subducting line.
                    min_distance_to_subducting_line = (
                            feature_reconstructed_geometry.get_reconstructed_geometry().distance(
                                    shared_sub_segment.get_resolved_geometry(),
                                    min_distance_to_all_subducting_lines))

                    # If the current subducting line is nearer than all previous ones
                    # then it's the nearest subducting line so far.
                    if min_distance_to_subducting_line is not None:
                        min_distance_to_all_subducting_lines = min_distance_to_subducting_line
                        nearest_shared_sub_segment = shared_sub_segment

        # We should have found the nearest subducting line.
        if nearest_shared_sub_segment is None:
            print('    Unable to find the nearest subducting line:')
            print('      either feature has no geometries or there are no subducting lines in topologies.')
            continue

        # Determine the overriding plate of the subducting line.
        overriding_plate = nearest_shared_sub_segment.get_overriding_plate()
        if not overriding_plate:
            print(f'    Unable to find the overriding plate of the nearest subducting line "{nearest_shared_sub_segment.get_feature().get_name()}"')
            print('      topology on overriding side of subducting line is missing.')
            continue

        # Success - we've found the overriding plate of the nearest subduction zone to the current feature.
        # So print out the overriding plate ID and the distance to nearest subducting line.
        print(f'    overriding plate ID: {overriding_plate.get_feature().get_reconstruction_plate_id()}')
        print(f'    distance to subducting line: {min_distance_to_all_subducting_lines * pygplates.Earth.mean_radius_in_kms:f}Kms')

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

A reconstruct model is created from the regular (non-topological) features and the rotation model. These are the features whose nearest subducting lines are to be found.

# Create a reconstruct model from some regular (non-topological) features and the rotation model.
reconstruct_model = pygplates.ReconstructModel('features.gpml', rotation_model)

A topological model is created from the topological features and the rotation model.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and the rotation model.
topological_model = pygplates.TopologicalModel('topologies.gpml', rotation_model)

pygplates.ReconstructModel.reconstruct_snapshot() reconstructs the regular features to the current time, and returns the result as a pygplates.ReconstructSnapshot.

pygplates.ReconstructSnapshot.get_reconstructed_features() then returns the reconstructed feature geometries grouped by their feature.

# Reconstruct the regular features to the current 'time'.
reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)
reconstructed_features = reconstruct_snapshot.get_reconstructed_features()

Each item in the reconstructed_features list is a tuple of a feature and a list of its reconstructed geometries. A feature can have more than one geometry, and so more than one reconstructed geometry.

for feature, feature_reconstructed_geometries in reconstructed_features:
    ...
    for feature_reconstructed_geometry in feature_reconstructed_geometries:

pygplates.TopologicalModel.topological_snapshot() resolves the topological features at the current time, and returns the result as a pygplates.TopologicalSnapshot.

pygplates.TopologicalSnapshot.get_resolved_topological_sections() then returns the boundary sections of the resolved topologies in the snapshot. By default these are the sections on the boundaries of both the resolved plate polygons (pygplates.ResolvedTopologicalBoundary) and the resolved deforming networks (pygplates.ResolvedTopologicalNetwork).

# Get a snapshot of our resolved topologies at the current 'time'.
topological_snapshot = topological_model.topological_snapshot(time)
# Extract the boundary sections between our resolved topological plate polygons (and deforming networks) from the current snapshot.
shared_boundary_sections = topological_snapshot.get_resolved_topological_sections()

These boundary sections are used because each of their sub-segments has a list of the topologies that share it. That list is searched to find the overriding plate of a subducting line.

A boundary section whose feature is not a subduction zone is skipped, since only subducting lines are of interest.

Not all of the geometry of a boundary section feature is on the boundary of a topology. For example, the ends of a section that extend past its neighbouring sections are clipped off. pygplates.ResolvedTopologicalSection.get_shared_sub_segments() returns the parts that are on a boundary.

for shared_boundary_section in shared_boundary_sections:
    if shared_boundary_section.get_feature().get_feature_type() != pygplates.FeatureType.gpml_subduction_zone:
        continue
    for shared_sub_segment in shared_boundary_section.get_shared_sub_segments():
        ...

For each regular feature, the script finds the minimum distance from the feature to all the subducting lines. To begin with there is no minimum distance, and no nearest subducting line (shared sub-segment).

# The minimum distance of the current feature (its geometries) to all subducting lines in resolved topologies.
min_distance_to_all_subducting_lines = None
nearest_shared_sub_segment = None

The distance() method of the reconstructed geometry returns the minimum distance from the reconstructed regular feature to a subducting line.

min_distance_to_all_subducting_lines is the distance threshold. With a threshold, the method returns None for a subducting line that is further away than the threshold. Only a subducting line that is nearer than the nearest one found so far is of interest.

# Get the minimum distance from the current reconstructed geometry to
# the current subducting line.
min_distance_to_subducting_line = (
        feature_reconstructed_geometry.get_reconstructed_geometry().distance(
                shared_sub_segment.get_resolved_geometry(),
                min_distance_to_all_subducting_lines))

If None was returned, the current subducting line is further away than min_distance_to_all_subducting_lines, and is ignored.

Otherwise the current subducting line is the nearest one found so far. It becomes the nearest subducting line (shared sub-segment), and its distance becomes the new minimum distance.

# If the current subducting line is nearer than all previous ones
# then it's the nearest subducting line so far.
if min_distance_to_subducting_line is not None:
    min_distance_to_all_subducting_lines = min_distance_to_subducting_line
    nearest_shared_sub_segment = shared_sub_segment

Once the nearest subducting line is found, pygplates.ResolvedTopologicalSharedSubSegment.get_overriding_plate() returns its overriding plate.

The method uses the subduction polarity of the subducting line to decide whether the overriding plate is on its left or its right side. It then searches the resolved topologies that share the subducting line, to find the single plate (or deforming network) on that side.

It returns None if the subducting line has no subduction polarity of 'Left' or 'Right', or if it cannot find a single plate (or network) on the overriding side.

# Determine the overriding plate of the subducting line.
overriding_plate = nearest_shared_sub_segment.get_overriding_plate()

Finally the script prints the plate ID of the overriding plate, and the distance from the current feature to its nearest subducting line.

# Success - we've found the overriding plate of the nearest subduction zone to the current feature.
# So print out the overriding plate ID and the distance to nearest subducting line.
print(f'    overriding plate ID: {overriding_plate.get_feature().get_reconstruction_plate_id()}')
print(f'    distance to subducting line: {min_distance_to_all_subducting_lines * pygplates.Earth.mean_radius_in_kms:f}Kms')
