Find divergence at subduction zones and convergence at ridges

This example finds points on plate boundaries, over a series of geological times:

  • where the plates converge along boundary sections labelled as mid-ocean ridges, and

  • where the plates diverge along boundary sections labelled as subduction zones.

This is useful for locating the parts of mid-ocean ridges that are not diverging as expected, and the parts of subduction zones that are not converging as expected.

Data files

topologies.gpml

Topological plate polygon and/or deforming network features, and the boundary section features that they reference. Mid-ocean ridges and subduction zones are recognised by the feature type (pygplates.FeatureType.gpml_mid_ocean_ridge or pygplates.FeatureType.gpml_subduction_zone) of the boundary section features.

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the topological features.

Files of these kinds are in the GPlates sample data.

Sample code

import math
import pygplates


# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

# Our geological times will be from 0Ma to 'num_time_steps' Ma (inclusive) in 1 My intervals.
num_time_steps = 140

# Threshold for detecting divergence or convergence (in cms/yr).
divergence_convergence_threshold_cms_per_yr = 0.1

converging_mid_ocean_ridge_features = []
diverging_subduction_zone_features = []

# 'time' = 0, 1, 2, ... , 140
for time in range(num_time_steps + 1):

    # Get a snapshot of our resolved topologies at the current 'time'.
    topological_snapshot = topological_model.topological_snapshot(time)

    # Define a function so we don't have to write the same code twice.
    def calculate_converging_or_diverging_points(
            boundary_section_feature_type,
            divergence_convergence_threshold_cms_per_yr,
            find_converging_points):
        """
        Calculate plate boundary statistics along boundary sections with feature type 'boundary_section_feature_type'.
        If 'find_converging_points' is True then find converging points, otherwise find diverging points.
        """

        # Calculate statistics along plate boundary sections labelled with the requested feature type.
        plate_boundary_statistics = topological_snapshot.calculate_plate_boundary_statistics(
                math.radians(1),  # 1 degree spacing between points
                velocity_units=pygplates.VelocityUnits.cms_per_yr,
                boundary_section_filter=boundary_section_feature_type)

        # Record points satisfying the converging/diverging criteria (and record their convergence velocities)
        points = []
        convergence_velocities = []
        for stat in plate_boundary_statistics:
            # If unable to calculate convergence velocity at the current point then skip it.
            if math.isnan(stat.convergence_velocity_signed_magnitude):
                continue

            # See if current point is converging (if 'find_converging_points' is True) or
            # diverging (if 'find_converging_points' is False).
            if ((find_converging_points and stat.convergence_velocity_signed_magnitude > divergence_convergence_threshold_cms_per_yr) or
                (not find_converging_points and stat.convergence_velocity_signed_magnitude < -divergence_convergence_threshold_cms_per_yr)):
                points.append(stat.boundary_point)
                convergence_velocities.append(stat.convergence_velocity_signed_magnitude)

        # If there were no points satisfying the converging/diverging criteria then return early.
        if not points:
            return None

        # Create a feature containing the points (and their convergence velocities).
        points_feature = pygplates.Feature()
        # Feature only exists at the current 'time' (for display in GPlates).
        points_feature.set_valid_time(time + 0.5, time - 0.5)
        # Set the geometry as a coverage geometry (ie, a multipoint and scalar values).
        # The convergence velocity scalar values will show up in GPlates as a separate layer.
        points_feature.set_geometry(
            (
                pygplates.MultiPointOnSphere(points),
                {
                    pygplates.ScalarType.create_gpml('ConvergenceVelocity') : convergence_velocities,
                }
            )
        )

        return points_feature

    # Find converging points along mid-ocean ridges.
    converging_mid_ocean_ridge_points_feature = calculate_converging_or_diverging_points(
        pygplates.FeatureType.gpml_mid_ocean_ridge,
        divergence_convergence_threshold_cms_per_yr,
        True)  # find converging points
    if converging_mid_ocean_ridge_points_feature:
        converging_mid_ocean_ridge_features.append(converging_mid_ocean_ridge_points_feature)

    # Find diverging points along subduction zones.
    diverging_subduction_zone_points_feature = calculate_converging_or_diverging_points(
        pygplates.FeatureType.gpml_subduction_zone,
        divergence_convergence_threshold_cms_per_yr,
        False)  # find diverging points
    if diverging_subduction_zone_points_feature:
        diverging_subduction_zone_features.append(diverging_subduction_zone_points_feature)

# Write all points at all times along mid-ocean ridges that are converging.
pygplates.FeatureCollection(converging_mid_ocean_ridge_features).write('converging-mid-ocean-ridge-points.gpmlz')

# Write all points at all times along subduction zones that are diverging.
pygplates.FeatureCollection(diverging_subduction_zone_features).write('diverging-subduction-zone-points.gpmlz')

Details

A topological model is created from the topological features and the rotation file. The topological features can be plate polygons, deforming networks or both.

Here there is one file of topological features and one rotation file. More than one of each can be given, and a pygplates.RotationModel can be given in place of the rotation files.

# Create a topological model from the topological plate polygon features (can also include deforming networks)
# and rotation file(s).
topological_model = pygplates.TopologicalModel('topologies.gpml', 'rotations.rot')

Note

The pygplates.TopologicalModel is created outside the time loop, since it does not depend on time.

pygplates.TopologicalModel.topological_snapshot() resolves the topological features at the current time, and returns the result as a pygplates.TopologicalSnapshot.

# Get a snapshot of our resolved topologies at the current 'time'.
topological_snapshot = topological_model.topological_snapshot(time)

Next a function is defined that finds the converging, or the diverging, points along one type of plate boundary. It is a function so that very similar code is not written twice: once for converging points and once for diverging points.

The function has three arguments:

  • the feature type of the boundary sections to look at (mid-ocean ridges or subduction zones, for example),

  • a velocity threshold, which the plates must converge or diverge faster than, and

  • whether to find converging points (True) or diverging points (False).

def calculate_converging_or_diverging_points(
        boundary_section_feature_type,
        divergence_convergence_threshold_cms_per_yr,
        find_converging_points):

The function first calls pygplates.TopologicalSnapshot.calculate_plate_boundary_statistics(). It generates points along the plate boundaries, and returns a pygplates.PlateBoundaryStatistic for each point.

Here the points are spaced 1 degree apart, and velocities are in centimetres per year. With boundary_section_filter set to a feature type, there are only points along the boundary sections of that feature type.

# Calculate statistics along plate boundary sections labelled with the requested feature type.
plate_boundary_statistics = topological_snapshot.calculate_plate_boundary_statistics(
        math.radians(1),  # 1 degree spacing between points
        velocity_units=pygplates.VelocityUnits.cms_per_yr,
        boundary_section_filter=boundary_section_feature_type)

The function then iterates over the statistics, to collect the locations and convergence velocities of the points it is looking for.

# Record points satisfying the converging/diverging criteria (and record their convergence velocities)
points = []
convergence_velocities = []
for stat in plate_boundary_statistics:

At some points there might be no plate (or network) on one side of the boundary. This happens where the topological model does not cover the whole globe, or where there is an unintended gap between plates. The convergence velocity is then float('nan'), and the point is skipped.

# If unable to calculate convergence velocity at the current point then skip it.
if math.isnan(stat.convergence_velocity_signed_magnitude):
    continue

stat.convergence_velocity_signed_magnitude is a signed magnitude. It is positive where the plates are converging and negative where they are diverging.

So a converging point is one where it is greater than the threshold. And a diverging point is one where it is less than minus the threshold (the plates are diverging faster than the threshold). The location and convergence velocity of each such point are added to two lists.

# See if current point is converging (if 'find_converging_points' is True) or
# diverging (if 'find_converging_points' is False).
if ((find_converging_points and stat.convergence_velocity_signed_magnitude > divergence_convergence_threshold_cms_per_yr) or
    (not find_converging_points and stat.convergence_velocity_signed_magnitude < -divergence_convergence_threshold_cms_per_yr)):
    points.append(stat.boundary_point)
    convergence_velocities.append(stat.convergence_velocity_signed_magnitude)

If any points were found, a feature is created to hold them and their convergence velocities.

The feature is given a valid time that extends half a million years either side of the current time. So when the features of all the times are loaded into GPlates, each one is only visible at its own time.

Its geometry is set as a coverage: a multipoint, and a scalar value at each of its points. GPlates displays the scalar values, here the convergence velocities, in a separate layer.

# Create a feature containing the points (and their convergence velocities).
points_feature = pygplates.Feature()
# Feature only exists at the current 'time' (for display in GPlates).
points_feature.set_valid_time(time + 0.5, time - 0.5)
# Set the geometry as a coverage geometry (ie, a multipoint and scalar values).
# The convergence velocity scalar values will show up in GPlates as a separate layer.
points_feature.set_geometry(
    (
        pygplates.MultiPointOnSphere(points),
        {
            pygplates.ScalarType.create_gpml('ConvergenceVelocity') : convergence_velocities,
        }
    )
)

That is the end of the function calculate_converging_or_diverging_points. It is called twice at each time: once to find the converging points along mid-ocean ridges, and once to find the diverging points along subduction zones.

# Find converging points along mid-ocean ridges.
converging_mid_ocean_ridge_points_feature = calculate_converging_or_diverging_points(
    pygplates.FeatureType.gpml_mid_ocean_ridge,
    divergence_convergence_threshold_cms_per_yr,
    True)  # find converging points
if converging_mid_ocean_ridge_points_feature:
    converging_mid_ocean_ridge_features.append(converging_mid_ocean_ridge_points_feature)

# Find diverging points along subduction zones.
diverging_subduction_zone_points_feature = calculate_converging_or_diverging_points(
    pygplates.FeatureType.gpml_subduction_zone,
    divergence_convergence_threshold_cms_per_yr,
    False)  # find diverging points
if diverging_subduction_zone_points_feature:
    diverging_subduction_zone_features.append(diverging_subduction_zone_points_feature)

Finally the features are written to two files. The first file has the points along mid-ocean ridges that are converging, at all times. The second file has the points along subduction zones that are diverging, at all times.

# Write all points at all times along mid-ocean ridges that are converging.
pygplates.FeatureCollection(converging_mid_ocean_ridge_features).write('converging-mid-ocean-ridge-points.gpmlz')

# Write all points at all times along subduction zones that are diverging.
pygplates.FeatureCollection(diverging_subduction_zone_features).write('diverging-subduction-zone-points.gpmlz')

The two files can now be loaded into GPlates, along with the topological model they were generated from. This shows which parts of mid-ocean ridges are unexpectedly converging, and which parts of subduction zones are unexpectedly diverging.
