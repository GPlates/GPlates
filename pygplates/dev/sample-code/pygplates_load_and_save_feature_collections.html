Load and save feature collections

This example loads features from files, and saves features to files.

The feature data must already be in a file format that pyGPlates can load (pygplates.FeatureCollection lists them). If it is not, it first needs to be imported.

Create a file containing a subset of features from another file

This example creates a new GPML file containing only the coastlines that have a plate ID of 801 (Australia).

Data files

coastlines.gpml

Coastline features, each with a reconstruction plate ID. Those on plate 801 are written to the new file. The GPlates sample data has such a file.

Sample code

import pygplates


# Load the global coastline features.
input_feature_collection = pygplates.FeatureCollection('coastlines.gpml')

# Start with an empty list of coastline features on plate 801.
features_in_plate_801 = []

# Iterate over all coastline features and add those on plate 801 to 'features_in_plate_801'.
for feature in input_feature_collection:
    if feature.get_reconstruction_plate_id() == 801:
        features_in_plate_801.append(feature)

# Write the coastline features for plate 801 to a new file.
output_feature_collection = pygplates.FeatureCollection(features_in_plate_801)
output_feature_collection.write('coastlines_801.gpml')

Details

A pygplates.FeatureCollection is used both to load features from a file and to save them to a file.

Creating a pygplates.FeatureCollection from a filename loads the features in that file. Here the file is coastlines.gpml, which contains coastline features.

# Load the global coastline features.
input_feature_collection = pygplates.FeatureCollection('coastlines.gpml')

Alternatively the pygplates.FeatureCollection.read() function could have been used:

features = pygplates.FeatureCollection.read('coastlines.gpml')

For a single file that is more complicated than necessary. It is useful for reading several files at once: given a list of filenames, it returns a list of feature collections.

The coastline features that are on plate 801 are collected in a Python list. A pygplates.FeatureCollection could have been used instead, but a list is easier, and it makes no difference: a feature collection is easily created from the list when it is time to save to a file.

# Start with an empty list of coastline features on plate 801.
features_in_plate_801 = []

The script iterates over all the coastline features, and adds only those with a plate ID of 801 to the list. A pygplates.FeatureCollection can be iterated over like any Python sequence (such as a list), using for item in sequence:.

# Iterate over all coastline features and add those on plate 801 to 'features_in_plate_801'.
for feature in input_feature_collection:
    if feature.get_reconstruction_plate_id() == 801:
        features_in_plate_801.append(feature)

Features are saved to a file through a pygplates.FeatureCollection, so one is created from the features_in_plate_801 list. It accepts any Python sequence of features.

# Write the coastline features for plate 801 to a new file.
output_feature_collection = pygplates.FeatureCollection(features_in_plate_801)

pygplates.FeatureCollection.write() then writes the feature collection to a new file. Here the coastline features of plate 801 are saved to a file called coastlines_801.gpml. The filename extension selects the file format.

output_feature_collection.write('coastlines_801.gpml')

Create a file containing features from multiple files

This example creates a new GPML file containing the ridges from one file and the isochrons from another.

Data files

ridges.gpml, isochrons.gpml

Any two files of features. Nothing in them is queried; their features are simply merged into one file. The GPlates sample data has files of mid-ocean ridges and isochrons.

Sample code

import pygplates


# The list of files to merge.
filenames = ['ridges.gpml', 'isochrons.gpml']

# The list of features from all input files.
merged_features = []

# Iterate over the input files and add their features to the merged list.
for filename in filenames:
    features = pygplates.FeatureCollection(filename)
    merged_features.extend(features)

# Write the merged features to a file.
merged_feature_collection = pygplates.FeatureCollection(merged_features)
merged_feature_collection.write('ridges_and_isochrons.gpml')

Details

A pygplates.FeatureCollection is used both to load features from a file and to save them to a file.

The script iterates over the input files. It loads the features of each file, and adds them to a single list, merged_features.

The features are added with the list.extend() method, which accepts anything that can be iterated over. It iterates over the pygplates.FeatureCollection, and appends each feature to the list.

# The list of features from all input files.
merged_features = []

# Iterate over the input files and add their features to the merged list.
for filename in filenames:
    features = pygplates.FeatureCollection(filename)
    merged_features.extend(features)

A pygplates.FeatureCollection is created from the merged features, and writes them to a new file.

# Write the merged features to a file.
merged_feature_collection = pygplates.FeatureCollection(merged_features)
merged_feature_collection.write('ridges_and_isochrons.gpml')
