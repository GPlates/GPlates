Calculate velocities of motion path and flowline seed points

This example calculates the velocity of the seed point of each motion path and flowline as it is reconstructed through geological time.

The seed point of a motion path is a point on a plate, and its motion path is the track of that point. The velocity of the reconstructed seed point is how fast, and in which direction, the plate is moving there at the reconstruction time.

The seed point of a flowline is a point on a mid-ocean ridge, and its velocity is that of the spreading ridge there.

Both velocities are relative to the anchor plate, as other velocities are.

Data files

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the motion paths and flowlines.

motion_path_features.gpml

Motion path features, each with seed points, a reconstruction plate ID, a relative plate ID and a list of times.

flowline_features.gpml

Flowline features, each with seed points, left and right plate IDs and a list of times.

Rotation files and flowlines are in the GPlates sample data.

Motion path and flowline features can be created in GPlates, or by Create common feature types.

Sample code

import math
import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Create a reconstruct model from the motion path features, the flowline features and the rotation model.
reconstruct_model = pygplates.ReconstructModel(
        ['motion_path_features.gpml', 'flowline_features.gpml'],
        rotation_model)

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

# Our geological times will be from 0Ma to 100Ma in 10 My intervals.
max_time = 100
time_increment = 10

for time in range(0, max_time + 1, time_increment):

    print(f'Time {time}:')

    # Reconstruct the motion paths and flowlines to the current 'time'.
    reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

    # Get the reconstructed motion paths and the reconstructed flowlines.
    # There is one for each seed point of each feature that exists at the current 'time'.
    reconstructed_motion_paths_and_flowlines = reconstruct_snapshot.get_reconstructed_geometries(
            reconstruct_types=pygplates.ReconstructType.motion_path | pygplates.ReconstructType.flowline)

    for reconstructed_motion_path_or_flowline in reconstructed_motion_paths_and_flowlines:

        # Where the seed point is at the current 'time'.
        seed_point = reconstructed_motion_path_or_flowline.get_reconstructed_seed_point()

        # The velocity of the seed point, from 'time + delta_time' to 'time', in centimetres per year.
        seed_point_velocity_vector = reconstructed_motion_path_or_flowline.get_reconstructed_seed_point_velocity(
                velocity_delta_time=delta_time,
                velocity_units=pygplates.VelocityUnits.cms_per_yr)

        # Convert the global 3D velocity vector to a local (magnitude, azimuth, inclination) tuple at the seed point.
        speed, azimuth, inclination = pygplates.LocalCartesian(seed_point).from_geocentric_to_magnitude_azimuth_inclination(
                seed_point_velocity_vector)

        if isinstance(reconstructed_motion_path_or_flowline, pygplates.ReconstructedMotionPath):
            description = 'Motion path'
        else:
            description = 'Flowline'
        seed_latitude, seed_longitude = seed_point.to_lat_lon()
        print(f'  {description} seed point at ({seed_latitude:.2f}, {seed_longitude:.2f}) is moving at '
              f'{speed:.2f} cm/yr in the direction {math.degrees(azimuth):.1f} degrees clockwise from North')

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

A reconstruct model is created from both files of features and the rotation model.

# Create a reconstruct model from the motion path features, the flowline features and the rotation model.
reconstruct_model = pygplates.ReconstructModel(
        ['motion_path_features.gpml', 'flowline_features.gpml'],
        rotation_model)

The velocities at each time are calculated over a 1My interval, from time + delta_time to time.

# Calculate velocities using a delta time interval of 1My.
delta_time = 1

The features are reconstructed to the current time using pygplates.ReconstructModel.reconstruct_snapshot().

# Reconstruct the motion paths and flowlines to the current 'time'.
reconstruct_snapshot = reconstruct_model.reconstruct_snapshot(time)

By default pygplates.ReconstructSnapshot.get_reconstructed_geometries() returns neither motion paths nor flowlines, so both are requested with the reconstruct_types argument (see pygplates.ReconstructType).

It returns a pygplates.ReconstructedMotionPath or a pygplates.ReconstructedFlowline for each seed point of each feature. A feature that does not exist at the current time (according to its valid time) has none. Nor does a motion path or a flowline at, or before, the oldest of its times, where there is no path or flowline yet.

# Get the reconstructed motion paths and the reconstructed flowlines.
# There is one for each seed point of each feature that exists at the current 'time'.
reconstructed_motion_paths_and_flowlines = reconstruct_snapshot.get_reconstructed_geometries(
        reconstruct_types=pygplates.ReconstructType.motion_path | pygplates.ReconstructType.flowline)

get_reconstructed_seed_point() returns the position of the seed point at the current time (see pygplates.ReconstructedMotionPath.get_reconstructed_seed_point() and pygplates.ReconstructedFlowline.get_reconstructed_seed_point()).

For a motion path this is the last point of the path, which is the youngest. For a flowline it is the point on the spreading ridge that its left and right halves spread from.

# Where the seed point is at the current 'time'.
seed_point = reconstructed_motion_path_or_flowline.get_reconstructed_seed_point()

get_reconstructed_seed_point_velocity() returns the velocity of the reconstructed seed point as a pygplates.Vector3D (a global cartesian velocity vector) (see pygplates.ReconstructedMotionPath.get_reconstructed_seed_point_velocity() and pygplates.ReconstructedFlowline.get_reconstructed_seed_point_velocity()).

It is in kilometres per million years by default. Here velocity_units asks for centimetres per year.

The seed point of a motion path moves with the reconstruction plate ID of its feature, so this is the velocity of that plate at the seed point. It is relative to the anchor plate, not to the relative plate ID of the feature, which only affects the shape of the motion path.

The seed point of a flowline moves by half-stage rotation between the left and right plate IDs of its feature, so its velocity is about midway between the velocities of those two plates there.

# The velocity of the seed point, from 'time + delta_time' to 'time', in centimetres per year.
seed_point_velocity_vector = reconstructed_motion_path_or_flowline.get_reconstructed_seed_point_velocity(
        velocity_delta_time=delta_time,
        velocity_units=pygplates.VelocityUnits.cms_per_yr)

The vector is converted to a local (magnitude, azimuth, inclination) tuple at the seed point.

A pygplates.LocalCartesian is a local coordinate system at one point, here the seed point, and pygplates.LocalCartesian.from_geocentric_to_magnitude_azimuth_inclination() converts a vector into it.

The magnitude is the speed. The azimuth is the direction of motion, as an angle in radians clockwise from North (as viewed from the seed point).

# Convert the global 3D velocity vector to a local (magnitude, azimuth, inclination) tuple at the seed point.
speed, azimuth, inclination = pygplates.LocalCartesian(seed_point).from_geocentric_to_magnitude_azimuth_inclination(
        seed_point_velocity_vector)

Finally the position, speed and direction of each seed point are printed.

if isinstance(reconstructed_motion_path_or_flowline, pygplates.ReconstructedMotionPath):
    description = 'Motion path'
else:
    description = 'Flowline'
seed_latitude, seed_longitude = seed_point.to_lat_lon()
print(f'  {description} seed point at ({seed_latitude:.2f}, {seed_longitude:.2f}) is moving at '
      f'{speed:.2f} cm/yr in the direction {math.degrees(azimuth):.1f} degrees clockwise from North')
