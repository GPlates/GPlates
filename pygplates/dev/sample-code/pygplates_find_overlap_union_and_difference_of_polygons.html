Find the overlap, union and difference of polygons

This example combines pairs of polygons using the four Boolean operations of pygplates.PolygonOnSphere, which were added in pyGPlates 1.1:

  • intersection(): the region inside both polygons (their overlap),

  • union(): the region inside either polygon,

  • difference(): the region inside the first polygon but outside the second, and

  • symmetric_difference(): the region inside exactly one of them.

Each returns a list of polygons, since the result can be in several pieces, or empty. The polygons in a list do not overlap each other, and they have interior rings where the region has holes.

The first example finds how much of a region of interest each reconstructed static polygon covers, and how much of the region none of them covers.

The second example compares two positions of the same polygon using all four operations.

Data files

Both scripts read the same files:

rotations.rot

A rotation file. It must contain rotations for the plate IDs of the static polygons.

static_polygons.gpml

Polygon features, each with a reconstruction plate ID. Static polygons are used here, but any polygon features will do, such as continental polygons.

Files of these kinds are in the GPlates sample data.

Find the overlap of reconstructed polygons with a region

Sample code

import pygplates


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# Reconstruct the static polygons to 50Ma.
reconstruction_time = 50
reconstruct_snapshot = pygplates.ReconstructSnapshot('static_polygons.gpml', rotation_model, reconstruction_time)

# The region of interest: a polygon that stays where it is (it is not reconstructed).
region = pygplates.PolygonOnSphere([(5, 45), (5, 90), (50, 90), (50, 45)])

# The polygons that make up the part of the region that no reconstructed polygon covers.
# To begin with that is the whole region.
uncovered_polygons = [region]

for reconstructed_geometry in reconstruct_snapshot.get_reconstructed_geometries():

    # Only polygons can overlap the region.
    reconstructed_polygon = reconstructed_geometry.get_reconstructed_geometry()
    if not isinstance(reconstructed_polygon, pygplates.PolygonOnSphere):
        continue

    # The part of the reconstructed polygon that is inside the region, as a list of polygons.
    # The list is empty if the two do not overlap.
    polygons_inside_region = reconstructed_polygon.intersection(region)

    if polygons_inside_region:
        area_inside_region = sum(polygon.get_area() for polygon in polygons_inside_region)
        area_inside_region_in_square_kms = area_inside_region * pygplates.Earth.mean_radius_in_kms**2
        num_interior_rings = sum(polygon.get_number_of_interior_rings() for polygon in polygons_inside_region)

        plate_id = reconstructed_geometry.get_feature().get_reconstruction_plate_id()
        print(f'Plate {plate_id} covers {area_inside_region_in_square_kms:.0f} square kms of the region, '
              f'in {len(polygons_inside_region)} polygons with {num_interior_rings} interior rings')

    # Remove the reconstructed polygon from what is left of the region.
    remaining_uncovered_polygons = []
    for uncovered_polygon in uncovered_polygons:
        remaining_uncovered_polygons.extend(uncovered_polygon.difference(reconstructed_polygon))
    uncovered_polygons = remaining_uncovered_polygons

uncovered_area = sum(polygon.get_area() for polygon in uncovered_polygons)
uncovered_area_in_square_kms = uncovered_area * pygplates.Earth.mean_radius_in_kms**2
region_area_in_square_kms = region.get_area() * pygplates.Earth.mean_radius_in_kms**2
print(f'No plate covers {uncovered_area_in_square_kms:.0f} of the {region_area_in_square_kms:.0f} square kms of the region, '
      f'in {len(uncovered_polygons)} polygons')

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

The static polygons are reconstructed to 50Ma by creating a pygplates.ReconstructSnapshot.

# Reconstruct the static polygons to 50Ma.
reconstruction_time = 50
reconstruct_snapshot = pygplates.ReconstructSnapshot('static_polygons.gpml', rotation_model, reconstruction_time)

The region of interest is a pygplates.PolygonOnSphere created from four points. It is not reconstructed: it stays where it is while the static polygons move across it.

# The region of interest: a polygon that stays where it is (it is not reconstructed).
region = pygplates.PolygonOnSphere([(5, 45), (5, 90), (50, 90), (50, 45)])

The part of the region that no reconstructed polygon covers is kept as a list of polygons. It starts as the whole region, and each reconstructed polygon is removed from it in the loop below.

# The polygons that make up the part of the region that no reconstructed polygon covers.
# To begin with that is the whole region.
uncovered_polygons = [region]

pygplates.ReconstructSnapshot.get_reconstructed_geometries() returns a pygplates.ReconstructedFeatureGeometry for each geometry of each feature that exists at 50Ma.

The Boolean operations are methods of polygons, so a reconstructed geometry of another type is skipped.

for reconstructed_geometry in reconstruct_snapshot.get_reconstructed_geometries():

    # Only polygons can overlap the region.
    reconstructed_polygon = reconstructed_geometry.get_reconstructed_geometry()
    if not isinstance(reconstructed_polygon, pygplates.PolygonOnSphere):
        continue

pygplates.PolygonOnSphere.intersection() returns the polygons that cover the region inside both the reconstructed polygon and the region of interest.

The list is empty if the two are apart, and also if they only touch (along an edge, or at points).

If the reconstructed polygon is entirely inside the region of interest, the list contains the reconstructed polygon itself.

# The part of the reconstructed polygon that is inside the region, as a list of polygons.
# The list is empty if the two do not overlap.
polygons_inside_region = reconstructed_polygon.intersection(region)

The area of the overlap is the sum of the areas of the polygons in the list, since they do not overlap each other. pygplates.PolygonOnSphere.get_area() returns an area on a sphere of unit radius, which is multiplied by the square of the Earth’s radius to convert it to square kilometres.

The interior rings of both polygons take part in the operation. So where the region of interest covers a hole in a reconstructed polygon, the polygon returned has that hole as an interior ring, and its area does not include it.

if polygons_inside_region:
    area_inside_region = sum(polygon.get_area() for polygon in polygons_inside_region)
    area_inside_region_in_square_kms = area_inside_region * pygplates.Earth.mean_radius_in_kms**2
    num_interior_rings = sum(polygon.get_number_of_interior_rings() for polygon in polygons_inside_region)

    plate_id = reconstructed_geometry.get_feature().get_reconstruction_plate_id()
    print(f'Plate {plate_id} covers {area_inside_region_in_square_kms:.0f} square kms of the region, '
          f'in {len(polygons_inside_region)} polygons with {num_interior_rings} interior rings')

pygplates.PolygonOnSphere.difference() returns the polygons that cover the region inside one polygon but outside another.

Here the reconstructed polygon is removed from each polygon of what is left of the region of interest, and the pieces that are returned become what is left.

If the two polygons are apart (or only touch) the list contains the first polygon itself, and if the first is entirely inside the second the list is empty.

Where the second polygon is entirely inside the first, the polygon returned has a hole where the second is.

# Remove the reconstructed polygon from what is left of the region.
remaining_uncovered_polygons = []
for uncovered_polygon in uncovered_polygons:
    remaining_uncovered_polygons.extend(uncovered_polygon.difference(reconstructed_polygon))
uncovered_polygons = remaining_uncovered_polygons

What is left after every reconstructed polygon has been removed is the part of the region of interest that no polygon covers: the gaps between the reconstructed static polygons.

The areas that the plates cover can add up to more than the rest of the region, because reconstructed static polygons also move over each other, and the area where two overlap is counted for both.

uncovered_area = sum(polygon.get_area() for polygon in uncovered_polygons)
uncovered_area_in_square_kms = uncovered_area * pygplates.Earth.mean_radius_in_kms**2
region_area_in_square_kms = region.get_area() * pygplates.Earth.mean_radius_in_kms**2
print(f'No plate covers {uncovered_area_in_square_kms:.0f} of the {region_area_in_square_kms:.0f} square kms of the region, '
      f'in {len(uncovered_polygons)} polygons')

Compare two positions of a polygon

This example compares where each static polygon was at 50Ma with where it is at present day. Two polygons to compare could equally be the positions that two rotation models give the same feature, or a reconstructed outline and one digitised from a map.

Sample code

import pygplates


# Reconstruct the static polygons to 50Ma.
reconstruction_time = 50
reconstruct_snapshot = pygplates.ReconstructSnapshot('static_polygons.gpml', 'rotations.rot', reconstruction_time)


def get_area_in_square_kms(polygons):
    """The total area of a list of polygons that do not overlap each other."""
    return sum(polygon.get_area() for polygon in polygons) * pygplates.Earth.mean_radius_in_kms**2


for reconstructed_geometry in reconstruct_snapshot.get_reconstructed_geometries():

    # The two polygons to compare: where the static polygon is at present day, and where it was at 50Ma.
    present_day_polygon = reconstructed_geometry.get_present_day_geometry()
    reconstructed_polygon = reconstructed_geometry.get_reconstructed_geometry()
    if not isinstance(reconstructed_polygon, pygplates.PolygonOnSphere):
        continue

    # The region inside both polygons.
    polygons_in_both = reconstructed_polygon.intersection(present_day_polygon)

    # The region inside the reconstructed polygon but outside the present day polygon.
    polygons_in_reconstructed_only = reconstructed_polygon.difference(present_day_polygon)

    # The region inside exactly one of the two polygons.
    polygons_in_one_only = reconstructed_polygon.symmetric_difference(present_day_polygon)

    # The region inside either polygon (or both).
    polygons_in_either = reconstructed_polygon.union(present_day_polygon)

    plate_id = reconstructed_geometry.get_feature().get_reconstruction_plate_id()
    print(f'Polygon of plate {plate_id} at {reconstruction_time}Ma and at present day:')
    print(f'  {get_area_in_square_kms(polygons_in_both):.0f} square kms are inside both')
    print(f'  {get_area_in_square_kms(polygons_in_reconstructed_only):.0f} square kms are inside the reconstructed polygon only')
    print(f'  {get_area_in_square_kms(polygons_in_one_only):.0f} square kms are inside one only')
    print(f'  {get_area_in_square_kms(polygons_in_either):.0f} square kms are inside either')

    # The polygons returned have interior rings where the region has holes.
    num_interior_rings = sum(polygon.get_number_of_interior_rings() for polygon in polygons_in_either)
    print(f'  the region inside either is {len(polygons_in_either)} polygons with {num_interior_rings} interior rings')

Details

The static polygons are reconstructed to 50Ma, as in the first example.

# Reconstruct the static polygons to 50Ma.
reconstruction_time = 50
reconstruct_snapshot = pygplates.ReconstructSnapshot('static_polygons.gpml', 'rotations.rot', reconstruction_time)

Each of the four operations returns a list of polygons that do not overlap each other, so one function finds the area of any of the results.

def get_area_in_square_kms(polygons):
    """The total area of a list of polygons that do not overlap each other."""
    return sum(polygon.get_area() for polygon in polygons) * pygplates.Earth.mean_radius_in_kms**2

A pygplates.ReconstructedFeatureGeometry has both of the polygons to compare: pygplates.ReconstructedFeatureGeometry.get_present_day_geometry() and pygplates.ReconstructedFeatureGeometry.get_reconstructed_geometry().

for reconstructed_geometry in reconstruct_snapshot.get_reconstructed_geometries():

    # The two polygons to compare: where the static polygon is at present day, and where it was at 50Ma.
    present_day_polygon = reconstructed_geometry.get_present_day_geometry()
    reconstructed_polygon = reconstructed_geometry.get_reconstructed_geometry()
    if not isinstance(reconstructed_polygon, pygplates.PolygonOnSphere):
        continue

pygplates.PolygonOnSphere.intersection() returns the region that the polygon covers at both times.

# The region inside both polygons.
polygons_in_both = reconstructed_polygon.intersection(present_day_polygon)

pygplates.PolygonOnSphere.difference() returns the region that the polygon covered at 50Ma but does not cover now.

Unlike the other three operations, the order of the two polygons matters: present_day_polygon.difference(reconstructed_polygon) is the region that it covers now but did not cover at 50Ma.

# The region inside the reconstructed polygon but outside the present day polygon.
polygons_in_reconstructed_only = reconstructed_polygon.difference(present_day_polygon)

pygplates.PolygonOnSphere.symmetric_difference() returns the region that the polygon covers at one of the times but not the other. This is both of the differences above.

Its area measures how much two outlines of the same thing disagree: it is zero if they are identical.

# The region inside exactly one of the two polygons.
polygons_in_one_only = reconstructed_polygon.symmetric_difference(present_day_polygon)

pygplates.PolygonOnSphere.union() returns the region that the polygon covers at either time.

Two polygons that overlap, or share an edge, are merged into one polygon. Two that are apart, or touch only at points, are returned as they are, so the list then has two polygons.

# The region inside either polygon (or both).
polygons_in_either = reconstructed_polygon.union(present_day_polygon)

The four areas are related: the area inside either polygon is the area inside both plus the area inside one only.

plate_id = reconstructed_geometry.get_feature().get_reconstruction_plate_id()
print(f'Polygon of plate {plate_id} at {reconstruction_time}Ma and at present day:')
print(f'  {get_area_in_square_kms(polygons_in_both):.0f} square kms are inside both')
print(f'  {get_area_in_square_kms(polygons_in_reconstructed_only):.0f} square kms are inside the reconstructed polygon only')
print(f'  {get_area_in_square_kms(polygons_in_one_only):.0f} square kms are inside one only')
print(f'  {get_area_in_square_kms(polygons_in_either):.0f} square kms are inside either')

A polygon returned by any of the operations has an interior ring wherever the region it covers has a hole. For example, the union of two positions of a polygon that has a hole in it has a hole where the two positions of that hole overlap.

# The polygons returned have interior rings where the region has holes.
num_interior_rings = sum(polygon.get_number_of_interior_rings() for polygon in polygons_in_either)
print(f'  the region inside either is {len(polygons_in_either)} polygons with {num_interior_rings} interior rings')

Note

Each ring of a polygon bounds the smaller of its two sides, so no ring can enclose more than a hemisphere. pygplates.PolygonOnSphere.union() and pygplates.PolygonOnSphere.symmetric_difference() raise pygplates.PartitionError if an outer ring of their result would (two very large polygons that overlap, say).

Note

Pieces of a result that are narrower than about 9 metres are dropped. The sliver_width_threshold_radians argument of each operation changes that width, and zero keeps every piece.
