Hierarchy of plate rotations

This example traverses the plate rotation hierarchy at a reconstruction time, and prints the relative and equivalent total rotations of each plate.

The output is similar to the Reconstruction Tree tab of the Total Reconstruction Poles dialog in GPlates.

Data files

rotations.rot

A rotation file. Rotation files are in the GPlates sample data.

Sample code

import pygplates


# A function to traverse the sub-tree rooted at a particular plate (the moving plate of 'edge').
def traverse_sub_tree(edge, depth):

    relative_total_rotation = edge.get_relative_total_rotation()
    relative_pole_latitude, relative_pole_longitude, relative_angle_degrees = (
        relative_total_rotation.get_lat_lon_euler_pole_and_angle_degrees())

    equivalent_total_rotation = edge.get_equivalent_total_rotation()
    equivalent_pole_latitude, equivalent_pole_longitude, equivalent_angle_degrees = (
        equivalent_total_rotation.get_lat_lon_euler_pole_and_angle_degrees())

    prefix_padding = ' ' * (2*depth)

    print(f'{prefix_padding}Plate ID: {edge.get_moving_plate_id()}, Fixed Plate ID: {edge.get_fixed_plate_id()}:')

    print(f'{prefix_padding}  Rotation rel. fixed (parent) plate: '
          f'lat: {relative_pole_latitude:f}, lon: {relative_pole_longitude:f}:, angle:{relative_angle_degrees:f}')

    print(f'{prefix_padding}  Equivalent rotation rel. anchored plate: '
          f'lat: {equivalent_pole_latitude:f}, lon: {equivalent_pole_longitude:f}:, angle:{equivalent_angle_degrees:f}')

    # Blank line.
    print()

    # Recurse into the children sub-trees.
    for child_edge in edge.get_child_edges():
        traverse_sub_tree(child_edge, depth + 1)


# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

# The reconstruction time (Ma) of the plate hierarchy we're interested in.
reconstruction_time = 60

# Get the reconstruction tree.
reconstruction_tree = rotation_model.get_reconstruction_tree(reconstruction_time)

# Get the edges of the reconstruction tree emanating from its root (anchor) plate.
anchor_plate_edges = reconstruction_tree.get_anchor_plate_edges()

# Iterate over the anchor plate edges and traverse the sub-tree of each edge.
for anchor_plate_edge in anchor_plate_edges:
    traverse_sub_tree(anchor_plate_edge, 0)

Details

The rotations are loaded from a rotation file into a pygplates.RotationModel.

# Load one or more rotation files into a rotation model.
rotation_model = pygplates.RotationModel('rotations.rot')

The plate rotation hierarchy at a reconstruction time is held in a reconstruction tree. pygplates.RotationModel.get_reconstruction_tree() returns the tree at the reconstruction time, here 60Ma.

The hierarchy can differ from one reconstruction time to the next, depending on how the rotations are arranged in the rotation file.

# Get the reconstruction tree.
reconstruction_tree = rotation_model.get_reconstruction_tree(reconstruction_time)

An edge of the reconstruction tree is the rotation of a moving plate relative to a fixed plate. The edges form a tree whose root is the anchor plate (plate ID zero, unless another is asked for).

The anchor plate edges are the edges at the top of the tree, and pygplates.ReconstructionTree.get_anchor_plate_edges() returns them.

# Get the edges of the reconstruction tree emanating from its root (anchor) plate.
anchor_plate_edges = reconstruction_tree.get_anchor_plate_edges()

The anchor plate edges all have the same fixed plate, the anchor plate, and each has a different moving plate. Each of those moving plates is the root of a sub-tree of the reconstruction tree.

The script traverses the sub-tree of each anchor plate edge, starting at a depth of zero.

# Iterate over the anchor plate edges and traverse the sub-tree of each edge.
for anchor_plate_edge in anchor_plate_edges:
    traverse_sub_tree(anchor_plate_edge, 0)

The traversal is done by a function. It visits one edge, and then the sub-tree below the moving plate of that edge.

It is a function because it is recursive (it calls itself), which is the simplest way to traverse a tree.

Its depth argument is the depth of the edge below the anchor plate. It is used only to indent the printed lines.

def traverse_sub_tree(edge, depth):
    ...

The function first gets the relative and equivalent total rotations of the edge, with pygplates.ReconstructionTreeEdge.get_relative_total_rotation() and pygplates.ReconstructionTreeEdge.get_equivalent_total_rotation():

  • The relative total rotation is the rotation of the moving plate of the edge relative to its fixed plate.

  • The equivalent total rotation is the rotation of the moving plate of the edge relative to the anchor plate.

A total rotation is a rotation from present day (0Ma) to the reconstruction time.

pygplates.FiniteRotation.get_lat_lon_euler_pole_and_angle_degrees() returns the pole and angle of each rotation.

relative_total_rotation = edge.get_relative_total_rotation()
relative_pole_latitude, relative_pole_longitude, relative_angle_degrees = (
    relative_total_rotation.get_lat_lon_euler_pole_and_angle_degrees())

equivalent_total_rotation = edge.get_equivalent_total_rotation()
equivalent_pole_latitude, equivalent_pole_longitude, equivalent_angle_degrees = (
    equivalent_total_rotation.get_lat_lon_euler_pole_and_angle_degrees())

The function then prints the moving and fixed plate IDs of the edge, and its two rotations. The indent is prefix_padding, which is two spaces for each level of depth.

prefix_padding = ' ' * (2*depth)

print(f'{prefix_padding}Plate ID: {edge.get_moving_plate_id()}, Fixed Plate ID: {edge.get_fixed_plate_id()}:')

print(f'{prefix_padding}  Rotation rel. fixed (parent) plate: '
      f'lat: {relative_pole_latitude:f}, lon: {relative_pole_longitude:f}:, angle:{relative_angle_degrees:f}')

print(f'{prefix_padding}  Equivalent rotation rel. anchored plate: '
      f'lat: {equivalent_pole_latitude:f}, lon: {equivalent_pole_longitude:f}:, angle:{equivalent_angle_degrees:f}')

# Blank line.
print()

Just as the anchor plate has anchor plate edges below it, the moving plate of an edge can have child edges below it. pygplates.ReconstructionTreeEdge.get_child_edges() returns them.

The function calls itself on each child edge, with a depth that is one greater. In this way it visits every edge, and so every plate, of the sub-tree.

The recursion stops at an edge that has no child edges. No plate moves relative to the moving plate of that edge.

# Recurse into the children sub-trees.
for child_edge in edge.get_child_edges():
    traverse_sub_tree(child_edge, depth + 1)

Here lat: 90.000000, lon: 0.000000:, angle:0.000000 is what pygplates.FiniteRotation.get_lat_lon_euler_pole_and_angle_degrees() returns, by default, for an identity rotation: the north pole and an angle of zero. An identity rotation has no pole of its own, since it does not rotate.
